Signal

I do not owe anyone a narrative about my choices, movements, or priorities.

  

Rule

Story creates debt; silence preserves autonomy.

  

Protocol

- Decline narrative-building conversations
    
- Keep explanations minimal or absent
    
- Allow ambiguity without correction
    
- Let consistency replace explanation over time
    

  

Stop Condition

If I start pre-emptively explaining to avoid misunderstanding, story debt has already formed.
