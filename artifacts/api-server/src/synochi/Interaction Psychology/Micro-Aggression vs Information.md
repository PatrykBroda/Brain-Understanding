Signal

Not all sharp or awkward interactions are aggression; many are informational tells.

  

Rule

Interpreting micro-aggressions as data prevents emotional escalation and preserves clarity.

  

Protocol

- Register the interaction without labelling it hostile
    
- Note timing, context, and delivery
    
- Adjust exposure or boundaries accordingly
    
- Do not confront unless pattern repeats with cost
    

  

Stop Condition

If I personalise the interaction or assign intent prematurely, information has turned into narrative.
