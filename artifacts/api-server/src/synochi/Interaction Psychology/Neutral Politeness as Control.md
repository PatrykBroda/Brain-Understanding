Signal

Politeness without warmth preserves control while avoiding friction.

  

Rule

Neutral courtesy prevents escalation without granting emotional or social access.

  

Protocol

- Be respectful but uninvested
    
- Use short acknowledgements
    
- Avoid humour that creates bonding
    
- Keep tone flat and clean
    

  

Stop Condition

If politeness turns into friendliness or explanation, access has widened beyond intent.
