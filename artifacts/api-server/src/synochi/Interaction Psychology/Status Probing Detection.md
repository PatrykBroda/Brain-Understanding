Signal

I can feel status probes before I cognitively interpret them; the body flags frame-shifts faster than language.

  

Rule

Personal questions introduced early or sideways in professional environments often function as hierarchy or leverage checks, not curiosity.

  

Protocol

- Answer briefly and neutrally
    
- Do not expand, justify, or redirect
    
- Return immediately to task-relevant context
    
- Allow the probe to die unsupported
    

  

Stop Condition

If I feel a pull to clarify, impress, defend, or narrate my life, the probe has gained leverage.
