Signal

An environment can offer high technical value while carrying a social or psychological cost.

  

Rule

Value must be weighed against cost; optimisation comes from balance, not maximisation.

  

Protocol

- Identify what the environment provides technically
    
- Identify what it drains socially or mentally
    
- Adjust frequency to keep net gain positive
    
- Reassess periodically as context changes
    

  

Stop Condition

If I rationalise staying despite accumulating irritation or fatigue, cost is exceeding value.
