# World Before Expression

**Definition:** The world comes first. Rules, costs, and limits must be established before self-expression is allowed to expand. Expression without world-logic becomes identity noise and narrative drift.

**Mechanism:**
- Define invariants → constrain outputs → preserve coherence over time
- Expression is permitted only inside the field
