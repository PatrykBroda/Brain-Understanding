Signal

I can extract value from environments without granting them identity access or emotional authority.

  

Rule

When a room provides stimulus but introduces noise, I constrain exposure rather than confront or withdraw.

  

Protocol

- Enter with respect
    
- Take rounds / reps
    
- Maintain personal opacity
    
- Exit cleanly
    
- Cap frequency to prevent environmental bleed
    

  

Stop Condition

If I feel compelled to explain myself, correct hierarchy, or personalise interactions, exposure is already too high.
