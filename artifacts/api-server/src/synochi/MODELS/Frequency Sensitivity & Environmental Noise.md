Signal

My system is sensitive to the frequency of environments; repeated exposure amplifies noise faster than value.

  

Rule

An environment can be technically beneficial while still degrading coherence if exposure is too frequent.

  

Protocol

- Sample environments intentionally
    
- Cap attendance based on signal-to-noise ratio
    
- Use spacing to preserve neutrality
    
- Prefer fewer, higher-quality exposures over repetition
    

  

Stop Condition

If irritation, judgement, or vigilance increases across visits, frequency is already too high.
