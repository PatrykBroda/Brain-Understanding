Signal

The most useful parts of books reflect something already forming internally.

  

Rule

If a passage resonates strongly, it is confirming direction, not providing it.

  

Protocol

- Notice what stands out, not what convinces
    
- Extract why it resonates
    
- Discard the rest without guilt
    
- Avoid building routes from external maps
    

  

Stop Condition

If I feel lost without the book, it has replaced internal navigation.
