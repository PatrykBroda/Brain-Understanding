Signal

Mental clarity improves when unnecessary concepts are actively removed, not replaced.

  

Rule

Addition is rarely the solution; subtraction restores signal.

  

Protocol

- Notice concepts that no longer constrain behaviour
    
- Stop revisiting ideas that have already paid their rent
    
- Remove language that inflates without grounding
    
- Trust fewer models, held more tightly
    

  

Stop Condition

If I keep adding frameworks to regain clarity, cleanliness has been abandoned.
