Signal

Insight feels sharp but leaves no trace if not integrated.

  

Rule

Only insights that alter behaviour under load are real.

  

Protocol

- Translate insight into one behavioural constraint
    
- Test it in a real environment
    
- Observe effect without narration
    
- Keep only what survives pressure
    

  

Stop Condition

If insights accumulate without changing conduct, abstraction has decoupled from reality.
