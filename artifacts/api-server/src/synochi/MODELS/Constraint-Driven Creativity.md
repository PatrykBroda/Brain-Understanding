# Constraint-Driven Creativity

**Definition:** Creativity deepens when options are removed. Limits force invention; rules prevent drift. The system becomes more intelligent when it must produce novelty without violating constraints.

**Mechanism:**
- Reduce degrees of freedom → increase quality density
- Use omission, silence, and cost to preserve world integrity
