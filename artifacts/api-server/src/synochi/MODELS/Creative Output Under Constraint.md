Signal

Creativity sharpens when limits are enforced.

  

Rule

Unlimited expression diffuses signal; constraint concentrates it.

  

Protocol

- Impose clear limits (time, format, scope)
    
- Produce without polishing
    
- Stop before exhaustion
    
- Release without explanation
    

  

Stop Condition

If creativity becomes sprawling or self-indulgent, constraints have loosened.
