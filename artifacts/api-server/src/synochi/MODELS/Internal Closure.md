Signal

Closure does not require external resolution or agreement.

  

Rule

Waiting for external closure prolongs loops unnecessarily.

  

Protocol

- Decide internally when a loop is complete
    
- Stop revisiting without new data
    
- Act as if the matter is closed
    
- Let behaviour reflect completion
    

  

Stop Condition

If I wait for acknowledgment or explanation to move on, closure has been outsourced.
