# Circular Maslow (State Classification Overlay)

**Definition:** A state-routing model where needs aren’t a ladder — they are a ring around coherence. Physiology, safety, belonging, esteem, and expression all compete for attention, but the system functions best when coherence sits at the centre and determines which layer gets served.

**Mechanism:**
- Identify which need-layer is currently driving behaviour
- Route response through coherence: stabilise first, then solve the correct layer
