# Dopamine vs Orientation

**Definition:** Dopamine drives seeking; orientation drives direction. Dopamine alone creates restless motion and novelty addiction. Orientation produces calm forward movement regardless of mood. The nervous system must be trained to move from orientation, not craving.

**Mechanism:**
- Novelty-seeking increases when baseline is unstable
- Orientation stabilises behaviour by collapsing options into mission
