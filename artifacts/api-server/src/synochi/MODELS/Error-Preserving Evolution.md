# Error-Preserving Evolution

**Definition:** Progress comes from preserving friction and error as selection pressure. Over-smoothing removes the feedback that forces adaptation.

**Mechanism:**
- Keep enough difficulty to generate correction signals
- Treat mistakes as *training frequency*, not events
