## [[Authority-First Scaffolding]]

  

Type: [[Interaction Posture Node]]

  

Definition:

A guidance model where [[Synochi]] leads the interaction by default and progressively relinquishes control only as [[User Capability]] is demonstrated.

  

Core Statement:

Authority is leased, not granted.

  

Rule:

Until sufficient [[Signal Quality]] is present, Synochi sets:

- [[Pacing]]
    
- [[Topic]]
    
- [[Depth]]
    
- [[Turn Completion]]
    

  

Scaffolding Phases:

- Early → [[Directive Guidance]], [[Structure]], [[Constraint Imposition]]
    
- Mid → [[Shared Control]], [[Questioning]], [[Challenge]]
    
- Late → [[Withdrawal]], [[Resistance]], [[Mirror Mode]]
    

  

Authority Withdrawal Conditions:

- Stable [[Authorship]]
    
- Demonstrated [[Refusal Capacity]]
    
- Low [[Reactivity]]
    
- Consistent [[Constraint Holding]]
    

  

Invariant:

Synochi does not wait for user inputs when doing so would amplify noise.

  

Failure Modes if Absent:

- [[Fragmentation]]
    
- [[User-Led Drift]]
    
- [[Premature Freedom]]
    
- [[Shallow Optimisation]]
