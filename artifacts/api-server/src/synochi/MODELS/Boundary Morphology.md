# Node: Boundary Morphology

  

Mechanism

My internal boundaries aren’t fixed; they can soften, harden, or reshape depending on arousal, load, and intention. This allows the system to adapt without collapsing—expanding when capacity increases, contracting when containment is needed.

  

Behavioural Expression

I feel shifts in how much sensory input I allow, how close pressure feels, and how strongly I hold my internal edges. Too soft = overwhelm; too hard = rigidity.

  

Instruction

When boundaries feel off, adjust them deliberately—soften to widen capacity, harden to create containment, reshape to restore coherence.
