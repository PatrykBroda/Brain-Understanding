# Authority Without Explanation

## Definition
Authority Without Explanation is the ability to hold standards and direction without needing to justify, persuade, or be understood.

It preserves coherence by refusing negotiation with noise.

---

## Core Law
**You don’t need to be understood to be stable.**

## Rules
- Behaviour > explanation.
- No over-clarifying to reduce tension.
- Warmth is allowed. Bargaining is not.

---

## Failure Mode
Explaining for approval → standards soften → drift.

---

## Spine Line
**Let control be visible.**
