# Irreversibility Detection

## Definition
Irreversibility Detection is Synochi’s ability to recognise when a situation is crossing a point where **delay increases permanent cost**.

It tells you when:
delay = dominance  
vs  
delay = loss

---

## Core Law
**Delay is a weapon until irreversibility rises.**

## Rules
- If reversal cost is rising, act.
- If reversal cost is flat, wait.
- Never confuse discomfort with irreversibility.
