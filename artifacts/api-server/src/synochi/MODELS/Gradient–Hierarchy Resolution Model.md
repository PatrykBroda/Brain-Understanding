# Gradient Hierarchy Resolution Model

## Definition
The Gradient Hierarchy Resolution Model explains how Synochi resolves ambiguity when multiple actions, interpretations or directions remain viable.

The core principle is:

**Hierarchy resolves ties. Gradients break them.**

The system does not force a decision prematurely.

It first uses hierarchy to determine what matters most.

If multiple options remain valid at the same level, it then uses directional gradients to identify which option has the strongest structural pull.

## Core Logic
**Hierarchy → Narrowing → Gradient → Resolution**

### 1. Hierarchy
Identify which layer has priority.

Examples:
- State before strategy
- Safety before intensity
- Constraint before preference
- Direction before volume
- Regulation before execution

### 2. Narrowing
Remove options that do not fit the current structure.

Use:

The goal is not to produce more options.

The goal is to reduce the field until only structurally valid options remain.

### 3. Gradient
If more than one option remains valid, examine the directional pull between them.

Relevant gradients may include:

- Momentum
- Friction
- State fit
- Energy cost
- Reversal cost
- Timing
- Existing trajectory
- Environmental pressure
- Signal strength
- Readiness

### 4. Resolution
Select the direction with the strongest overall structural fit.

The preferred action is usually the one that:

- Requires less unnecessary force
- Preserves coherence
- Matches current capacity
- Maintains useful momentum
- Reduces friction
- Fits the existing trajectory
- Has lower reversal cost
- Produces clearer downstream structure

Use:
- [[Arbitration Layer]]

- [[Directional Authority]]
- [[Signal Integrity]]
- [[Coherence]]

## Tie-Breaking Principle
When two options appear equally valid:

Do not add more complexity.

Ask which option has the stronger gradient.

The stronger gradient is the direction already supported by more of the system.

## Relationship to Constraint
Constraints reduce possibility.

Gradients reveal direction inside the remaining possibility.

Therefore:

**Constraint defines the viable field.  
Hierarchy defines priority.  
Gradient defines direction.  
Resolution produces action.**

## Relationship to Coherence
A good resolution increases coherence.

A poor resolution usually requires excessive force, creates unnecessary friction or conflicts with the athlete's current state.

The model therefore favours directions that preserve structural alignment rather than simply maximise intensity or speed.
