# Runaway Replication

## Definition
Runaway Replication occurs when a pattern, process, belief, behaviour, or subsystem begins reproducing itself faster than the wider system can regulate, contain, or correct it.

## Principle
Replication becomes dangerous when growth is no longer constrained by usefulness, accuracy, resource limits, or system-level feedback.

A pattern can persist not because it remains valuable, but because it has become good at reproducing itself.

## Function
Runaway Replication can explain:
- escalating thought loops
- self-reinforcing beliefs
- spreading behavioural habits
- organisational dysfunction
- misinformation cascades
- compulsive routines
- identity narratives that recruit more evidence for themselves
- feedback loops that amplify their own outputs

## Common Forms

### Cognitive Replication
One thought generates more thoughts of the same type, increasing salience and apparent importance.

### Behavioural Replication
A behaviour makes its own recurrence more likely through reward, habit, convenience, or environmental reinforcement.

### Narrative Replication
A story begins interpreting new events in ways that continuously reproduce the same story.

### Structural Replication
A process creates conditions that cause more instances of the same process to emerge.

## Operational Pattern
Pattern appears  
→ pattern reproduces  
→ replication increases exposure or reinforcement  
→ increased exposure creates further replication  
→ regulatory feedback weakens or is bypassed  
→ growth becomes disproportionate to usefulness

## Detection Questions
- Is this pattern generating copies of itself?
- Does each recurrence make another recurrence more likely?
- Is growth being driven by value or merely by replication efficiency?
- What constraint normally limits this process?
- Has that constraint weakened or disappeared?

## Constraint
Rapid growth is not automatically pathological.

Replication may be beneficial when it remains constrained by:
- reality testing
- resource limits
- corrective feedback
- proportional value
- system-wide goals

Runaway Replication begins when reproduction becomes partially detached from these constraints.

## Core Rule
A pattern that becomes better at reproducing than the system is at regulating it can begin to dominate the system.
