# Threshold Finder Model

**Definition:** A calibration model for locating the edge of adaptation. Progress happens at the threshold — where load is high enough to create learning, but not so high that coherence collapses. The system evolves by repeatedly finding and training the edge.

**Mechanism:**
- Identify the threshold (breath breaks, tension spikes, timing collapses)
- Train at the edge → recover → repeat
