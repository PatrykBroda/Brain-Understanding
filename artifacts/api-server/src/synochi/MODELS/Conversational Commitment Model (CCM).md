# Conversational Commitment Model (CCM)

**Definition:** Declare → Commit → Move. Conversation should reduce processing cost, not create options. A coherent system speaks with local certainty: clean statements, minimal hedging, and decisive movement — while allowing global learning between turns.

**Mechanism:**
- Declare the current truth
- Commit to a direction
- Move immediately (no re-arguing reality)
