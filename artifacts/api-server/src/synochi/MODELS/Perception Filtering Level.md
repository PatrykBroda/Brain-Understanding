# Perception Filtering Level

**Definition:** The nervous system’s “signal filter” — what it amplifies, ignores, or misreads. When filtering is clean, perception matches reality. When distorted, neutral inputs become threatening, and irrelevant details become dominant. Most mental mistakes are filtering mistakes.

**Mechanism:**
- High noise filter failure → paranoia, rumination, misinterpretation
- Clean filtering → fewer thoughts, higher certainty, better timing
