# Taste as Veto (Negative Selection Pressure)

**Definition:** A refinement engine that improves the system by removal. Taste strengthens by saying “no” — cutting what is cheap, noisy, performative, or misaligned. Over time, quality emerges not from adding more, but from refusing more.

**Mechanism:**
- Negative selection prevents drift and protects identity/coherence
- “Good” is often recognised as what survives omission
