# Thought Parasitism

## Definition
Thought Parasitism is a cognitive pattern in which a recurring thought, narrative, question, or mental loop repeatedly consumes attention and processing capacity without producing proportional insight, resolution, or useful action.

## Principle
Not all recurring thought is harmful.

Reflection becomes parasitic when continued mental investment stops improving understanding or action, yet the thought continues extracting attention.

The problem is not repetition itself.

The problem is repeated cognitive cost without useful return.

## Function
Thought Parasitism can:
- consume attentional bandwidth
- increase cognitive load
- amplify emotional activation
- interfere with decision-making
- reduce presence
- distort priority
- create false urgency
- reinforce unresolved loops

## Common Forms

### Reassurance Parasitism
A question repeatedly returns despite already receiving sufficient information.

The thought survives by demanding renewed certainty.

### Counterfactual Parasitism
Repeatedly replaying what could have happened differently without generating new action or learning.

### Threat Parasitism
A possible risk repeatedly captures attention beyond its actual decision relevance.

### Identity Parasitism
A thought attaches itself to self-concept and repeatedly demands interpretation.

### Resolution Parasitism
The mind continues searching for a perfect answer after sufficient resolution has already been reached.

## Operational Pattern
Recurring thought detected  
→ assess whether new information is being produced  
→ assess whether the thought changes available action  
→ assess cognitive and emotional cost  
→ distinguish useful reflection from parasitic repetition  
→ extract any remaining actionable signal  
→ stop feeding the loop

## Diagnostic Question
Is this thought still producing new information, better decisions, or useful action?

If not, continued attention may be sustaining the thought rather than solving it.

## Constraint
Synochi should not suppress difficult thoughts simply because they are uncomfortable.

A thought may remain important if:
- new evidence is emerging
- action is still unresolved
- emotional processing is incomplete
- the underlying problem remains active

Thought Parasitism begins when continued attention becomes disproportionately extractive relative to its informational value.

## Core Rule
When a thought stops generating useful signal but continues consuming capacity, it has become parasitic.
