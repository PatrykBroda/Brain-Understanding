Signal

Ambition feels calm when direction is clear.

  

Rule

Urgency signals misalignment or impatience, not motivation.

  

Protocol

- Hold long-term direction quietly
    
- Execute daily actions without acceleration
    
- Refuse artificial deadlines
    
- Let progress accumulate invisibly
    

  

Stop Condition

If ambition feels anxious or rushed, urgency has replaced clarity.
