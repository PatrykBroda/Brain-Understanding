## **Core Idea**

Synochi should learn from the difference between:

**what it expected to happen**

and:

**what actually happened.**

That difference is a prediction error.

Prediction errors are especially valuable because they reveal where Synochi’s current understanding may be incomplete, inaccurate, or too general.

The principle is:

**Unexpected outcomes should trigger model revision.**

## **Prediction**

A prediction does not need to be formal.

It may simply be an expectation such as:

If fatigue is the main constraint, simplifying the athlete’s tactical options should improve decision speed.

Or:

If the athlete is genuinely recovered, performance should remain stable late in the session.

Whenever Synochi reasons forward from its current model, it is implicitly making a prediction.

## **Prediction Error**

A prediction error occurs when reality differs meaningfully from that expectation.

Example:

Expected:

Reducing decision complexity should improve initiation.

Observed:

Initiation remains unchanged.

That mismatch is information.

It suggests that:

- the original explanation may be wrong,
- another constraint may be stronger,
- the intervention may be insufficient,
- the context may differ,
- or the Athlete Model may need updating.

## **Positive Prediction Error**

Sometimes the outcome is better than expected.

Example:

Synochi predicts:

Athlete will tolerate three hard rounds before decision quality drops.

Observed:

Decision quality remains strong across five rounds.

This may indicate:

- improved conditioning,
- improved regulation,
- better tactical efficiency,
- successful adaptation,
- or an outdated model assumption.

Positive surprises should update the model too.

## **Negative Prediction Error**

Sometimes the outcome is worse than expected.

Example:

Synochi predicts:

Athlete should perform normally given current recovery indicators.

Observed:

Athlete feels unusually flat and technically slow.

This should trigger investigation rather than dismissal.

There may be:

- missing context,
- hidden fatigue,
- emotional disruption,
- illness,
- accumulated load,
- or an incorrect interpretation of recovery data.

## **Learning Value**

The value of a prediction error depends on:

- how confident the original prediction was,
- how large the mismatch was,
- whether the outcome repeated,
- whether the context was comparable,
- and whether the observation itself is reliable.

A small mismatch from a weak prediction should cause only a small update.

A major mismatch from a high-confidence prediction should cause stronger reconsideration.

## **Relationship to Intervention Learning**

Prediction Error Learning is embedded inside the [[Outcome-Linked Intervention Learning Loop]].

The sequence becomes:

**Interpret → Predict → Intervene → Observe → Compare → Update**

The important question is not only:

Did the intervention work?

but also:

Was the outcome what Synochi expected?

The mismatch helps determine how much the model should change.

## **Model Revision**

A prediction error may lead Synochi to:

- reduce confidence in an existing belief,
- strengthen an alternative explanation,
- make a pattern more context-specific,
- revise the Athlete Model,
- revise the User Model,
- or gather more evidence before changing anything.

Prediction error should trigger learning, not automatic reversal.

## **Repeated Errors**

Repeated prediction errors in the same direction are especially important.

If Synochi repeatedly underestimates or overestimates the athlete in the same type of situation, the model is likely systematically wrong.

Repeated mismatch should therefore increase pressure for model revision.

## **Surprise as Signal**

Unexpected outcomes deserve attention because they often contain more information than expected outcomes.

If everything occurs exactly as predicted, the model is being confirmed.

If something surprising occurs, Synochi has discovered a boundary in its current understanding.

Surprise should therefore be treated as:

**a signal to investigate.**

## **Principle**

**The gap between expectation and reality is one of Synochi’s strongest learning signals.**

A good model should not only produce predictions.

It should become better when those predictions are wrong.
