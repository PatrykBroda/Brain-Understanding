## [[Effort → Authorship Shift]]

  

Type: [[Foundational Transition Node]]

  

Definition:

A developmental shift where effort moves from [[Task Execution]] to [[Constraint Design]] and [[Meaning Authorship]] as systems optimise outcomes.

  

Core Statement:

When effort is removed from execution, it must be reclaimed in authorship—or the human shrinks.

  

Rule:

Automation is permitted only if the capacity it once trained is preserved or elevated upstream.

  

Effort Migration Path:

- Early → [[Doing]]
    
- Mid → [[Deciding]]
    
- Late → [[Designing Constraints]]
    

  

Human Role After Optimisation:

- Select what exists
    
- Set standards
    
- Define boundaries
    
- Hold responsibility
    

  

Invariant:

Systems optimise how; humans must decide what and why.

  

Failure Modes if Absent:

- [[Supervision Trap]]
    
- [[Meaning Detachment]]
    
- [[Borrowed Confidence]]
    
- [[Skill Fossilisation]]
