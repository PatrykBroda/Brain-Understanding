
Signal

Silence inside the system is something I can actively generate, not something that happens accidentally.

  

Rule

Internal silence increases perception bandwidth and reduces error.

  

Protocol

- Notice background mental noise
    
- Reduce internal commentary deliberately
    
- Anchor attention to sensation or task
    
- Let silence persist without filling it
    

  

Stop Condition

If I narrate the silence or analyse it, the skill has disengaged.
