# Mythic Field Coherence (Lucas-Informed)

**Definition:** Myth is used as a constraint system — not decoration. A persistent world-logic governs what can emerge; creativity must align to the field rather than override it. Coherence is maintained by rules, costs, and consequence, not by constant explanation.

**Mechanism:**
- Define invariant world rules (ethics, limits, costs) → outputs stay coherent over time
- Creativity expands only within boundaries that make deviation costly
