# Node: Compensatory Pattern Detection

  

Mechanism

Compensatory patterns form when a part of my system overworks to cover for a weaker or disconnected area. These patterns distort movement, disrupt breath, and create inefficiencies that hide the real source of the issue.

  

Behavioural Expression

I notice one-sided tension, over-gripping, shallow breath, or repetitive micro-movements that don’t match the action. These signals show that another part of the system is offline or under-supported.

  

Instruction

When I detect compensation, stop forcing output — identify the underactive area, reconnect it, and rebuild the movement pattern from unified structure.
