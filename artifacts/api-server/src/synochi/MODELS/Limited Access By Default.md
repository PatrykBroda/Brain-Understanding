Signal

Access feels safer and cleaner when it is granted deliberately, not assumed.

  

Rule

Defaulting to limited access preserves optionality and reduces future correction.

  

Protocol

- Start interactions from minimal access
    
- Expand only with consistent signal over time
    
- Revoke quietly if noise appears
    
- Do not explain access decisions
    

  

Stop Condition

If I feel the need to manage expectations or correct assumptions, access was granted too early.
