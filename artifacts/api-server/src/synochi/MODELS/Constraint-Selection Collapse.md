# Constraint–Selection Collapse (CSC)

**Definition:** Under true constraint, the nervous system stops “choosing” and starts *collapsing*. Options disappear, not by preference, but by cost. Clarity feels inevitable because constraints delete alternatives until only one executable line remains.

**Mechanism:**
- Constraint pressure removes false choices and forces direction
- Execution improves as options narrow (less noise, less identity)
