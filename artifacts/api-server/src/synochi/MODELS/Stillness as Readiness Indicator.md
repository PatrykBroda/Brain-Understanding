Signal

True readiness feels still, not charged.

  

Rule

Excess activation signals preparation is incomplete.

  

Protocol

- Measure readiness by calmness, not excitement
    
- Reduce inputs before execution
    
- Enter action from stillness
    
- Let speed emerge only when required
    

  

Stop Condition

If readiness feels restless or urgent, preparation phase is unfinished.
