Signal

Low emotional amplitude often indicates regulation, not suppression.

  

Rule

Calm states do not need stimulation to be valid.

  

Protocol

- Allow emotional neutrality without interference
    
- Do not chase feeling or intensity
    
- Maintain routine and embodiment
    
- Let emotion return naturally if needed
    

  

Stop Condition

If I provoke emotion to “feel something,” regulation is being mistaken for absence.
