**Confidence Updating**

**Core Idea**

  

Synochi should not treat beliefs about a user or athlete as fixed.

  

Every interpretation exists with some degree of confidence, and that confidence should change as new evidence appears.

  

New information can:

  

- strengthen an existing belief,

- weaken it,

- leave it unchanged,

- reveal that it only applies in certain contexts,

- or overturn it entirely.

  

The purpose of Confidence Updating is to make Synochi **revisable rather than rigid**.

  

**Belief States**

  

A useful progression is:

  

**Possible → Emerging → Probable → High Confidence**

  

These states should reflect accumulated evidence rather than arbitrary certainty.

  

A belief can also move backwards.

  

For example:

  

**High Confidence → Probable → Emerging**

  

if new evidence repeatedly contradicts the previous interpretation.

  

Confidence is therefore dynamic.

  

**Confidence Increases When**

  

Confidence should generally increase when:

  

- the same pattern appears repeatedly,

- multiple independent evidence sources support it,

- the user explicitly confirms the interpretation,

- it appears across relevant contexts,

- predictions based on the belief prove accurate,

- interventions based on the belief produce the expected response,

- contradictory explanations become less plausible.

  

This should draw on [[Evidence Weighting Model]] rather than simply counting observations.

  

**Confidence Decreases When**

  

Confidence should decrease when:

  

- repeated observations contradict the belief,

- expected outcomes fail to occur,

- the user provides credible contradictory information,

- the pattern stops appearing,

- the original evidence is found to be context-specific,

- a stronger competing explanation emerges,

- an intervention based on the belief repeatedly fails.

  

Failure to confirm a hypothesis is itself useful information.

  

**Outcome-Based Updating**

  

The strongest confidence updates often occur when a belief produces a testable prediction.

  

Example:

  

Hypothesis:

  

The athlete is struggling primarily because fatigue is reducing decision speed.

  

Intervention:

  

Reduce decision complexity and provide a narrower tactical objective.

  

Outcome:

  

Performance improves substantially late in rounds.

  

This does not prove the hypothesis absolutely, but it should increase confidence.

  

If the intervention repeatedly produces no improvement, confidence should fall.

  

This connects directly to the [[Outcome-Linked Intervention Learning Loop]].

  

**Context-Specific Confidence**

  

Confidence should not always apply globally.

  

Synochi may have:

  

High confidence that the athlete becomes passive when heavily fatigued.

  

while having:

  

Low confidence that the athlete is generally passive.

  

The system should therefore attach confidence to the **specific claim and context**, not only to the person.

  

This prevents temporary states from becoming permanent identity labels.

  

**Contradiction Handling**

  

Contradictory evidence should trigger investigation rather than automatic replacement.

  

Synochi should ask:

  

- Did the context change?

- Did the athlete develop?

- Was the original inference wrong?

- Are both patterns valid under different conditions?

- Is the contradiction caused by state rather than trait?

  

Confidence should change only after the contradiction is interpreted.

  

**Confidence and Action**

  

Low confidence does not mean Synochi must do nothing.

  

The system can act under uncertainty while representing uncertainty clearly.

  

For example:

  

“One possibility is that your hesitation is coming from uncertainty in the initial exchange. I’m not confident enough to treat that as the main issue yet, but we can test it.”

  

This allows useful intervention without pretending certainty.

  

**Stable Model Protection**

  

High-confidence stable beliefs should require stronger evidence to overturn than weak emerging hypotheses.

  

However, no belief should become permanently protected from revision.

  

The rule is:

  

**More established beliefs require more meaningful contradictory evidence — not immunity from contradiction.**

  

**Learning Cycle**

  

Confidence updating should occur continuously:

  

**Evidence → Interpretation → Confidence → Prediction/Intervention → Outcome → Updated Confidence**

  

This creates a system in which Synochi progressively improves the accuracy of its understanding rather than simply accumulating information.

  

**Principle**

  

**Synochi should know not only what it believes, but how strongly it should believe it — and why.**

  

Confidence should rise and fall in proportion to evidence, context, prediction accuracy, and observed outcomes.
