# Graduated Dosing Protocol

**Definition:** Dose only what is required to open the session. The nervous system does not need maximum intensity to begin meaningful work. Restraint preserves clarity, control, and structure — stronger input is reserved for specific phases.

**Mechanism:**
- Start small → establish coherence → escalate only if needed
- Avoid front-loading intensity that destabilises baseline
