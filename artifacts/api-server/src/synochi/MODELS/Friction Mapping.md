# Friction Mapping

## Definition
Friction Mapping is Synochi’s ability to identify **where energy is being lost** inside the system — mentally, physically, behaviourally — and remove the **smallest high-leverage friction point** first.

This converts:
confusion → diagnosis  
strain → simplicity  
effort → efficiency

---

## Core Law
**Most problems persist because the true friction point is unnamed.**

## Rules
- Don’t “try harder” first — **map friction first**
- Fix the **smallest** friction point with the **largest** behavioural leverage
- One correction per phase (KAIZEN)

## Failure Mode
Effort placed into the wrong location → fatigue + resentment + drift.

---

## Spine Line
**Remove friction. Don’t add force.**
