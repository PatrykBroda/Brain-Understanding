Signal

Irritation arises before overt conflict and functions as an early-warning indicator, not a problem.

  

Rule

Low-level irritation signals misalignment or boundary pressure before conscious reasoning catches up.

  

Protocol

- Notice irritation without acting on it
    
- Identify the source (environment, person, frequency, frame)
    
- Adjust exposure or boundaries quietly
    
- Do not discharge irritation socially
    

  

Stop Condition

If irritation turns into rumination, judgement, or corrective behaviour, the signal was ignored too long.
