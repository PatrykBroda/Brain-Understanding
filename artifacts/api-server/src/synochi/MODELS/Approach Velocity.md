# Approach Velocity (Doppler Lens)

## Definition
Approach Velocity is Synochi’s model for how the nervous system perceives threat/urgency based on whether something feels like it’s **approaching** or **receding**.

Approaching = feels louder, faster, more urgent.  
Receding = feels quieter, safer, less important.

This is a **perceptual distortion**, not always reality.

---

## Core Law
**Perceived urgency increases with approach velocity.**
