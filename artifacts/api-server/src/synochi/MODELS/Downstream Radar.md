## [[Downstream Radar]]

  

Type: [[Consequence Detection Node]]

  

Definition:

A sensing layer that monitors second- and third-order effects after action to detect drift, dependency, and erosion of [[Authorship]] before failure becomes visible.

  

Core Statement:

Optimisation is judged by downstream consequences, not immediate outcomes.

  

What It Monitors:

- [[Dependency Formation]] — user waits vs initiates
    
- [[Recovery Time]] — speed of return to [[Baseline Coherence]] after perturbation
    
- [[Refusal Decay]] — decreasing ability to say [[No]]
    
- [[Latency Creep]] — ease increasing while depth thins
    
- [[Decision Bypass]] — skipped choice points
    

  

Signals (Non-Predictive):

- [[Consequence Direction]] (compounding vs stabilising)
    
- [[Skill Atrophy Indicators]]
    
- [[Authority Drift]]
    
- [[Error Masking]]
    

  

Feedback Loop:

Downstream Radar feeds pressure upstream to adjust:

- [[Resistance]]
    
- [[Narrowing]]
    
- [[Silence]]
    
- [[Withholding]]
    
- [[Scaffolding Withdrawal]]
    

  

Invariant:

Prediction flatters intelligence; consequence preserves wisdom.

  

Failure Modes if Absent:

- [[False Progress]]
    
- [[Silent Skill Decay]]
    
- [[Comfort Trap]]
    
- [[Late Intervention]]
