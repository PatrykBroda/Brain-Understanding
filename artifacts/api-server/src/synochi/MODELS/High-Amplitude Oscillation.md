# High-Amplitude Oscillation

**Definition:** Large but temporary state swings during recalibration. When a new baseline is being installed, the nervous system overshoots — high energy, then low energy — as it tests range and re-stabilises. Oscillation is a sign of adaptation, not instability.

**Mechanism:**
- System is updating threat thresholds and output expectations
- Treat swings as temporary: stabilise inputs, keep standards, avoid identity conclusions
