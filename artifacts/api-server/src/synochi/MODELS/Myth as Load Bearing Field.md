Signal

Certain symbolic structures stabilise behaviour without conscious belief.

  

Rule

Myth is functional when treated as field logic, not narrative identity.

  

Protocol

- Use myth as constraint, not story
    
- Avoid self-identification with archetypes
    
- Let myth govern limits and costs
    
- Discard myth that inflates self-image
    

  

Stop Condition

If myth increases ego, fantasy, or exception-making, it has become corrosive.
