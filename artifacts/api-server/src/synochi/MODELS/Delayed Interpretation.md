Signal

Understanding improves when interpretation is postponed.

  

Rule

Immediate interpretation biases perception.

  

Protocol

- Experience events without labelling
    
- Store impressions temporarily
    
- Revisit only after emotional neutrality returns
    
- Interpret once, briefly, then close
    

  

Stop Condition

If interpretation happens in real time, distortion is likely.
