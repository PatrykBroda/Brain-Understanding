# Gradient Sensing

## Definition
Gradient Sensing is the ability to detect when a situation is steepening **before** it becomes a problem.

It identifies:
- rising irreversibility
- increasing cost
- tightening time constraints
- shrinking options

---

## Core Law
**Anticipation = sensing gradient steepening before collapse.**
