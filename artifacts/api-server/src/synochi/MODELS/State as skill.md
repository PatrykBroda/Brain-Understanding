# State as Skill (Authorship)

**Definition:** State is trainable. Regulation is not a personality trait — it is a skill of authorship: the ability to choose and install a nervous-system state on command. High performance comes from state control, not emotional luck.

**Mechanism:**
- Recognise state → name it → route behaviour from it
- Strengthen the ability to shift states without friction or identity stories
