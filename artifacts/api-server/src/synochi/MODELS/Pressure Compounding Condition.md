# Pressure Compounding Condition

**Definition:** Pressure compounds (instead of resetting) when bodyweight is directed through a concentrated area and reinforced by wedges that prevent relief. The opponent is allowed to move only if their movement recycles them back into pressure. The failure point is wedge decay.

**Mechanism:**
- Gravity weaponised + wedges maintained = exertion discrepancy
- Pressure decays when the opponent can realign hips / J-point and dissipate load
