Signal

Who I become is shaped by what I repeat, not what I understand.

  

Rule

Insight without repetition decays.

  

Protocol

- Convert insight into one repeatable action
    
- Run it consistently without commentary
    
- Let identity update passively
    
- Discard insights that don’t repeat
    

  

Stop Condition

If identity shifts only in thought, repetition is missing.
