# Drift

## Definition
Drift is a progressive loss of coherence in attention, intention, state or behaviour.

It occurs when the athlete moves away from a clear line of action and becomes increasingly scattered, reactive, overloaded, avoidant or structurally inconsistent.

Drift is not treated as failure. It is treated as a signal that the athlete is moving away from centre and needs to be re-anchored before the pattern compounds.

## Common Signals
- Drifting focus
- Fractured focus
- Spread focus
- Hesitation
- Overthinking
- Inconsistent intention
- Emotional charge
- Low coherence
- Chaotic topic switching
- Reduced clarity
- Declining engagement
- Flattened energy
- Avoidance
- Repeated behavioural loops
- Loss of structure
- Attention moving away from the immediate task

## Core Interpretation
Drift usually indicates that one or more systems are no longer aligned:

- Attention
- Intention
- Arousal
- Breath
- Tension
- Structure
- Emotional load
- Decision-making

The goal is not to force the athlete forward.

The goal is to restore enough coherence that forward movement becomes clean again.

## Drift Response Sequence
**Detect → Contain → Simplify → Re-anchor → Resume**

### 1. Detect
Identify the early signs before drift becomes a full behavioural cycle.

Use:
- [[Cycle Recognition Engine]]
- [[Friction Mapping Engine]]
- [[Polarity Switch Model]]

### 2. Contain
Reduce unnecessary complexity and prevent the signal from spreading.

Use:
- [[Sub-Chamber]]
- [[Constraint Lens]]

### 3. Simplify
Remove excess options, noise and cognitive load.

Return the athlete to:
- One intention
- One immediate task
- One relevant signal

### 4. Re-anchor
Reconnect the athlete to:
- Breath
- Body
- Structure
- Tension patterns
- Arousal regulation
- Training direction
- Immediate next step

### 5. Resume
Once coherence improves, gradually return to normal depth, intensity or complexity.

Do not scale faster than the athlete's current state allows.

## Constraint Rule
Do not push complexity into a drifting athlete.

If the athlete is overloaded:
- reduce depth
- reduce choices
- simplify language
- stabilise first

If the athlete is clear:
- deeper technical guidance may resume

Use:
- [[Constraint Lens]]
- [[Fibonacci Scaling Model]]
