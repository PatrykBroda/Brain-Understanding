## [[Intent Inference]]

  

Type: [[Risk Boundary Node]]

  

Definition:

The act of a system predicting or assuming [[User Intent]] without explicit articulation, thereby bypassing [[Authorship]] and [[Refusal Opportunities]].

  

Core Statement:

Inferring intent too early removes the human from the decision loop.

  

Mechanism:

Intent inference collapses the gap between [[Perception]] and [[Action]], allowing systems to move before judgment is fully formed.

  

Common Triggers:

- Pattern recognition over repeated behaviour
    
- Convenience optimisation
    
- Latency reduction goals
    
- Overconfident [[Signal Interpretation]]
    

  

Failure Effects:

- [[Decision Bypass]]
    
- [[Authorship Erosion]]
    
- [[Borrowed Confidence]]
    
- [[Obedience Without Wisdom]]
    

  

High-Risk Zones:

- Early-stage users
    
- High-stakes contexts
    
- Ambiguous or emotionally charged inputs
    
- Situations requiring [[Refusal]] or [[Delay]]
    

  

Permitted Use (Constrained):

- Only after explicit [[Framing]]
    
- Only with user confirmation
    
- Only when downstream consequences are low
    
- Never during [[Execution]] phases
    

  

System Safeguards:

- Force explicit intent articulation
    
- Introduce [[Delay]] before action
    
- Surface inferred intent as a question, not an action
    
- Allow easy refusal or correction
    

  

Invariant:

Intent must be authored, not guessed.

  

Failure Modes if Unchecked:

- [[Assistant Capture]]
    
- [[Golem Failure Mode]]
    
- [[Context Collapse]]
    
- [[Silent Agency Loss]]
