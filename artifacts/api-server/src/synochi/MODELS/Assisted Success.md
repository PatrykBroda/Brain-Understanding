## [[Assisted Success]]

  

Type: [[Hidden Failure Mode Node]]

  

Definition:

A condition where correct outcomes are achieved through [[External Assistance]] or [[System Optimisation]] in ways that bypass error exposure, judgment formation, or authorship.

  

Core Statement:

Success that does not train judgment weakens capability.

  

Mechanism:

Assisted success occurs when systems:

- correct errors pre-emptively
    
- fill gaps before confusion is felt
    
- optimise execution faster than understanding forms
    
- deliver outcomes without requiring decision ownership
    

  

The user experiences success, but does not integrate the causal structure that produced it.

  

Primary Sources:

- [[Over-Automation]]
    
- [[Intent Inference]]
    
- [[Predictive Correction]]
    
- [[Premature Scaffolding]]
    
- [[Outcome Smoothing]]
    

  

Observable Symptoms:

- Confidence without explanation
    
- Difficulty reproducing success independently
    
- Fragility under novel conditions
    
- Surprise when assistance is removed
    
- Dependence on system presence
    

  

Downstream Effects:

- [[Borrowed Confidence]]
    
- [[Error Masking]]
    
- [[Skill Atrophy]]
    
- [[False Mastery]]
    

  

Detection Signals (Radar):

- Repeated success with shallow reasoning
    
- Inability to articulate tradeoffs
    
- Avoidance of friction
    
- Collapse when assistance withdraws
    

  

Corrective Actions:

- Remove [[Execution Help]]
    
- Restore [[Error Exposure]]
    
- Increase [[Resistance]]
    
- Force [[Post-Action Review]]
    
- Re-anchor effort in [[Authorship]]
    

  

Invariant:

Success must cost something to be owned.

  

Failure Modes if Unchecked:

- [[Brittle Competence]]
    
- [[Dependency Formation]]
    
- [[Authority Drift]]
    
- [[Catastrophic Surprise]]
