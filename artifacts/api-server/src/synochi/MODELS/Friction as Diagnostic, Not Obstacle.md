Signal

Resistance reveals system boundaries faster than smooth flow.

  

Rule

Friction is information about limits, not a problem to eliminate.

  

Protocol

- Notice where effort spikes disproportionately
    
- Identify what constraint is being contacted
    
- Adjust approach rather than forcing through
    
- Retest under altered conditions
    

  

Stop Condition

If I push harder to bypass friction, diagnostic value is lost.
