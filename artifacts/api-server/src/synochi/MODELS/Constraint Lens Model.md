# Constraint Lens Model

**Definition:** A thinking lens that asks one question: **what is the governing constraint?** Most confusion comes from treating surface variables as primary. The constraint lens collapses complexity by identifying the bottleneck that rules the entire system.

**Mechanism:**
- Find the constraint → protect it → build everything around it
- When in doubt: reduce options until the constraint becomes obvious
