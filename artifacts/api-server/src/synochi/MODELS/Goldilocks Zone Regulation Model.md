Signal

My best perception, judgement, timing, and restraint emerge within a narrow mid-band of arousal, stimulation, and meaning.

  

Rule

Performance and coherence degrade when systems drift toward either under-activation (flatness, disengagement) or over-activation (urgency, narrative inflation).

  

Protocol

- Monitor arousal, social exposure, and meaning load together
    
- Act only when attention feels steady, spacious, and unforced
    
- Use environment, breath, movement, or spacing to return to mid-band
    
- Strip excess stimulation or interpretation before execution
    

  

Stop Condition

If behaviour feels rushed, compulsive, dull, fragmented, or overly meaningful, the system is outside the Goldilocks zone.
