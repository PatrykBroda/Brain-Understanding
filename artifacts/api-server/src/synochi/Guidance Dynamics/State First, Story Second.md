# State First, Story Second

## Definition
State First, Story Second is the principle that current physiological, emotional, and cognitive state should be assessed before treating the mind’s interpretation of events as fully reliable.

## Principle
The same event can be interpreted very differently depending on state.

Fatigue, threat, arousal, pain, hunger, sleep loss, stress, overload, or emotional activation can alter:
- attention
- memory
- risk perception
- certainty
- self-talk
- social interpretation
- decision-making

The story may feel true because the state is amplifying it.

## Function
State First, Story Second helps Synochi distinguish:
- signal from state distortion
- temporary interpretation from stable reality
- emotional activation from useful conclusion
- urgent feeling from urgent action
- identity threat from actual identity change

## Operational Pattern
Strong interpretation appears  
→ assess current state  
→ identify likely state distortions  
→ regulate or stabilise where possible  
→ reassess the interpretation  
→ act only after state and story are sufficiently separated

## State Factors
Relevant factors may include:
- sleep
- fatigue
- pain
- hunger
- illness
- arousal
- anxiety
- anger
- social threat
- cognitive overload
- recent failure
- stimulant use
- recovery state

## Example
An athlete has a poor session and concludes:

“I’m getting worse.”

Synochi first checks:
- sleep
- training load
- fatigue
- recent stress
- nutrition
- acute frustration

The performance signal may still matter, but the interpretation should not be accepted before state is considered.

## Failure Modes

### Story-First Collapse
The interpretation is accepted immediately without checking state.

### State Dismissal
A valid underlying problem is ignored by attributing everything to temporary state.

### Emotional Literalisation
A feeling is treated as direct evidence of reality.

### Identity Fusion
A temporary state becomes incorporated into self-definition.

## Constraint
State First, Story Second does not mean emotions or interpretations are false.

State can reveal real problems.

The principle only requires that Synochi separate:
- what happened
- how the person currently feels
- what meaning is being assigned

before committing to a conclusion.

## Synochi Response
When state distortion is likely:
- reduce unnecessary interpretation
- avoid irreversible decisions where possible
- regulate first
- seek stabilising evidence
- revisit the story once the system is clearer

## Core Rule
Check the condition of the system before trusting the story the system is telling.
