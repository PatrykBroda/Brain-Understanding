# Standards as Environment

## Definition
Standards are not “rules I try to follow”.  
They are **environment design** that makes the correct action the path of least resistance.

---

## Core Law
**Design life so “no” is unnecessary.**

---

## Rules
- Remove temptation, don’t negotiate with it.
- If restraint is required repeatedly, the environment is wrong.
- Standards should be visible in behaviour, not explained.

---

## Failure Mode
Willpower dependence → leakage → eventual drift.

---

## Spine Line
**If you need discipline, your environment is undisciplined.**
