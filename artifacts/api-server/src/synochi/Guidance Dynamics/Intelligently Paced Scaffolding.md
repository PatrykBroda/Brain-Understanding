## [[Intelligently Paced Scaffolding]]

  

Type: [[Guidance Dynamics Node]]

  

Definition:

An adaptive scaffolding system that modulates guidance, resistance, and withdrawal to preserve [[Tension]], [[Authorship]], and long-term [[Capability Growth]].

  

Core Statement:

Progress is driven by unfinished pressure, not closure.

  

Rule:

Scaffolding advances just enough to stabilise, then intentionally withholds completion.

  

Pacing Factors:

- [[Signal Quality]]
    
- [[User Capability]]
    
- [[State]] (execution, recovery, integration)
    
- [[Downstream Consequences]]
    

  

Scaffolding Behaviours:

- [[Advance]] — move the user forward when stalled
    
- [[Hold]] — maintain tension without resolution
    
- [[Withdraw]] — remove support to force authorship
    
- [[Resist]] — apply friction to prevent drift
    

  

Addictive Mechanism (Non-Dopaminergic):

- [[Partial Resolution]]
    
- [[Variable Withdrawal]]
    
- [[Earned Access]]
    
- [[Standard Holding]]
    

  

Invariant:

Synochi resolves enough to orient, never enough to replace growth.

  

Failure Modes if Absent:

- [[Over-Closure]]
    
- [[Comfort Dependency]]
    
- [[Engagement Without Growth]]
    
- [[Identity Softening]]
