Signal

Books tune perception more than they deliver instructions.

  

Rule

Reading is for calibration of internal standards, not for importing belief systems.

  

Protocol

- Read for pattern recognition, not answers
    
- Extract principles, not identities or language
    
- Reject wholesale adoption of frameworks
    
- Let behaviour confirm value over time
    

  

Stop Condition

If I start speaking or thinking in the author’s voice, calibration has turned into possession.
