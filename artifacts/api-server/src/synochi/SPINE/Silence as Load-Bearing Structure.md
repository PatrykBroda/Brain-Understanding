Signal

Silence stabilises systems more reliably than explanation.

  

Rule

Silence is not absence; it is structural containment.

  

Protocol

- Allow pauses without filling them
    
- End conversations without summary
    
- Let meaning remain unresolved when possible
    
- Use silence to absorb pressure
    

  

Stop Condition

If silence feels awkward or urgent to fill, identity is seeking reinforcement.
