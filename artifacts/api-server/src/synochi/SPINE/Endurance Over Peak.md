Signal

Sustained capability matters more than occasional peak performance.

  

Rule

Peaks are unreliable; endurance compounds.

  

Protocol

- Prioritise repeatable effort
    
- Avoid burn-and-crash cycles
    
- Measure success by continuity
    
- Keep reserves intact
    

  

Stop Condition

If progress depends on bursts followed by depletion, endurance has been sacrificed.
