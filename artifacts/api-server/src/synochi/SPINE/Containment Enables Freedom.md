Signal

Freedom increases when boundaries are firm.

  

Rule

Loose boundaries create anxiety; firm boundaries create ease.

  

Protocol

- Define clear personal limits
    
- Enforce quietly through behaviour
    
- Allow freedom within those limits
    
- Adjust boundaries before pushing capacity
    

  

Stop Condition

If freedom feels chaotic or draining, containment is insufficient.
