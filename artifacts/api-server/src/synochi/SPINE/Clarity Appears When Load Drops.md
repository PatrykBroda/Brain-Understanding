Signal

Clarity arrives naturally when pressure is reduced; it does not need to be forced.

  

Rule

Trying to think clearly under unnecessary load delays clarity.

  

Protocol

- Reduce cognitive and social inputs
    
- Remove urgency artificially added by narrative
    
- Allow the system to settle
    
- Act only after clarity stabilises
    

  

Stop Condition

If I push for clarity while overloaded, confusion will persist.
