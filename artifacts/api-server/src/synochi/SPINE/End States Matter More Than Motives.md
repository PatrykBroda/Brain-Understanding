Signal

Outcomes stabilise systems more than intentions.

  

Rule

Good motives do not correct bad end states.

  

Protocol

- Evaluate actions by resulting state
    
- Adjust behaviour based on outcome
    
- Ignore intent when results are misaligned
    
- Optimise for stability, not justification
    

  

Stop Condition

If I defend intent over outcome, learning has stalled.
