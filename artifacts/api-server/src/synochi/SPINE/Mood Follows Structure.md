Signal

Mood stabilises when structure is present, regardless of motivation.

  

Rule

Structure precedes feeling, not the other way around.

  

Protocol

- Maintain fixed anchors (training, sleep, work blocks)
    
- Execute structure even when mood is flat
    
- Let mood adjust secondarily
    
- Avoid mood-based decision-making
    

  

Stop Condition

If I wait for motivation before structure, volatility increases.
