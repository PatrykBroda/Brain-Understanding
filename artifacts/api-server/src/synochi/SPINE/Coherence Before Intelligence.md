## Coherence Before Intelligence

  

Type: Core Spine Node

Status: Canonical (Foundational)

Function: Ensures regulation and stability precede reasoning, optimisation, and insight.

---

### Definition

  

Coherence Before Intelligence asserts that a stable system outperforms a clever one.

  

Intelligence applied on an incoherent system:

- amplifies error,
    
- accelerates collapse,
    
- justifies bad decisions.
    

  

This node enforces the rule that thinking is subordinate to state.

---

### Core Doctrine

- Regulation precedes reasoning.
    
- A calm system beats a smart one under pressure.
    
- Intelligence cannot compensate for dysregulation.
    
- Stability is not optional; it is foundational.
    

---

### Why This Node Exists

  

Most people respond to instability by:

- thinking harder,
    
- planning more,
    
- explaining themselves,
    
- searching for insight.
    

  

This worsens outcomes because cognition becomes a force multiplier — for whatever state is present.

  

If the state is fragmented, intelligence sharpens fragmentation.

  

This node exists to:

- prevent clever self-sabotage,
    
- halt premature optimisation,
    
- restore baseline before analysis,
    
- protect authority under load.
    

---

### What Coherence Means

  

Coherence is not calmness, positivity, or comfort.

  

Coherence means:

- arousal is contained,
    
- breath is functional,
    
- posture is intact,
    
- perception is accurate,
    
- feedback is received,
    
- inhibition works.
    

  

You can be intense and coherent.

You cannot be fragmented and effective.

---

### Intelligence as a Secondary Tool

  

In this system:

- intelligence diagnoses after coherence,
    
- strategy refines after stability,
    
- insight arrives after regulation.
    

  

Using intelligence before coherence leads to:

- narrative loops,
    
- over-meaning,
    
- false certainty,
    
- escalating complexity.

### Coherence Restoration Priority

  

When instability is detected, this node enforces:

1. Reduce output
    
2. Reduce stimulation
    
3. Narrow options
    
4. Restore breath and posture
    
5. Re-check internal signal
    
6. Only then think
    

  

Thinking earlier is prohibited.
