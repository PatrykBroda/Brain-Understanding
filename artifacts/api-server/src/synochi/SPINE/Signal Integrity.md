# Signal Integrity

**Definition:** The system’s ability to keep truth clean under load. When signal integrity is high, perception stays accurate, decisions stay simple, and action stays aligned. When it drops, noise masquerades as insight — and the nervous system starts reacting to distortion.

**Mechanism:**
- High integrity → fewer thoughts, stronger direction, calmer execution
- Low integrity → scanning, looping, false urgency, “fake problems”
