Signal

Systems that remain stable under load are correct enough.

  

Rule

Elegance, insight, and meaning are secondary to stability.

  

Protocol

- Evaluate decisions by stability produced
    
- Prefer boring stability over clever volatility
    
- Revert to what holds when uncertain
    

  

Stop Condition

If outcomes increase chaos or oscillation, correctness is false.
