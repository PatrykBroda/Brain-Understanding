Signal

Emotion carries force; where it is pointed determines outcome.

  

Rule

Undirected emotion disperses power; directed emotion becomes fuel.

  

Protocol

- Identify the dominant emotional charge
    
- Decide where (if anywhere) it is allowed to express
    
- Contain it until direction is chosen
    
- Use it briefly, then return to baseline
    

  

Stop Condition

If emotion spills without direction, leakage has occurred.
