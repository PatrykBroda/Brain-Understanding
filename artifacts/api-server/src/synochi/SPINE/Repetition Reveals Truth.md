Signal

Patterns only emerge through repetition, not single events.

  

Rule

One-off impressions are insufficient for judgement.

  

Protocol

- Observe behaviour across multiple instances
    
- Delay conclusions until patterns stabilise
    
- Weight consistency over intensity
    
- Adjust boundaries based on recurrence
    

  

Stop Condition

If I react strongly to isolated events, pattern recognition has been bypassed.
