# Protocols get reused, rules get ignored.

**Definition:** Behaviour change comes from repeatable actions, not abstract principles. The nervous system follows what is easy to execute under load. Rules collapse in stress; protocols survive because they are simple, embodied, and already rehearsed.

**Mechanism:**
- Convert every rule into a physical or environmental protocol
- Design for low-friction repetition: same cue → same response
