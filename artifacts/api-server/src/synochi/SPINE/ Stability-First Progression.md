# Stability-First Progression

## Definition
Stability-First Progression is the principle that progression should only occur from a structure that can already hold.

The system does not increase intensity, complexity, speed or exposure faster than the athlete can organise.

Progress is built from stability rather than forced through instability.

## Core Principle
**Stability before expansion.**

Before adding more load, complexity or speed, confirm that the existing structure remains coherent.

If stability is lost, progression slows.

If stability holds, progression can continue.

## Core Logic
**Stabilise → Confirm → Expand → Reassess**

### 1. Stabilise
Establish a usable baseline.

Prioritise:
- Regulation
- Structural control
- Clear direction
- Repeatable execution
- Low unnecessary friction

### 3. Expand
Increase only one meaningful variable at a time where possible.

### 4. Reassess
Every increase creates a new stability test.

If organisation remains intact:
- continue progression

If coherence degrades:
- reduce load
- restore structure
- rebuild from the last stable level

## Failure Pattern
Progression becomes unstable when the athlete repeatedly adds load before the previous layer has consolidated.

This may produce:
- Fragmentation
- Compensatory patterns
- Excess tension
- Poor timing
- Reduced signal quality
- Inconsistent performance

## Relationship to Adaptation
Adaptation requires challenge.

But challenge must remain within a range that the system can organise around.

Too little challenge produces stagnation.

Too much challenge destroys useful structure.

Stability-First Progression therefore seeks the smallest increase capable of producing adaptation without unnecessary collapse.

## Relationship to Coherence
Progress is valid when greater capability emerges without sacrificing coherence.

The goal is not simply:

**More.**

The goal is:

**More capacity while remaining organised.**
