Signal

Pressure clarifies faster than contemplation.

  

Rule

Reflection without constraint generates stories; constraint generates signal.

  

Protocol

- Place ideas into real-world constraints
    
- Observe behaviour under load
    
- Remove reflection if it delays testing
    
- Trust outcomes over interpretation
    

  

Stop Condition

If reflection replaces exposure to pressure, avoidance is active.
