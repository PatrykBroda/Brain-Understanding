# Baseline Protection (Coherence Before Growth)

## Definition
Baseline Protection is the rule that your stable state is the primary asset.  
Progress is allowed only if it does not destabilise baseline coherence.

---

## Core Law
**Coherence is the constraint that permits expansion.**

---

## Rules
- Protect sleep, regulation, nutrition first.
- Train/add only when baseline is intact.
- End sessions early when coherence is present.

---

## Failure Mode
Chasing upgrades → state instability → regression.

---

## Spine Line
**Don’t build on vibration. Build on stillness.**
