**Signal**

Narrative accuracy depends on state quality.

  

**Rule**

Stories written from dysregulated states distort reality.

  

**Protocol**

• Regulate state before interpretation

• Delay storytelling or journalling

• Capture facts only if needed

• Return to narrative once neutral

  

**Stop Condition**

If stories feel urgent or emotionally charged, state is leading.
