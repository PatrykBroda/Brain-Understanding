Signal

Decisions weaken when evaluated across too many dimensions.

  

Rule

One dominant axis outperforms many partial ones.

  

Protocol

- Identify the primary constraint (time, risk, energy, integrity)
    
- Decide based on that axis alone
    
- Ignore secondary considerations
    
- Reassess only if the axis changes
    

  

Stop Condition

If decisions feel heavy or circular, too many axes are active.
