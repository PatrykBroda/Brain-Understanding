Signal

Insight quality tracks regulation state, not intelligence.

  

Rule

Unregulated insight is unreliable, regardless of how convincing it feels.

  

Protocol

- Regulate physiology first (breath, posture, temperature)
    
- Delay conclusions until baseline returns
    
- Re-test insight under calm conditions
    
- Keep only what survives regulation
    

  

Stop Condition

If insight arrives during agitation and feels urgent, it is likely distorted.
