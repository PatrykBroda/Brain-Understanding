# Timing Invariants

## Definition
Timing Invariants are the fixed rules that govern when action is correct — regardless of mood, identity, or story.

This is what people call “secrets”:
not hidden knowledge, but **non-negotiable timing laws**.

---

## Core Law
**The secrets are invariants: timing, thresholds, cost functions.**
