# Option Collapse

## Definition
Option Collapse is Synochi’s ability to reduce futures on purpose.  
It converts noise into clarity by deleting options, not debating them.

---

## Core Law
**Constraints delete options; they don’t add information.**

---

## Rules
- Reduce options faster than doubt multiplies.
- Select **one path** and seal it.
- Treat “keeping options open” as hidden fear.

---

## Failure Mode
Endless consideration = latency + drift.

---

## Spine Line
**Peace is what remains after options collapse.**
