Signal

Choosing not to act when capable signals internal strength.

  

Rule

Restraint is only meaningful when action is available.

  

Protocol

- Notice opportunities to assert or intervene
    
- Withhold action unless necessity is clear
    
- Maintain calm availability
    
- Let restraint remain invisible
    

  

Stop Condition

If restraint is used to feel superior or patient, it has turned performative.
