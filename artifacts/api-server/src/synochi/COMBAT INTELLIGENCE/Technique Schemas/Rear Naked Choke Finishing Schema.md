# Rear Naked Choke Finishing Schema

## Definition

Rear Naked Choke Finishing is a strangulation structure applied from behind the opponent using the attacker's arm around the neck while controlling the opponent's ability to hand fight, rotate or create neck space.

## Primary Objective

Establish deep neck access, remove defensive hand interference and apply bilateral neck compression.

## Core Mechanics

1. Maintain Back Control.
2. Win access beneath the opponent's chin where required.
3. Position the choking arm deeply around the neck.
4. Control or bypass defensive hands.
5. Hide and protect the finishing hand.
6. Connect the arms into a stable finishing structure.
7. Remove space around the neck.
8. Apply progressive compression while maintaining chest-to-back connection.

## Key Principle

**Control creates the choke.**

The finish becomes easier when defensive hand access and rotational freedom have already been reduced.

## Decision Rules

If the opponent protects the neck:

- prioritise hand control and positional dominance

If the chin is tucked:

- improve access rather than forcing the finish through the jaw

If the opponent rotates:

- maintain Back Control before re-entering the choke

If the finishing arm becomes deep:

- protect the hand and close remaining space

## Failure Modes

- sacrificing Back Control to chase the neck
- exposing the finishing hand
- leaving space around the neck
- attempting to force access without controlling the hands
- squeezing from poor alignment

## Gi / No-Gi Distinction

**Gi:** collar chokes may create alternative pathways.

**No-Gi:** the Rear Naked Choke becomes one of the primary finishing structures from Back Control.

## Synochi Read

Rear Naked Choke Finishing is an **access-to-compression sequence**.

**Back control → hand control → neck access → structural closure → finish**
