# Heel Hook Finishing Schema

## Definition

Heel Hook Finishing is a rotational lower-limb submission in which the heel is controlled while the opponent's knee and hip are restricted enough that rotation transfers into the knee.

Because the structures involved are vulnerable, finishing pressure must be applied with exceptional control.

## Primary Objective

Create rotational isolation of the opponent's leg while preventing the hip and knee from freely escaping the imposed rotation.

## Core Mechanics

1. Establish secure leg entanglement.
2. Control the opponent's knee line.
3. Expose and secure the heel.
4. Prevent uncontrolled hip rotation.
5. Maintain connection to the trapped leg.
6. Align the heel-control structure.
7. Apply minimal progressive rotational pressure.
8. Stop immediately once the finishing threshold is reached.

## Key Principle

**The heel is the handle. The knee is the target of rotational isolation.**

## Decision Rules

If the knee line is escaping:

- restore control before applying rotation

If the opponent begins turning:

- follow the leg safely rather than forcing against uncontrolled movement

If heel exposure is poor:

- improve access before increasing force

If structural control is incomplete:

- do not finish

## Failure Modes

- applying rotation without knee-line control
- uncontrolled torque
- chasing the heel while losing the leg
- allowing the opponent to spin freely
- accelerating the finish unnecessarily

## Gi / No-Gi Distinction

**Gi:** heel hooks are often restricted or prohibited depending on ruleset.

**No-Gi:** heel-hook systems are substantially more common.

## Synochi Read

Heel Hook Finishing is a **rotational isolation schema with narrow safety margins**.

**Knee-line control → heel access → rotational containment → minimal finishing pressure**
