# Headquarters Passing Schema

## Definition

Headquarters is a transitional passing configuration used to reduce the opponent's available guard options while preserving multiple passing routes.

It is not a single pass.

It is a controlled decision state from which the passer can read the opponent's reactions and select an appropriate progression.

## Primary Objective

Restrict the opponent's hip and leg organisation while maintaining enough mobility to transition between passing directions.

## Entry Conditions

Headquarters becomes available when:

- one of the opponent's legs can be isolated or trapped
- the passer can maintain stable posture over the hips
- the opponent cannot freely align both knees toward the passer
- the passer maintains access to more than one passing direction

## Core Mechanics

1. Establish stable control over one leg.
2. Prevent the opponent from freely squaring their hips.
3. Maintain posture and base.
4. Monitor the free leg.
5. Apply directional pressure.
6. Observe the opponent's reaction.
7. Select the passing route created by that reaction.
8. Transition without surrendering control.

## Reaction Logic

If the opponent's knee turns inward:

- knee cut pathways may become available.

If the hips rotate away:

- leg drag pathways may become available.

If the knees collapse together:

- compression-based passing becomes stronger.

If the opponent extends away:

- outside movement becomes easier.

## Key Principle

**Headquarters reduces opponent options while preserving passer options.**

Its value is therefore not the position itself.

Its value is the number of reliable transitions it keeps available.

## Failure Modes

- becoming static
- allowing both knees to square toward the passer
- committing before the opponent's reaction is understood
- losing posture during directional changes
- allowing the trapped leg to recover freely

## Gi / No-Gi Distinction

**Gi:** grip persistence can make the position easier to stabilise.

**No-Gi:** stance, connection and positional pressure become more important because distal grips are less persistent.

## Synochi Read

Headquarters is a **branching decision state**.

Synochi should interpret the position through available transitions rather than as an isolated technique.

The important information is:

**current control → opponent reaction → available branch → selected progression**
