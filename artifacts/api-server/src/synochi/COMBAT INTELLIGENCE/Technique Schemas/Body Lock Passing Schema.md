# Body Lock Passing Schema

## Function
A reusable coaching schema for recognising, diagnosing, and improving body lock passing.

This node should help FRAME decide:

- whether the body lock is actually stable
- which part of the connection is failing
- whether the athlete should keep progressing or first rebuild control
- what cue is most useful in the moment
- which drill best targets the observed failure

The purpose is not to explain body lock passing generally.

The purpose is to help FRAME intervene intelligently.

## Starting Conditions
Body lock passing becomes viable when:

- the passer has closed distance safely
- the opponent’s torso or waist can be meaningfully connected to
- the passer has enough head and chest position to limit rotation
- the bottom athlete cannot freely extend away or rebuild strong frames
- the passer can begin controlling the opponent’s hips while staying balanced

FRAME should not recommend body lock passing simply because the passer is close.

The connection must already be useful.

## Core Sequence
A reliable body lock progression usually follows this logic:

1. close distance
2. connect around the torso or hips
3. establish head position
4. reduce shoulder and hip rotation
5. neutralise hooks or knee position
6. advance the hips
7. clear the legs progressively
8. stabilise chest-to-chest top control

The exact grip may vary.

The controlling relationship matters more than one fixed hand configuration.

## Primary Mechanical Priorities

### Chest Connection
The passer should maintain close upper-body contact.

If the torso connection becomes loose, the bottom athlete gains access to:

- frames
- rotation
- underhooks
- hook recovery
- distance creation

FRAME should treat loss of chest connection as a primary failure, not a secondary detail.

### Head Position
Head position helps control the opponent’s upper-body direction.

FRAME should look for whether the passer’s head is:

- reinforcing chest pressure
- blocking rotation
- preventing the opponent from turning inward
- helping steer the shoulders

Poor head position often explains why an otherwise strong body lock feels weak.

### Hip Proximity
The passer’s hips should remain close enough to limit the bottom athlete’s lower-body freedom.

If the upper body is connected but the hips drift away, the opponent may still:

- insert hooks
- extend the knees
- create elevation
- rebuild guard

### Progressive Leg Clearance
The passer should clear defensive structures one layer at a time.

FRAME should distinguish between:

- body lock established
- hooks neutralised
- knee line cleared
- pass completed

This allows better diagnosis of where progression stopped.

## Decision Branches

### Opponent Establishes Strong Frames
FRAME should prioritise re-closing distance.

Possible intervention:

- improve head position
- reconnect chest pressure
- remove the frame before trying to pass further

Do not cue leg clearance while the upper-body connection is already broken.

### Opponent Inserts Butterfly Hooks
FRAME should assess whether the passer still controls the torso strongly enough to continue.

Useful responses may involve:

- flattening the hook
- changing hip angle
- widening base
- controlling elevation before progressing

### Opponent Turns Onto a Side
This may create:

- easier hip access
- back exposure
- underhook battles
- alternate passing angles

FRAME should treat the turn as information, not automatically as a failed pass.

### Opponent Recovers Knee Inside
This usually indicates that hip distance or lower-body control has weakened.

Useful coaching preference:
restore hip connection before trying to advance again.

### Passer Gets Stuck in Half Guard
FRAME should recognise that the body lock has already done part of its job.

The problem has shifted.

Intervention should now focus on:

- upper-body consolidation
- freeing the trapped leg
- preventing the bottom athlete rebuilding structure

## Failure Diagnosis

### Failure Pattern: Athlete Gets Close but Cannot Progress
Likely causes:

- chest connection is shallow
- hips are too far away
- head position is not controlling direction
- the opponent still has active hooks

Useful coaching preference:
improve control before trying to move around the guard.

### Failure Pattern: Opponent Keeps Turning In
Likely causes:

- weak head position
- loose shoulder control
- insufficient chest connection

Useful coaching preference:
fix upper-body directional control.

### Failure Pattern: Opponent Keeps Recovering Hooks
Likely causes:

- hips too far away
- lower-body progression too passive
- passer focusing only on the arms

Useful coaching preference:
close the hip gap.

### Failure Pattern: Passer Gets Elevated
Likely causes:

- base too narrow
- weight too forward
- active butterfly hooks not neutralised

Useful coaching preference:
stabilise base before progressing.

### Failure Pattern: Pass Stalls After Reaching Half Guard
Likely causes:

- trapped leg not being addressed
- chest control incomplete
- bottom athlete still has inside frames

Useful coaching preference:
treat it as a completion problem, not an entry problem.

## Coaching Cues
FRAME should prefer short, specific cues such as:

- “Close the hip gap.”
- “Keep your chest connected.”
- “Win the head position first.”
- “Flatten the hook before you move.”
- “Stop them turning into you.”
- “You’ve already passed most of the guard — finish the trapped leg.”

Avoid giving the athlete the whole body lock system unless they ask for it.

## Video Recognition
FRAME should look for:

- arms connected around the torso or hips
- sustained chest-to-body contact
- head position controlling the opponent’s rotation
- hips remaining close
- butterfly hooks being neutralised
- knees being progressively cleared
- transition into half guard or chest-to-chest control

FRAME should avoid labelling every close-range passing exchange as body lock passing.

The defining feature is sustained torso control combined with progressive lower-body clearance.

## Drill Selection Logic

### Connection Failure
Use drills around:
- closing distance
- chest connection
- maintaining the lock against framing

### Head Position Failure
Use drills around:
- blocking rotation
- steering shoulders
- maintaining pressure while the opponent turns

### Hook Management Failure
Use drills around:
- butterfly hook neutralisation
- base adjustment
- hip positioning

### Completion Failure
Use drills around:
- clearing the final knee
- freeing trapped legs
- stabilising chest-to-chest control

### Reaction Failure
Use progressive resistance where the defender alternates between:
- framing
- inserting hooks
- turning inward
- recovering a knee
- forcing half guard

The drill should target the athlete’s actual breakdown point.

## Coaching Preference
FRAME should not prescribe more movement when the athlete’s control structure is already weak.

Prefer:

connection first
→ identify the specific leak
→ apply one correction
→ retest
→ progress only when the structure holds

The system should favour minimal, high-value interventions over technical overload.

## Synochi Interpretation
Body lock passing is a constraint-management problem.

The coaching question is:

Which layer of connection is leaking?

The system should use this schema to distinguish between:

- upper-body connection failure
- rotational control failure
- hip distance failure
- hook-management failure
- completion failure

The useful logic is:

recognise connection state
→ identify the weakest layer
→ correct that layer
→ observe response
→ update coaching preference
