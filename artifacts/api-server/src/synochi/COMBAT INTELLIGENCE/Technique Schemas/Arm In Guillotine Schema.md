# Arm In Guillotine Schema

## Definition

The Arm In Guillotine is a guillotine configuration in which one of the opponent's arms remains inside the choking structure.

Because the shoulder occupies additional space, finishing mechanics differ from a clean neck-only guillotine.

## Primary Objective

Use head control, shoulder positioning and torso compression to close the available space around the neck despite the trapped arm.

## Core Mechanics

1. Secure the opponent's head and included arm.
2. Maintain deep control around the neck.
3. Prevent posture recovery.
4. Compress the opponent's shoulder toward the neck.
5. Control torso orientation.
6. Remove space through body positioning.
7. Maintain connection during defensive movement.
8. Apply progressive finishing pressure.

## Key Principle

**The included arm changes the geometry but does not remove the need for neck compression.**

The shoulder must become part of the finishing structure rather than simply occupying space.

## Decision Rules

If the opponent's shoulder creates excessive space:

- improve body angle before squeezing

If the opponent drives forward:

- maintain head control and adapt hip position

If the arm begins escaping:

- recognise whether the position is transitioning into a standard guillotine

If posture begins recovering:

- restore head control first

## Failure Modes

- treating the finish exactly like a neck-only guillotine
- failing to use the opponent's shoulder structurally
- shallow neck control
- allowing posture recovery
- losing torso connection

## Gi / No-Gi Distinction

The central finishing mechanics remain similar.

**Gi:** clothing can affect friction and hand access.

**No-Gi:** positional compression and body alignment become particularly important.

## Synochi Read

Arm In Guillotine is a **shared-space compression schema**.

The opponent's arm occupies part of the finishing structure and must be integrated rather than ignored.
