# Inside Ashi Ankle Lock Schema

## Definition

Inside Ashi Ankle Lock is a straight ankle lock finishing structure in which the attacker's lower body occupies inside position around the opponent's trapped leg.

The configuration uses internal leg control to restrict movement and preserve access to the foot.

## Primary Objective

Maintain inside lower-body control while isolating the ankle and preventing the opponent from freely withdrawing or rotating the leg.

## Core Mechanics

1. Establish Inside Ashi control.
2. Secure the opponent's knee line.
3. Keep the trapped leg connected to the attacker's hips.
4. Isolate the ankle.
5. Restrict defensive rotation.
6. Align the finishing structure.
7. Preserve the entanglement during resistance.
8. Apply pressure progressively.

## Key Principle

**Inside position around the leg stabilises distal control.**

## Decision Rules

If the opponent turns:

- track the knee and maintain the entanglement

If the knee line begins escaping:

- restore proximal control before attacking the foot

If the ankle becomes exposed:

- secure the finish without sacrificing hip connection

If the opponent changes entanglement state:

- reassess the new position rather than forcing the old finish

## Failure Modes

- controlling the foot while losing the knee
- loose inside-leg connection
- allowing free rotation
- failing to adapt when the entanglement changes
- overcommitting to the finish

## Gi / No-Gi Distinction

**Gi:** trouser grips may assist retention.

**No-Gi:** leg configuration and positional alignment carry most of the control.

## Synochi Read

Inside Ashi Ankle Lock is an **inside-control submission structure**.

**Inside position → knee-line control → ankle isolation → finish**
