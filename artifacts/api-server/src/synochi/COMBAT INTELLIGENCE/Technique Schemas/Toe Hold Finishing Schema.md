# Toe Hold Finishing Schema

## Definition

Toe Hold Finishing is a rotational foot-lock structure in which the attacker controls the opponent's foot and applies combined plantar flexion and rotation while the leg is stabilised.

## Primary Objective

Prevent the opponent's leg from freely rotating while creating controlled rotational pressure through the foot and ankle.

## Core Mechanics

1. Secure the opponent's foot.
2. Establish figure-four hand control.
3. Control the opponent's knee line or hip.
4. Prevent the leg from freely rotating with the foot.
5. Align the foot with the intended rotational direction.
6. Maintain close connection.
7. Apply controlled rotational pressure.
8. Release immediately at the finishing threshold.

## Key Principle

**Foot rotation becomes meaningful only when the rest of the leg cannot freely follow it.**

## Decision Rules

If the opponent's knee rotates with the foot:

- improve leg control before continuing

If grip security deteriorates:

- reset before applying pressure

If the opponent spins:

- maintain positional safety rather than forcing the submission

If the leg becomes stable:

- apply pressure progressively

## Failure Modes

- twisting the foot without controlling the leg
- uncontrolled rotational force
- poor grip positioning
- allowing the knee to follow freely
- continuing after positional control has failed

## Gi / No-Gi Distinction

Ruleset availability varies significantly in both Gi and No-Gi competition.

## Synochi Read

Toe Hold Finishing is a **distal rotation with proximal containment schema**.

**Leg control → foot isolation → rotational restriction → finish**
