# Knee Bar Finishing Schema

## Definition

Knee Bar Finishing is a lower-limb submission that isolates the opponent's leg and applies controlled extension through the knee joint.

The finish depends on stabilising the hip and controlling the leg above and below the knee.

## Primary Objective

Prevent the opponent's hip and knee from rotating freely while applying progressive extension through the leg.

## Core Mechanics

1. Isolate the opponent's leg.
2. Control the knee line.
3. Connect the opponent's thigh to the attacker's body.
4. Secure the lower leg.
5. Prevent hip rotation.
6. Align the knee with the finishing direction.
7. Extend through the hips in a controlled manner.
8. Apply pressure progressively.

## Key Principle

**The knee must be isolated between controlled structures.**

## Decision Rules

If the opponent rotates:

- follow the hip and preserve knee alignment

If the knee begins slipping:

- restore proximal control

If the leg bends or changes angle:

- re-establish alignment before extending

If positional control deteriorates:

- prioritise retention over the finish

## Failure Modes

- attacking below the knee without controlling the thigh
- allowing free hip rotation
- poor knee alignment
- explosive extension
- losing control while chasing the finish

## Gi / No-Gi Distinction

**Gi:** gripping can reinforce leg retention.

**No-Gi:** hip connection and lower-body configuration become more important.

## Synochi Read

Knee Bar Finishing is a **linear joint-isolation schema**.

**Hip control → knee-line isolation → alignment → extension**
