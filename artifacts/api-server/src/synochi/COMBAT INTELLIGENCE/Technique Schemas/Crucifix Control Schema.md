# Crucifix Control Schema

## Definition

Crucifix Control is a dominant control structure that isolates one of the opponent's arms using the legs while controlling the head and upper torso.

The position creates strong asymmetry by reducing the opponent's available defensive limbs.

## Primary Objective

Maintain simultaneous control of the opponent's arm, head and torso while preventing rotational escape.

## Core Mechanics

1. Isolate one arm with the legs.
2. Control the head and upper torso.
3. Prevent the opponent from turning toward the trapped arm.
4. Maintain hip connection.
5. Monitor the free arm.
6. Adjust leg position as the opponent rotates.
7. Preserve control before attacking.
8. Transition if the arm escapes.

## Key Principle

**Crucifix control becomes strong because one defensive limb is removed from the system.**

## Decision Rules

If the trapped arm begins escaping:

- restore leg control before attacking

If the opponent turns toward the attacker:

- maintain head control and follow rotation

If the opponent turns away:

- preserve hip connection and prevent shoulder clearance

If control deteriorates:

- transition rather than forcing the position

## Failure Modes

- attacking while the trapped arm is loose
- losing head control
- allowing the opponent to rotate both shoulders freely
- focusing on one limb while losing torso connection
- failing to transition when control is compromised

## Gi / No-Gi Distinction

**Gi:** collar controls add attacking options.

**No-Gi:** limb isolation and torso connection carry more of the control burden.

## Synochi Read

Crucifix Control is an **asymmetry-amplification state**.

The opponent becomes easier to control because one defensive limb is functionally removed.
