# Single Leg X Entry Schema

## Definition

Single Leg X Entry is the process of gaining inside access to one of the opponent's legs and organising the body into Single Leg X before the opponent can withdraw or square their base.

## Primary Objective

Isolate one leg, connect the opponent's hip to the attacker's lower body and establish a stable off-balancing platform.

## Core Mechanics

1. Create access to one leg.
2. Establish inside position.
3. Insert the hips beneath or beside the opponent's base.
4. Connect to the trapped leg.
5. Position the feet into the Single Leg X structure.
6. Control distance.
7. Prevent the opponent from immediately withdrawing the leg.
8. Begin off-balancing or attack progression.

## Key Principle

**The entry succeeds when access becomes connection.**

## Decision Rules

If the opponent steps away:

- follow the leg before completing the configuration

If the knee line remains distant:

- improve hip position

If inside access is blocked:

- create angle before forcing entry

If the structure stabilises:

- move into off-balancing or attack sequences

## Failure Modes

- reaching for the leg without hip access
- entering too far from the opponent's base
- failing to control distance
- loose leg configuration
- allowing immediate withdrawal

## Gi / No-Gi Distinction

**Gi:** grips can assist entry and retention.

**No-Gi:** timing, hip position and leg connection become more important.

## Synochi Read

Single Leg X Entry is an **access-to-connection transition**.

**Inside access → hip positioning → leg capture → stabilised Single Leg X**
