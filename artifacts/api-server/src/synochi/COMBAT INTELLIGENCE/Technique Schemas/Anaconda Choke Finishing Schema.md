# Anaconda Choke Finishing Schema

## Definition

The Anaconda Choke is a head-and-arm strangulation in which the attacking arm wraps around the opponent's neck and trapped arm before the bodies are repositioned to tighten the finishing structure.

## Primary Objective

Secure the head-and-arm connection and progressively remove space through controlled rotation and body positioning.

## Core Mechanics

1. Establish control around the head and arm.
2. Secure the hand connection.
3. Keep the opponent's head compressed toward the trapped shoulder.
4. Control their ability to posture.
5. Use rotation where necessary to tighten the structure.
6. Maintain connection during the positional change.
7. Remove remaining space.
8. Apply progressive compression.

## Key Principle

**Rotation should tighten an existing structure, not replace one that was never established.**

## Decision Rules

If the initial connection is loose:

- improve control before rolling or rotating

If the opponent follows the rotation:

- preserve chest and head connection

If the trapped shoulder separates from the neck:

- restore compression before finishing

If positional control becomes unstable:

- stabilise before continuing the choke

## Failure Modes

- rolling before securing the structure
- losing head control during rotation
- allowing the trapped arm to withdraw
- creating space while attempting to tighten
- relying on momentum instead of positional closure

## Gi / No-Gi Distinction

**Gi:** fabric can alter friction during rotational transitions.

**No-Gi:** connection must remain particularly precise during movement.

## Synochi Read

Anaconda finishing is a **rotation-assisted compression schema**.

The positional movement is useful only when it reduces available space around an already controlled head-and-arm structure.
