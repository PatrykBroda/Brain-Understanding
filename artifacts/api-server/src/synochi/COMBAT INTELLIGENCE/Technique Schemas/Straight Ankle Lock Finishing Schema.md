# Straight Ankle Lock Finishing Schema

## Definition

Straight Ankle Lock Finishing is a lower-limb submission structure that immobilises the opponent's leg while applying controlled pressure through the ankle and foot.

The finish depends on controlling the leg line and preventing the opponent from freely rotating, retracting or relieving pressure.

## Primary Objective

Create a stable lower-body control structure in which the opponent's ankle is isolated and pressure can be applied without losing positional control.

## Core Mechanics

1. Secure the opponent's leg.
2. Control the knee line.
3. Position the attacking forearm around the ankle.
4. Remove unnecessary space around the foot.
5. Stabilise the opponent's ability to rotate.
6. Align the attacker's hips and torso with the finishing direction.
7. Maintain leg control while extending through the finish.
8. Apply pressure progressively.

## Key Principle

**Control the leg before attacking the ankle.**

## Decision Rules

If the opponent rotates:

- maintain knee-line control and follow the movement

If the foot begins slipping:

- improve ankle connection before increasing pressure

If the opponent retracts the leg:

- restore positional control before continuing

If control is stable:

- apply the finish gradually

## Failure Modes

- attacking the foot without controlling the knee
- leaving space around the ankle
- poor hip alignment
- allowing free rotational escape
- applying force before the leg is stabilised

## Gi / No-Gi Distinction

**Gi:** trouser grips may reinforce leg control.

**No-Gi:** body positioning and leg entanglement become more important.

## Synochi Read

Straight Ankle Lock Finishing is a **distal finish supported by proximal control**.

**Knee-line control → ankle isolation → alignment → progressive pressure**
