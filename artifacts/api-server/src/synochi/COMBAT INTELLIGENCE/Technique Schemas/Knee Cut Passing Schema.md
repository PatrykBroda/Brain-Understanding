# Knee Cut Passing Schema

## Function
A reusable coaching schema for recognising, diagnosing, and improving knee cut passing.

This node should help FRAME decide:

- whether a knee cut is actually available
- what prerequisite is missing when it fails
- what cue to give next
- what reaction should trigger a branch
- what drill would best target the failure

The value of the schema is not describing the knee cut. It is helping FRAME choose the next useful intervention.

## Starting Conditions
The knee cut becomes viable when several conditions are present:

- the passer has meaningful access to one side of the opponent’s hips
- the opponent’s inside knee can be cleared, pinned, redirected, or bypassed
- the passer can begin controlling upper-body rotation
- the passer has enough balance to advance without being elevated or reversed

A knee cut should not be recommended simply because the passer is standing near an open guard.

FRAME should first assess whether the structure for the pass exists.

## Core Sequence
A reliable knee cut usually follows this logic:

1. establish useful passing angle
2. control or clear the inside knee
3. win upper-body control
4. deny the opponent’s ability to turn inward
5. drive the cutting knee across the thigh line
6. maintain chest and hip connection
7. free the trailing leg
8. stabilise top control

The exact grips can vary.

The sequence matters more than one fixed grip configuration.

## Primary Mechanical Priorities

### Upper Body Control
The passer should usually establish a meaningful connection above the hips.

This may involve:

- underhook
- crossface
- head position
- shoulder control
- control of the far arm or torso

If the opponent can freely rotate their shoulders toward the passer, the knee cut becomes unstable.

### Inside Knee Control
The opponent’s inside knee should not remain freely positioned between the bodies.

FRAME should look for whether the passer has:

- stapled it
- redirected it
- collapsed it
- cleared past it

If the knee remains structurally useful, guard recovery remains available.

### Hip Direction
The passer should prevent the opponent from freely rotating the pelvis underneath them.

The pass is stronger when the opponent’s shoulders and hips are prevented from rebuilding alignment.

### Trailing Leg Freedom
The pass is not complete if the trailing leg remains trapped.

FRAME should distinguish between:

- successful upper-body progression
- full pass completion

This prevents false positives in video analysis.

## Decision Branches

### Opponent Maintains Knee Shield
FRAME should not simply cue “drive harder.”

Possible intervention:

- improve upper-body control
- collapse the shield
- change head position
- redirect the hips
- switch passing direction if the shield remains structurally strong

### Opponent Wins Underhook
Risk increases for:

- dogfight
- single leg
- reversal
- wrestle-up

FRAME should prioritise restoring upper-body control before continuing the knee cut.

### Opponent Turns Away
The passer may have access to:

- back exposure
- hip control
- transition into another passing direction

FRAME should recognise this as a reaction opportunity rather than forcing the original finish.

### Opponent Squares Back Up
This usually indicates loss of:

- hip control
- upper-body connection
- knee-line advantage

FRAME should diagnose which layer was lost rather than giving a generic passing cue.

### Trailing Foot Gets Trapped
FRAME should recognise that the pass has progressed but is incomplete.

Intervention should shift from entry mechanics to leg extraction and stabilisation.

## Failure Diagnosis

### Failure Pattern: Knee Gets Across but Opponent Recovers
Likely causes:

- weak upper-body control
- poor hip control
- opponent still able to rotate

Useful coaching preference:
prioritise torso control before more lower-body movement.

### Failure Pattern: Knee Cannot Clear
Likely causes:

- inside knee still structurally strong
- poor passing angle
- weight distribution too passive
- insufficient redirection

Useful coaching preference:
fix the entry rather than forcing the cut.

### Failure Pattern: Athlete Gets Reversed
Likely causes:

- centre of gravity too far forward
- weak base
- opponent controls underhook or elevation

Useful coaching preference:
restore balance and positional control before progression.

### Failure Pattern: Pass Stalls in Half Guard
Likely causes:

- trailing leg trapped
- opponent retains useful frames
- chest-to-chest control incomplete

Useful coaching preference:
treat the problem as a half-guard completion problem rather than restarting the entire pass.

## Coaching Cues
FRAME should prefer short, situation-specific cues such as:

- “Win the upper body before you cut.”
- “Clear the inside knee first.”
- “Stop them turning into you.”
- “Keep your hips connected as the knee crosses.”
- “Your pass is there — free the trailing foot.”
- “You lost the underhook. Fix that before driving.”

Avoid giving multiple cues at once unless the athlete asks for a full breakdown.

## Video Recognition
FRAME should look for:

- cutting knee travelling across the opponent’s thigh
- inside knee being pinned, redirected, or cleared
- underhook or equivalent upper-body control
- passer’s head position
- opponent’s shoulder rotation
- hip alignment
- whether the trailing leg remains trapped
- transition into stable top control

FRAME should avoid labelling every diagonal knee movement as a knee cut.

The surrounding control structure matters.

## Drill Selection Logic
If FRAME detects:

### Entry Failure
Use drills around:
- entering from open guard
- knee-line control
- establishing angle

### Upper Body Failure
Use drills around:
- underhook battles
- head position
- crossface connection
- preventing inward rotation

### Completion Failure
Use drills around:
- freeing the trailing leg
- settling chest-to-chest
- preventing late guard recovery

### Reaction Failure
Use progressive resistance drills where the defender alternates between:
- knee shield
- underhook
- turning away
- squaring back up

The drill should target the athlete’s actual failure pattern rather than the entire technique.

## Coaching Preference
FRAME should favour the simplest intervention that changes the athlete’s outcome.

Do not prescribe a full knee cut rebuild when one missing condition explains the failure.

Prefer:

observe failure
→ identify missing condition
→ give one cue
→ test again
→ update

## Synochi Interpretation
The knee cut should be treated as a conditional sequence rather than a memorised move.

The coaching problem is:

Which prerequisite is missing right now?

The system should use this schema to move from technique recognition into targeted intervention.

The useful logic is:

recognise structure
→ identify failure point
→ select smallest useful correction
→ observe response
→ update coaching preference
