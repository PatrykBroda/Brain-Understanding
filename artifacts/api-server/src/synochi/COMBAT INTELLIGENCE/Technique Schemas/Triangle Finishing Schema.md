# Triangle Finishing Schema

## Definition

Triangle Finishing is a strangulation structure in which the attacker's legs surround the opponent's neck and one arm, using the opponent's shoulder to complete bilateral compression.

## Primary Objective

Align the opponent's neck and trapped shoulder inside a closed leg structure while eliminating unnecessary internal space.

## Core Mechanics

1. Secure the opponent's head and one arm inside the leg configuration.
2. Control posture.
3. Position the trapped shoulder toward the neck.
4. Adjust body angle.
5. Close the leg structure efficiently.
6. Remove internal space.
7. Prevent the opponent from regaining posture or rotating free.
8. Apply progressive finishing pressure.

## Key Principle

**Angle and space removal matter more than simply squeezing the knees together.**

## Decision Rules

If the opponent's shoulder is not entering the neck:

- change angle before increasing pressure

If posture begins recovering:

- restore head control

If excessive space exists inside the triangle:

- tighten the configuration before finishing

If the opponent stacks forward:

- manage angle and position before continuing the finish

## Failure Modes

- remaining square when angle is required
- squeezing with poor leg configuration
- failing to control posture
- allowing the trapped arm to move into a safer position
- attempting to finish with excessive internal space

## Gi / No-Gi Distinction

The underlying strangulation mechanics remain similar.

**Gi:** grips can improve posture control.

**No-Gi:** head control, leg positioning and angle become more mechanically explicit.

## Synochi Read

Triangle Finishing is an **angle-dependent enclosure schema**.

**Posture control → shoulder integration → angle creation → enclosure → compression**
