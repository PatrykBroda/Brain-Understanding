# Mount Control Schema

## Definition

Mount Control is the system used to preserve top positional dominance while adapting to the opponent's attempts to bridge, frame, turn, elbow escape or recover their legs.

Control is maintained through continuous adjustment rather than rigidly holding one configuration.

## Primary Objective

Keep the opponent's hips and shoulders sufficiently controlled that meaningful escape progression cannot accumulate.

## Core Mechanics

1. Maintain alignment above the opponent's torso.
2. Monitor hip and shoulder movement.
3. Adjust base according to the direction of escape force.
4. Remove or neutralise defensive frames.
5. Prevent knee and elbow connection.
6. Follow controlled rotation without surrendering top position.
7. Increase positional control as defensive options decrease.
8. Transition toward attacks when stability permits.

## Key Principle

**Mount is maintained by controlling escape pathways, not by remaining motionless.**

## Decision Rules

If the opponent bridges:

- redistribute base and follow the direction of force

If the opponent turns:

- adapt the mount configuration to the new orientation

If the elbows move toward the hips:

- deny knee-elbow reconnection

If escape movement stops:

- use the stabilised state to increase control or attack

## Failure Modes

- maintaining a fixed base against changing force
- sitting too high or too low without purpose
- allowing knee-elbow connection
- attacking before positional stability exists
- reacting after escape progression has already accumulated

## Gi / No-Gi Distinction

**Gi:** grips may provide additional methods of upper-body immobilisation.

**No-Gi:** weight distribution, wedges and reactive base become proportionally more important.

## Synochi Read

Mount Control is a **dynamic containment system**.

The opponent generates escape vectors.

The top player continuously redistributes control to close those vectors before meaningful progression accumulates.
