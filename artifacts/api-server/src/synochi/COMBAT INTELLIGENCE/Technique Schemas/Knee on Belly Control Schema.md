# Knee on Belly Control Schema

## Definition

Knee on Belly Control is a mobile top-control structure that concentrates pressure through the opponent's torso while preserving rapid transition options.

It combines pinning pressure with directional mobility.

## Primary Objective

Create enough pressure to restrict movement while retaining the ability to follow, attack or transition quickly.

## Core Mechanics

1. Place the knee across the opponent's torso.
2. Maintain a stable post with the opposite leg.
3. Control upper-body orientation.
4. Keep weight directed through the opponent rather than floating above them.
5. Monitor hip and shoulder movement.
6. Adjust knee position as the opponent turns.
7. Preserve transition access to Mount, Side Control or attacks.
8. Avoid becoming overcommitted to the pin.

## Key Principle

**Knee on Belly is a mobile pressure state, not a static pose.**

## Decision Rules

If the opponent turns toward the knee:

- redirect pressure and follow the rotation

If the opponent turns away:

- transition toward Mount or Side Control

If the opponent frames strongly:

- remove or bypass the frame before increasing pressure

If the opponent becomes static:

- use the stabilised state to attack or advance

## Failure Modes

- placing weight on the knee without stable base
- leaning too far forward
- allowing the opponent to turn underneath freely
- sacrificing mobility for pressure
- failing to transition when the position changes

## Gi / No-Gi Distinction

**Gi:** grips can improve torso control.

**No-Gi:** balance and dynamic weight transfer become more important.

## Synochi Read

Knee on Belly Control is a **pressure-mobility hybrid state**.

The value comes from maintaining control without sacrificing transition speed.
