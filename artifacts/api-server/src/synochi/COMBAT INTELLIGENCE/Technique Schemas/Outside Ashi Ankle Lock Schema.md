# Outside Ashi Ankle Lock Schema

## Definition

Outside Ashi Ankle Lock is a straight ankle lock finishing structure applied from an outside-leg entanglement in which the attacker's legs control the opponent's trapped leg from the outside.

## Primary Objective

Use lower-body connection to restrict rotational escape while maintaining reliable access to the ankle.

## Core Mechanics

1. Establish Outside Ashi leg configuration.
2. Control the opponent's knee line.
3. Maintain hip-to-leg connection.
4. Secure the ankle.
5. Prevent uncontrolled rotation.
6. Align the torso with the finishing direction.
7. Maintain lower-body attachment.
8. Apply progressive ankle-lock pressure.

## Key Principle

**The entanglement must stabilise the leg before the finish becomes reliable.**

## Decision Rules

If the opponent rotates:

- preserve knee-line control

If the trapped leg begins slipping:

- restore hip connection

If ankle exposure improves:

- secure the finishing grip without sacrificing control

If the opponent begins clearing the entanglement:

- prioritise leg retention before continuing the submission

## Failure Modes

- loose knee-line control
- insufficient hip connection
- chasing the ankle while losing the entanglement
- uncontrolled rotational pressure
- attempting to finish from poor alignment

## Gi / No-Gi Distinction

**Gi:** gripping options may reinforce leg retention.

**No-Gi:** precise lower-body configuration becomes more important.

## Synochi Read

Outside Ashi Ankle Lock is an **entanglement-to-finish conversion schema**.

**Leg capture → knee-line control → ankle access → finish**
