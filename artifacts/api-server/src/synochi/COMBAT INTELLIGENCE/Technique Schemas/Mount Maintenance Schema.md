# Mount Maintenance Schema

## Definition

Mount Maintenance is the higher-level process through which Mount is preserved across changing defensive states.

Where Mount Control describes immediate control mechanics, Mount Maintenance describes the ongoing adaptation required to remain dominant as the opponent changes escape strategy.

## Primary Objective

Prevent isolated defensive movements from combining into a complete escape sequence.

## Core Mechanics

1. Detect the opponent's current escape direction.
2. Identify which control point is being challenged.
3. Adjust base, pressure or limb positioning.
4. Stop escape progress before it compounds.
5. Restore structural dominance.
6. Allow the opponent's next reaction to reveal the next control requirement.
7. Repeat until attacking opportunities appear.

## Key Principle

**Escape prevention is cheaper than escape recovery.**

A small adjustment made early can prevent a much larger positional correction later.

## Decision Rules

If the opponent begins building an escape:

- address the earliest meaningful progression point

If one escape pathway is closed:

- anticipate transition into another

If control becomes stable:

- increase offensive pressure without sacrificing maintenance

If the opponent creates meaningful space:

- restore positional integrity before attacking

## Failure Modes

- waiting until the escape is nearly complete
- overcommitting to stopping one escape direction
- attacking while positional structure deteriorates
- failing to recognise connected escape sequences
- treating every defensive movement independently

## Gi / No-Gi Distinction

**Gi:** persistent grips may slow escape transitions.

**No-Gi:** defensive movement may occur more quickly, increasing the importance of early recognition.

## Synochi Read

Mount Maintenance is an **escape-progression suppression system**.

The relevant sequence is:

**detect progression → interrupt progression → restore control → observe next direction**

The strongest maintenance occurs before the opponent's escape movements connect into a full pathway.
