# X Guard Passing Schema

## Definition

X Guard Passing is the process of dismantling the opponent's ability to control the passer's base through crossed hook structures underneath the hips.

The passer must restore weight distribution and remove hook influence before attempting positional advancement.

## Primary Objective

Reclaim control of base and leg alignment while progressively reducing the opponent's ability to elevate, rotate or extend the passer.

## Entry Conditions

The schema becomes available when:

- the opponent has established X Guard
- the passer remains capable of maintaining or recovering posture
- individual hooks can be identified
- the opponent's control can be progressively dismantled

## Core Mechanics

1. Stabilise posture.
2. Identify which hook is currently carrying the greatest control.
3. Reduce the opponent's ability to manipulate the base.
4. Remove one controlling structure.
5. Prevent immediate replacement.
6. Restore the trapped leg's alignment.
7. Clear the remaining hooks.
8. Convert directly into passing position.

## Key Principle

**Do not treat both hooks as equally important at every moment.**

Identify the structure currently controlling the system and remove it first.

## Decision Rules

If the opponent begins elevating:

- prioritise base and weight distribution

If one hook becomes weak:

- remove it and immediately occupy the resulting space

If the opponent transitions toward Single Leg X:

- recognise the positional transition and change the passing response

If the legs become disconnected:

- advance before the guard reorganises

## Failure Modes

- attempting to jump over an intact X Guard
- stripping random controls without priority
- allowing removed hooks to return
- leaning into the opponent's strongest elevation direction
- failing to convert escape into passing pressure

## Gi / No-Gi Distinction

**Gi:** trouser and sleeve grips can increase persistence of the guard.

**No-Gi:** hook configuration and positional alignment account for more of the control.

## Synochi Read

X Guard Passing is a **base-restoration problem**.

The guard is effective because it distributes control across the passer's legs and centre.

The passer reverses this process by removing control sequentially.
