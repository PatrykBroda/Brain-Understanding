## Definition

Transition and Positional Change Detection identifies meaningful changes from one combat state to another.

## Core Principle

Many of the most important technical events occur between recognised positions rather than inside static positions.

Video analysis must therefore model transitions explicitly.

## Examples

- Standing → takedown
- Guard → passing engagement
- Half guard → side control
- Side control → mount
- Mount → back exposure
- Turtle → front headlock
- Guard → leg entanglement
- Failed pass → guard recovery
- Submission attempt → positional loss

## Transition Components

A transition may contain:

1. Initial state
2. Trigger
3. Movement or technical action
4. Control change
5. New state
6. Outcome

## Transition Completion

FRAME should distinguish between:

- Attempted transition
- Partial transition
- Completed transition
- Reversed transition
- Interrupted transition

## Positional Stability

A new position should not automatically be considered established the instant it appears.

FRAME should consider whether the athlete has:

- Stabilised their base
- Secured relevant control
- Prevented immediate reversal
- Maintained the state for sufficient time or functional control

## Coaching Relevance

Transition detection enables FRAME to find:

- Where positional losses occur
- How athletes enter dominant positions
- Where scrambles repeatedly emerge
- Whether transitions are controlled or chaotic
- Which stages of an exchange need drilling
