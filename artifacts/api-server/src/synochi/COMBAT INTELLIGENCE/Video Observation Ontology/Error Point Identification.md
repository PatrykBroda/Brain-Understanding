# Error Point Identification

## Type
Video Observation Ontology

## Domain
[[Combat Intelligence Hub]]

## Definition
Error Point Identification is Synochi’s ability to locate the earliest meaningful event that materially increased the probability of an undesirable outcome.

The visible failure is not always the true error.

The true error is often upstream.

## Core Principle
Diagnose from outcome backward until the first meaningful deterioration is found.

**Outcome → preceding transition → control shift → constraint increase → decision point → earliest meaningful error**

## Why It Matters
Combat analysis often over-focuses on the final failure.

Examples:

- submission finished
- guard passed
- takedown completed
- back taken
- mount conceded

But by the time these outcomes occur, the exchange may already be structurally lost.

Synochi should therefore search for the first point where the athlete’s position, control, options, or timing became meaningfully worse.

## Error Point vs Outcome
The outcome is what happened.

The error point is where the probability of that outcome began to rise significantly.

Example:

Outcome:
Athlete gets mounted.

Possible error chain:

inside frame lost  
→ shoulder pinned  
→ hips turned away  
→ knee line cleared  
→ mount established

The useful error point may be frame loss, not mount concession.

## Error Point Classes

### Technical Error
A movement or structure was executed poorly.

Examples:

- elbow flared
- grip misplaced
- head position lost
- base narrowed

### Timing Error
Correct action performed too late or too early.

### Recognition Error
Athlete failed to perceive an emerging threat or opportunity.

### Decision Error
Athlete recognised the situation but selected a lower-value option.

### Sequencing Error
Correct actions were used in the wrong order.

### Constraint Management Error
Athlete allowed multiple restrictions to accumulate before addressing them.

### Strategic Error
Repeated local decisions conflict with the broader tactical objective.

## Earliest Meaningful Error
Synochi should not simply identify the earliest imperfection.

It should identify the earliest event that had meaningful downstream consequence.

A minor technical deviation that changes nothing should not be over-weighted.

The question is:

**Did this event materially alter the future action-space or outcome probability?**

## Error Chains
Many failures emerge through linked errors.

Example:

late grip fight  
→ inside position lost  
→ posture compromised  
→ forced defensive reaction  
→ submission exposure

Synochi should preserve the chain rather than collapsing everything into one diagnosis.

## Primary vs Secondary Error
A primary error initiates meaningful deterioration.

A secondary error occurs after the athlete is already disadvantaged.

Example:

Primary:
failed to deny underhook.

Secondary:
poor bridge after being fully flattened.

The secondary error may still matter, but it should not replace the upstream diagnosis.

## Recoverability
Not every error creates immediate failure.

After an error, Synochi should assess whether recovery remained realistic.

Possible states:

- fully recoverable
- recoverable with narrow window
- highly constrained
- effectively lost

This helps distinguish:

"mistake"

from

"point of no return"

## Repeated Error Pattern
One isolated error may be noise.

Repeated occurrences across footage can reveal a stable pattern.

Examples:

- consistently losing head position
- always reacting after hip line is cleared
- repeatedly posting same-side hand
- conceding inside space during entries

Repeated error points should influence Athlete Model confidence.

## Diagnostic Example
Surface analysis:

"You got caught in the armbar."

Error-point analysis:

"The armbar became likely earlier when your elbow separated during the pass. The submission was the final expression of an upstream positional error."

## Coaching Value
Error Point Identification helps Synochi prescribe training around causes rather than symptoms.

Instead of:

"Work on armbar defence."

Synochi may prescribe:

"Train keeping elbow-knee connection during this passing transition."

This produces more transferable learning.

## Synochi Function
Synochi should identify errors through backward causal tracing:

**Observe outcome → reconstruct transition → detect control changes → detect constraint accumulation → locate decision windows → identify earliest meaningful deterioration → assign confidence**

Error points should remain probabilistic where causality is uncertain.
