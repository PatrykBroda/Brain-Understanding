# Pattern Recurrence Detection

## Type
Video Observation Ontology

## Domain
[[Combat Intelligence Hub]]

## Definition
Pattern Recurrence Detection is Synochi’s ability to recognise when the same meaningful structure, error, opportunity, reaction, or tactical sequence appears repeatedly across one or more combat exchanges.

A repeated event becomes more valuable when Synochi can determine whether it represents a stable pattern rather than isolated noise.

## Core Principle
Do not over-learn from one moment.

**Single event → Repetition → Structural similarity → Pattern confidence → Athlete Model update**

## Why It Matters
One clip can mislead.

Repeated behaviour is more informative.

Examples:

- repeatedly losing inside position on the same side
- consistently reacting late to crossfaces
- repeatedly creating the same back-take pathway
- habitually posting the same hand during scrambles
- repeatedly succeeding from one leg-entanglement entry

These patterns are more useful than isolated successes or failures.

## Pattern Types

### Error Pattern
The same failure mechanism occurs repeatedly.

Example:

frame loss  
→ shoulder flattened  
→ late hip escape

### Success Pattern
A repeatable structure consistently produces good outcomes.

Example:

snapdown  
→ front headlock  
→ go-behind

### Reaction Pattern
The athlete repeatedly responds to a stimulus in the same way.

Example:

opponent pressures forward  
→ athlete always retreats straight back

### Opportunity Pattern
The same useful opening repeatedly appears.

Example:

opponent posts during passing exchanges  
→ underhook becomes available

### Tactical Pattern
Multiple actions form a recurring strategic sequence.

Example:

threaten pass  
→ force knee recovery  
→ attack far-side leg

### Constraint Pattern
The same structural restriction repeatedly causes downstream problems.

Example:

head position lost before every failed takedown defence.

## Structural Similarity
Two events do not need to look visually identical to belong to the same pattern.

Synochi should match deeper structure.

Example:

Different techniques may share the same underlying pattern:

- overcommitted forward weight
- lost base
- forced post
- reversal

The visible techniques differ.

The mechanism is the same.

## Frequency vs Importance
A frequent event is not automatically important.

Synochi should consider:

- frequency
- severity
- downstream consequence
- recoverability
- competitive context
- relevance to athlete goals

A rare catastrophic pattern may deserve more attention than a frequent low-cost imperfection.

## Pattern Confidence
Confidence should increase when:

- the same structure appears repeatedly
- similar triggers produce similar responses
- the pattern appears across different opponents
- outcomes are consistent
- visual confidence is high

Confidence should remain lower when:

- footage is limited
- events are ambiguous
- opponent behaviour differs substantially
- sample size is small

## Context Dependence
Patterns should not be treated as universal traits without context.

Example:

Athlete repeatedly concedes underhooks from bottom half guard.

This does not mean:

"Athlete has poor inside position everywhere."

The pattern should initially remain scoped to the environment in which it was observed.

## Pattern Generalisation
Only after repeated evidence should Synochi widen the pattern.

Possible progression:

Specific:
loses underhook from right-side half guard

Broader:
struggles to maintain inside upper-body position from bottom guard

Generalised:
inside-position recognition may be a recurring defensive constraint

Generalisation should be earned.

## Pattern Break
Synochi should also detect when an established pattern stops occurring.

Example:

Previous footage:
athlete consistently reacts late to knee cuts.

Recent footage:
athlete frames early and recovers guard.

This may indicate adaptation.

Pattern disappearance is evidence too.

## Coaching Value
Pattern Recurrence Detection helps Synochi avoid random technical advice.

Instead of:

"You lost the underhook here."

Synochi can say:

"This is the fourth exchange where you concede the near-side underhook before your guard starts collapsing. That looks like a recurring upstream pattern."

This creates stronger intervention targets.

## Athlete Model Integration
Repeated patterns can update the Athlete Model with:

- strengths
- vulnerabilities
- preferred reactions
- common decision errors
- reliable offensive pathways
- recurring missed windows

Pattern confidence should increase gradually rather than becoming permanent after one session.

## Synochi Function
Synochi should compare observations across time:

**Observe event → Encode structure → Compare with prior events → Detect similarity → Estimate recurrence → Update pattern confidence → Monitor future confirmation or contradiction**

This allows the system to move from clip analysis toward longitudinal combat intelligence.
