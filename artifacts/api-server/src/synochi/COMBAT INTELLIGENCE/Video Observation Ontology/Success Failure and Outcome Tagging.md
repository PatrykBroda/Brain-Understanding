## Definition

Success Failure and Outcome Tagging classifies the functional result of an observed action or exchange.

## Core Principle

Success should be determined relative to the intended objective of the action.

An action can fail technically while still creating a useful secondary outcome.

## Outcome Categories

Possible labels include:

- Successful
- Partially successful
- Failed
- Neutral
- Interrupted
- Reversed
- Countered
- Unclear

## Examples

A takedown may:

- Score cleanly
- Force a scramble
- Create front headlock control
- Fail completely
- Expose the attacker to a counter

These outcomes should not all be treated identically.

## Primary and Secondary Outcomes

FRAME should distinguish:

Primary outcome:
Did the intended action succeed?

Secondary outcome:
What else did the action create?

Example:

A failed arm drag may still create back exposure.

## Delayed Outcomes

Some techniques create advantages that appear several actions later.

FRAME should avoid judging every action solely by the immediate next frame.

## Confidence

Outcome tagging should inherit uncertainty from:

- Occlusion
- Missing footage
- Poor camera angle
- Ambiguous positional state

## Coaching Relevance

Outcome tagging enables:

- Technique success-rate analysis
- Pattern recognition
- Identification of reliable weapons
- Identification of repeated breakdowns
- Better drill prescription
