## Definition

Repeated Pattern Detection identifies recurring behaviours, situations, outcomes or technical tendencies across multiple exchanges.

## Core Principle

Repeated evidence is generally more useful for coaching than a single isolated event.

## Pattern Types

Examples include:

- Repeated guard loss
- Repeated underhook loss
- Same passing direction
- Same successful takedown
- Same failed submission
- Consistent back exposure
- Repeated hesitation
- Persistent head-position loss
- Consistent reaction to pressure
- Repeated success from one control system

## Pattern Requirements

FRAME should consider:

- Number of occurrences
- Similarity between occurrences
- Context
- Opponent variation
- Confidence of each observation

## Avoid Premature Patterns

One occurrence is an observation.

Two may indicate a possible pattern.

Repeated occurrences increase confidence.

FRAME should avoid converting isolated actions into permanent Athlete Model traits.

## Positive Patterns

Pattern detection should identify strengths as well as weaknesses.

Example:

"You repeatedly regain inside position before completing your pass."

## Coaching Relevance

Repeated patterns can influence:

- Athlete Model
- Weekly Mission
- Drill prescription
- Technical priorities
- Competition preparation
- Coaching conversations
