## Definition

Opportunity Recognition identifies moments where a viable technical or tactical option appears available based on the visible state of the exchange.

## Core Principle

FRAME should identify opportunities conservatively.

An option should only be suggested when the required conditions appear to exist.

## Opportunity Types

Examples include:

- Submission opening
- Sweep opportunity
- Guard recovery
- Pass direction
- Back exposure
- Underhook availability
- Front headlock opportunity
- Leg-entry opportunity
- Escape route
- Positional consolidation
- Grip improvement
- Angle change

## Opportunity Window

Opportunities may exist briefly.

FRAME should attempt to identify:

- When the window opens
- What creates it
- Whether the athlete recognises it
- When the window closes

## Missed vs Rejected Opportunity

Not every unused option is a mistake.

An athlete may deliberately choose another strategy.

FRAME should prefer:

"There appears to be an opportunity to..."

rather than:

"You should have..."

unless context strongly supports the judgement.

## Coaching Relevance

Opportunity recognition can produce actionable observations such as:

- "Build a drill around this."
- "Work on recognising this position."
- "Ask FRAME for options from here."
- "This entry appeared several times."
