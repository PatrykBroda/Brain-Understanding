# Recovery Opportunity Detection

## Type
Video Observation Ontology

## Domain
[[Combat Intelligence Hub]]

## Definition
Recovery Opportunity Detection is Synochi’s ability to identify moments where an athlete can meaningfully restore structure, reduce constraint, regain initiative, or return to a more favourable state after deterioration has already begun.

A recovery opportunity is not necessarily a full escape.

It is any viable moment where the athlete can improve the state of the exchange.

## Core Principle
Do not treat disadvantage as binary.

Bad positions often contain temporary recovery windows.

**Deterioration → Recovery window → Restored option-space → Improved state**

## Why It Matters
Combat analysis can become too outcome-focused.

An athlete may lose a position but still have several meaningful chances to recover before the final outcome.

Example:

Crossface conceded  
→ frame reappears  
→ hip space opens  
→ knee can recover  
→ guard can potentially return

If Synochi only tracks the final pass, it misses the athlete’s best recovery moment.

## Recovery Opportunity Components

### Current Constraint State
What is currently limiting the athlete?

Examples:

- flattened shoulders
- trapped knee
- lost inside position
- compromised posture
- isolated limb

### Release Event
What changed to create recovery potential?

Examples:

- opponent posts
- grip loosens
- weight shifts
- head pressure reduces
- knee line reopens
- attachment breaks

### Restorable Structure
What can be recovered?

Examples:

- frame
- base
- posture
- inside position
- hip mobility
- elbow-knee connection
- head position

### Recovery Direction
Where can the athlete realistically move from here?

Examples:

- re-guard
- stand
- turn in
- turn away
- re-pummel
- disengage
- counter-attack

## Recovery Window
Recovery opportunities are often temporary.

The window may close when:

- opponent reconnects control
- weight settles
- second constraint is added
- limb becomes isolated
- angle is lost
- boundary removes movement

Synochi should therefore distinguish:

**recovery available**

from

**recovery still available**

## Partial Recovery
Recovery does not need to restore the original position.

Examples:

Mount → half guard

Back control → turtle

Side control → seated guard

Front headlock → neutral standing

These may still represent successful recovery because the athlete restores meaningful option-space.

## Recovery Hierarchy
A useful recovery sequence may be:

**Survive → Remove immediate threat → Restore structure → Regain movement → Recover position → Regain initiative**

Synochi should not skip stages.

An athlete under a deep submission threat should not be criticised for failing to immediately reverse position.

## Recovery Quality
Synochi should assess whether a recovery action:

- removes the highest-value constraint
- restores multiple options
- only delays deterioration
- creates a counter-threat
- exposes a new vulnerability
- resets the exchange

## Missed Recovery Opportunity
A missed recovery opportunity occurs when:

- the window was meaningfully available
- the athlete had a viable action
- the opportunity disappeared
- no equivalent improvement occurred

This should remain probabilistic where visual evidence is incomplete.

## False Recovery
Some movements appear to improve position but do not restore meaningful control.

Example:

Athlete creates temporary hip space but remains crossfaced, flattened, and unable to recover inside position.

Movement occurred.

Functional recovery did not.

Synochi should judge recovery by restored action-space, not motion alone.

## Recurrent Recovery Pattern
Across repeated footage, Synochi can identify whether an athlete:

- recognises recovery windows early
- waits until constraint accumulates
- recovers structure but not initiative
- repeatedly chooses low-value recovery directions
- excels at creating secondary recovery opportunities

These patterns should inform the Athlete Model.

## Diagnostic Example
Surface analysis:

"You nearly recovered guard."

Recovery-aware analysis:

"When his weight shifted forward, you briefly regained hip movement and your knee line reopened. That was the highest-value recovery window; once his chest reconnected, the opportunity closed."

## Coaching Value
Recovery Opportunity Detection helps Synochi identify:

- where escapes should begin
- which structure should be restored first
- whether the athlete is recognising windows
- whether recovery sequencing is correct
- when a bad position was still salvageable

This makes defensive coaching more precise.

## Synochi Function
Synochi should track recovery dynamically:

**Detect deterioration → monitor constraint release → identify restored option-space → detect viable recovery actions → observe response → evaluate recovery quality → update state**

Over time, Synochi can learn which recovery windows the athlete reliably sees, misses, or converts.
