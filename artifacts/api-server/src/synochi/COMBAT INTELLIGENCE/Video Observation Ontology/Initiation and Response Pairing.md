

[[Combat Intelligence Hub]]

## Definition

Initiation and Response Pairing links an athlete's action with the opponent's immediate response and any subsequent counter-response.

## Core Principle

Combat actions should rarely be analysed in isolation.

Techniques exist inside interaction loops.

## Basic Structure

Initiation → Response → Adjustment → Outcome

Example:

Pass attempt → defensive frame → angle change → pass completion

## Common Pairings

- Shot → sprawl
- Guard pull → passing entry
- Underhook → whizzer
- Knee cut → knee shield
- Arm drag → posture recovery
- Leg entry → leg extraction
- Mount escape → remount
- Submission attempt → defensive hand fighting

## Timing

FRAME should attempt to identify whether the response was:

- Anticipatory
- Immediate
- Delayed
- Absent
- Incorrect
- Successful but incomplete

## Interaction Chains

More complex sequences may continue:

Initiation → Response → Counter → Re-counter

These should remain linked as one interaction chain when possible.

## Coaching Relevance

Pairing actions with responses allows FRAME to understand:

- Whether an athlete anticipates common reactions
- Whether attacks fail because of predictable defences
- Whether follow-up options are available
- Whether the athlete has coherent second and third actions
