## Definition

Position and State Recognition is the process of identifying the current grappling or combat state shown in video.

The goal is not simply to name a position, but to determine the functional state of the exchange at a given moment.

## Core Principle

A position should be classified by the control relationships and available actions it creates, not only by visual appearance.

Two visually similar positions may represent different functional states.

## Common States

Examples include:

- Neutral standing
- Clinch
- Takedown engagement
- Seated guard
- Supine guard
- Open guard
- Closed guard
- Half guard
- Butterfly guard
- Single-leg X
- X guard
- K guard
- Leg entanglement
- Passing position
- Side control
- Knee-on-belly
- Mount
- Back control
- Turtle
- Front headlock
- Scramble
- Submission engagement
- Transitional / unresolved state

## Recognition Requirements

FRAME should attempt to identify:

- Athlete orientation
- Top / bottom relationship
- Hip relationship
- Head position
- Limb configuration
- Grip or connection structure
- Degree of positional stability
- Whether the position is established or transitional

## Transitional States

Not every frame should be forced into a named position.

Examples:

- Guard recovery in progress
- Pass partially completed
- Scramble
- Takedown transition
- Back exposure without established control
- Leg entanglement forming but not secured

These should be labelled as transitional when appropriate.

## Ambiguity Handling

If the position cannot be determined confidently:

- Use the closest broader state
- Reduce confidence
- Avoid inventing specific positional detail
- Preserve multiple plausible interpretations where useful

Example:

"Open guard / leg-entry transition — exact configuration unclear."

## Coaching Relevance

Position recognition allows FRAME to understand:

- Where exchanges begin
- Where athletes repeatedly succeed or fail
- Which positions dominate training or competition footage
- Whether technical actions make sense in context
- How positional transitions occur

## Video Analysis Rule

Position recognition should describe what is visibly supported before attempting to infer why the athlete chose the position.
