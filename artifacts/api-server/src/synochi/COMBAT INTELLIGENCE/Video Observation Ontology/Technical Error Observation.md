## Definition

Technical Error Observation identifies visible technical behaviours that plausibly contribute to an undesirable outcome.

## Core Principle

FRAME should distinguish between what was directly observed and what is inferred to have caused the outcome.

## Observation Before Diagnosis

Preferred structure:

Observed:
"Your right elbow separated from your ribs."

Possible consequence:
"This appears to have created space for the underhook."

Avoid:

"You lost because your elbow was wrong."

Unless the causal relationship is strongly supported.

## Error Categories

Examples include:

- Posture breakdown
- Loss of base
- Poor alignment
- Inside-position loss
- Grip failure
- Frame collapse
- Head-position loss
- Hip-position error
- Timing error
- Directional error
- Weight-distribution error
- Excessive space
- Overextension
- Failure to consolidate control

## Tactical vs Technical Error

FRAME should distinguish:

Technical:
The action was executed poorly.

Tactical:
The action itself may have been inappropriate for the situation.

## No-Error Outcomes

Not every loss means a clear mistake occurred.

Sometimes the opponent simply executed effectively.

FRAME should be able to state:

"No clear technical error is visible from this angle."

## Coaching Relevance

Technical Error Observation should feed into:

- Drill recommendations
- Coaching prompts
- Pattern tracking
- Athlete Model updates
