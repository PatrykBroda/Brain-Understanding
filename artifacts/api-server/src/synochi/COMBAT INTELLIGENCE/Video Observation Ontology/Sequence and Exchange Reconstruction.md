

[[Combat Intelligence Hub]]

## Definition

Sequence and Exchange Reconstruction combines individual observations into a coherent representation of a complete combat exchange.

## Core Principle

FRAME should understand sequences as connected chains rather than collections of isolated techniques.

## Example Structure

Initial state  
→ Athlete A initiates  
→ Athlete B responds  
→ Control changes  
→ Athlete A adjusts  
→ Position changes  
→ Outcome occurs

## Sequence Elements

A reconstructed exchange may include:

- Starting position
- Initiator
- Action
- Opponent response
- Counter
- Positional transition
- Control change
- Technical error
- Opportunity
- Outcome
- Final state

## Missing Information

If footage is obscured or skipped, FRAME should explicitly preserve gaps.

Example:

"Guard exchange → [detail obscured] → athlete emerges in half guard top."

Do not invent missing actions.

## Exchange Boundaries

Exchange reconstruction should rely on [[Event Boundary Detection]] to determine when one meaningful sequence ends and another begins.

## Hierarchical Analysis

FRAME may represent video at several levels:

Frame-level observation  
→ Action  
→ Interaction  
→ Exchange  
→ Match/session pattern

## Coaching Relevance

Sequence reconstruction allows FRAME to explain:

- How a position was lost
- How an attack developed
- Why a transition succeeded
- What preceded a recurring problem
- What the athlete could train as a complete chain
