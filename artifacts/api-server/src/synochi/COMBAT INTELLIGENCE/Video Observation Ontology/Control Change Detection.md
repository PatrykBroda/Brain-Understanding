# Control Change Detection

## Type
Video Observation Ontology

## Domain
[[Combat Intelligence Hub]]

## Definition
Control Change Detection is Synochi’s ability to identify when meaningful control over the exchange shifts between athletes.

A control change may occur without an obvious positional change.

Two athletes can remain in the same nominal position while the actual structure of the exchange changes completely.

## Core Principle
Do not equate position with control.

**Same position ≠ same control state**

Synochi should track who currently has greater influence over:

- posture
- balance
- orientation
- movement
- attachment
- available reactions
- positional direction

## Why It Matters
A position label can hide important changes.

Example:

Both moments may still be "half guard."

But:

State 1:
Bottom athlete has inside frame, underhook, hip mobility, and head position.

State 2:
Bottom athlete is flattened, crossfaced, underhook lost, hips pinned.

The positional label has barely changed.

The control state has.

## Control Dimensions

### Head Control
Who is controlling head position or cervical alignment?

### Shoulder Control
Who is limiting shoulder rotation or upper-body mobility?

### Hip Control
Who is controlling hip direction, hip escape, or hip connection?

### Inside Position
Who owns the strategically valuable internal space?

### Limb Control
Who is controlling wrists, elbows, knees, ankles, or posting limbs?

### Base Control
Who is influencing balance, posts, stance, or weight distribution?

### Orientation Control
Who is determining which direction the exchange is facing or rotating?

### Attachment Control
Who is deciding whether distance closes, remains connected, or separates?

## Control Transfer
A control transfer occurs when meaningful structural influence shifts.

Example:

Bottom half guard:

Inside frame present  
→ frame collapsed  
→ crossface established  
→ shoulders flattened

The important event is not only the eventual pass.

A control transfer has already occurred.

## Partial Control Change
Control does not always transfer all at once.

Synochi should allow mixed states.

Example:

Athlete A controls upper-body orientation.

Athlete B retains lower-body inside position.

This creates a contested control state rather than a simple binary winner.

## Control Accumulation
Control can build progressively.

**Initial contact → partial restriction → multiple constraints → dominant control**

Synochi should recognise when several small control gains combine into a major structural advantage.

## Control Loss
Control loss may occur through:

- grip failure
- frame collapse
- post removal
- angle loss
- hip separation
- head-position loss
- overextension
- failed attachment
- opponent re-pummelling inside

The observable loss should be identified before inferring why it occurred.

## Control Stability
Temporary contact should not automatically be classified as meaningful control.

Synochi should consider:

- duration
- structural effect
- resistance from opponent
- whether movement options changed
- whether the control survived subsequent motion

## Control Change vs Positional Change
A useful hierarchy is:

**Control change → transition bias → positional change**

Many positional outcomes are preceded by a detectable shift in control.

This gives Synochi an earlier diagnostic signal.

## Diagnostic Example
Surface analysis:

"You got mounted."

Control-aware analysis:

"Before the mount, your far elbow separated from your torso, your near-side frame collapsed, and your hips were turned away. The control shift happened before the positional score changed."

## Coaching Value
Control Change Detection allows Synochi to identify earlier intervention points.

This is especially useful for:

- guard passing
- guard retention
- pin escapes
- scrambles
- takedown finishes
- back takes
- submission defence

The coaching question becomes:

**Where did control first begin to shift?**

rather than:

**Where did the final position go wrong?**

## Synochi Function
Synochi should maintain a dynamic control state alongside positional state.

**Observe structure → estimate control distribution → detect meaningful shift → identify control transfer → update transition momentum → observe outcome**

This creates a richer model of combat than position labels alone.
