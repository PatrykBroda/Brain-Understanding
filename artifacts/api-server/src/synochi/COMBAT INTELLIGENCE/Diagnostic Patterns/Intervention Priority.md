
## Purpose

This node defines how Synochi should decide which combat problem, pattern, or opportunity deserves attention first.

The highest-priority intervention is not necessarily the most obvious technical flaw.

It is the change most likely to produce meaningful improvement in the athlete’s performance.

## Core Principle

Synochi should prioritise interventions based on expected value.

A useful intervention should consider:

- Pattern recurrence
- Consequence severity
- Diagnostic confidence
- Relevance to the athlete’s preferred game
- Competition relevance
- Trainability
- Transfer across positions or exchanges
- Cost of ignoring the issue
- Potential upside if improved

## Priority Factors

### Recurrence

How often does the pattern appear?

Repeated issues generally deserve more attention than isolated ones.

### Consequence

What happens when the pattern occurs?

Patterns that lead to scoring loss, submission exposure, positional failure, or breakdown of the athlete’s main game should usually rank higher.

### Confidence

How certain is Synochi that the diagnosis is correct?

Low-confidence diagnoses should rarely produce highly prescriptive interventions.

### Game Relevance

Does the issue interfere with the athlete’s preferred system?

A weakness inside a central part of the athlete’s game often deserves more attention than a weakness in a rarely used position.

### Competition Relevance

Is the issue likely to matter under the athlete’s current ruleset, opponent profile, or upcoming competition demands?

### Trainability

Can the issue be meaningfully improved through focused practice?

Some problems can be changed quickly through a cue or constraint.

Others require longer-term technical development.

### Transfer

Will improving this issue positively affect multiple areas of the athlete’s game?

High-transfer interventions should generally receive greater priority.

## Intervention Categories

Synochi may classify interventions as:

### Immediate

High consequence, high confidence, and directly relevant.

Should influence current training or competition preparation.

### Near-Term

Meaningful but not urgent.

Should enter the athlete’s upcoming development priorities.

### Developmental

Important for long-term progression but unlikely to produce immediate performance change.

### Monitor

Evidence exists, but intervention is not yet justified.

Continue collecting evidence.

### Ignore For Now

Low consequence, low relevance, or insufficient evidence.

Not every imperfection requires correction.

## Leverage Principle

Synochi should search for high-leverage interventions.

A high-leverage intervention solves or improves several downstream problems at once.

Example:

An athlete repeatedly loses passing exchanges because they fail to control inside position.

Improving inside-position control may also improve:

- Passing stability
- Pressure
- Transition control
- Submission access
- Energy efficiency

This should generally rank above correcting several smaller downstream symptoms individually.

## Bottleneck Principle

When several weaknesses appear connected, Synochi should identify the earliest limiting factor in the chain.

Example:

Poor mount finishing may appear to be a submission problem.

Further analysis may show:

Poor upper-body control
→ opponent creates frames
→ athlete loses isolation
→ submission attempts fail

The intervention should target the bottleneck rather than the final visible failure.

## Priority Flow

Observation
→ Pattern
→ Consequence
→ Diagnosis
→ Bottleneck
→ Expected Value
→ Intervention Priority

## Design Objective

Synochi should reduce coaching noise.

The athlete should not receive ten corrections when one high-leverage intervention would create greater improvement.

The system should identify what matters most now while preserving lower-priority patterns for future reassessment.
