
## Purpose

This node defines when an observed combat behaviour should begin to be treated as a meaningful pattern rather than an isolated event.

Synochi should not overreact to single moments.

A pattern becomes useful when recurrence, context, and consequence begin to align.

## Core Principle

Repetition increases confidence, but repetition alone is not enough.

Synochi should consider:

- How often the behaviour occurs
- Whether it appears across multiple sessions
- Whether it appears against different opponents
- Whether it appears in similar positions or contexts
- Whether it leads to meaningful positive or negative outcomes
- Whether the athlete or coach independently reports the same issue

## Isolated Event

An isolated event should usually remain an observation.

Examples:

- One failed takedown
- One missed submission
- One positional escape against an unusually strong opponent
- One technical error during fatigue

Do not convert isolated events into stable athlete traits.

## Emerging Pattern

A behaviour becomes an emerging pattern when:

- It appears more than once
- It occurs in comparable contexts
- It produces a similar outcome
- The explanation remains plausible across examples

Emerging patterns should be tracked but not overstated.

## Established Pattern

A behaviour becomes an established pattern when:

- It repeats across multiple sessions or matches
- It appears against different opponents
- It has consistent tactical or technical consequences
- Multiple evidence sources support it
- Competing explanations have weakened

Established patterns can influence coaching priorities and athlete modelling.

## Pattern Strength

### Weak

Limited recurrence or narrow context.

### Moderate

Repeated enough to influence analysis, but still context-dependent.

### Strong

Repeated across contexts with consistent consequences.

## Context Sensitivity

Synochi should distinguish between:

- Global pattern
- Position-specific pattern
- Opponent-specific pattern
- Ruleset-specific pattern
- Fatigue-related pattern
- Competition-only pattern
- Training-only pattern

A pattern should only generalise as far as the evidence supports.

## Promotion Rule

Observation
→ Repeated Observation
→ Emerging Pattern
→ Established Pattern
→ Athlete Model Update

Pattern promotion should be gradual.

## Demotion Rule

Patterns should weaken when:

- New evidence contradicts them
- The athlete successfully corrects the behaviour
- The behaviour stops recurring
- The original interpretation becomes less likely

Combat Intelligence should allow patterns to decay rather than treating them as permanent truths.

## Design Objective

Synochi should learn an athlete’s game through accumulated evidence while remaining capable of changing its mind.

The goal is adaptive pattern recognition, not static labelling.
