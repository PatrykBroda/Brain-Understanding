
## Purpose

This node defines how Synochi should identify reliable strengths within an athlete’s game.

Combat Intelligence should not only diagnose failure.

It should learn what consistently works, why it works, and how those strengths can be expanded into a more coherent game.

## Core Principle

A strength is not simply a successful technique.

A strength is a repeatable pattern that consistently creates advantageous outcomes.

Synochi should distinguish between:

- One successful action
- An emerging strength
- A reliable strength
- A central game pillar

## Strength Evidence

Synochi should consider:

- Frequency of successful use
- Success across different opponents
- Success under resistance
- Competition transfer
- Positional consistency
- Ability to create follow-up options
- Athlete confidence in the sequence
- Coach-confirmed reliability
- Repeated success across sessions

## Emerging Strength

A behaviour may be considered an emerging strength when:

- It succeeds repeatedly
- The athlete actively returns to it
- It creates useful positions or reactions
- Success is not dependent on one specific opponent

Emerging strengths should be monitored before being treated as core game features.

## Reliable Strength

A behaviour becomes a reliable strength when:

- It performs consistently under resistance
- It succeeds across multiple contexts
- It creates predictable reactions
- The athlete can recover when the first option fails
- It meaningfully contributes to winning exchanges
