
## Purpose

This node defines how Synochi should identify recurring situations where the athlete is close to creating an advantage but does not consistently capitalise on it.

Not every useful diagnostic is a weakness.

Sometimes the athlete is already creating the right conditions but fails to recognise, connect, or exploit the opportunity.

## Core Principle

Synochi should look for repeated moments where the athlete:

- Creates a useful reaction
- Reaches an advantageous position
- Forces predictable defensive behaviour
- Exposes a transition
- Produces a scoring or submission opportunity
- Creates the correct setup but fails to complete the sequence

These moments should be treated differently from fundamental technical failures.

## Opportunity Definition

An opportunity pattern exists when:

1. The athlete repeatedly creates favourable conditions
2. A useful next action is available
3. The athlete does not consistently recognise or exploit it
4. The opportunity is relevant to their existing game

## Examples

### Example 1

Athlete repeatedly forces opponents to post during a sweep attempt.

The sweep fails, but the post creates:

- Arm exposure
- Triangle access
- Wrestle-up opportunity

The problem may not be the sweep itself.

The opportunity may be the predictable reaction it creates.

### Example 2

Athlete reaches front headlock repeatedly but disengages when the opponent builds posture.

Synochi may identify recurring access to:

- Snapdowns
- Go-behinds
- Back exposure
- Secondary takedowns

### Example 3

Athlete passes into half guard repeatedly but immediately attempts to force the pass.

The position may already provide:

- Crossface control
- Underhook access
- Upper-body isolation
- Submission threats

The missed opportunity is not necessarily technical inability.

It may be failure to recognise available progression.

## Opportunity Types

### Technical Opportunity

A specific technique or transition repeatedly becomes available.

### Tactical Opportunity

The opponent repeatedly reacts in a predictable way that can be exploited.

### Positional Opportunity

The athlete consistently reaches a useful position but does not consolidate or progress.

### Submission Opportunity

Submission exposure appears repeatedly without recognition or correct sequencing.

### Reaction Opportunity

One attack reliably creates a defensive response that opens another route.

## Recognition vs Execution

Synochi should distinguish between:

### Recognition Failure

The athlete does not appear to notice the opportunity.

### Decision Failure

The athlete notices it but chooses an inferior option.

### Execution Failure

The correct option is attempted but technically fails.

### Timing Failure

The correct action is selected but the window has already closed.

These should produce different coaching responses.

## Opportunity Value

Synochi should increase the priority of an opportunity when:

- It appears frequently
- It connects naturally to an existing strength
- It requires relatively little additional skill
- It creates major scoring or finishing potential
- Opponents repeatedly produce the same reaction
- It can connect multiple parts of the athlete’s game

## Conversion Principle

Combat Intelligence should ask:

“What is the athlete already creating that could be converted into more value?”

This can often produce faster improvement than introducing an entirely new technique.

## Opportunity Flow

Existing Strength
→ Predictable Reaction
→ Opportunity
→ Recognition
→ Correct Decision
→ Execution
→ Advantage

## Design Objective

Synochi should identify hidden upside within the athlete’s existing game.

The goal is not only to repair what fails.

It is also to recognise where the athlete is already close to greater performance and help convert those moments into reliable advantages.
