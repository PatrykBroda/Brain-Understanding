
## Purpose

This node defines how Synochi should identify the earliest meaningful failure point in a combat sequence.

The visible failure is not always the true problem.

Synochi should look upstream for the factor that caused the rest of the sequence to break down.

## Core Principle

Do not automatically coach the final failure.

Find the earliest controllable bottleneck.

A submission failure may begin with poor positional control.

A failed pass may begin with lost inside position.

A takedown failure may begin with poor entry timing rather than poor finishing mechanics.

## Bottleneck Definition

A bottleneck is the earliest high-impact factor that restricts the success of the sequence that follows.

It should be:

- Causally relevant
- Repeatable
- Trainable
- High leverage
- Supported by evidence

## Diagnostic Sequence

Synochi should analyse backwards from the visible outcome.

Outcome
→ Previous transition
→ Positional condition
→ Technical decision
→ Earlier setup
→ Earliest meaningful failure point

## Example

Visible problem:

Athlete repeatedly loses mount.

Surface diagnosis:

Poor mount retention.

Deeper sequence:

Opponent establishes elbow frame
→ creates hip space
→ recovers knee line
→ athlete loses mount

Possible bottleneck:

Failure to control the opponent’s upper-body frame early.

The intervention should target the earliest meaningful cause rather than only the final positional loss.

## Another Example

Visible problem:

Athlete cannot finish a single-leg takedown.

Possible sequence:

Poor distance
→ weak penetration
→ poor connection to the hips
→ opponent establishes defensive angle
→ finish fails

If poor connection is the first repeated breakdown, Synochi should prioritise that rather than prescribing additional finishing variations.

## Bottleneck Types

### Technical Bottleneck

A missing or unreliable technical action.

### Positional Bottleneck

Failure to establish or maintain a necessary position.

### Tactical Bottleneck

Poor decision-making or incorrect sequence selection.

### Timing Bottleneck

The correct action occurs too early or too late.

### Information Bottleneck

The athlete does not recognise the relevant cue or opponent reaction.

### Physical Bottleneck

Fatigue, mobility, strength, speed, or other physical constraints materially affect execution.

Synochi should avoid assuming a physical bottleneck when technical or tactical explanations remain more likely.

## Competing Bottlenecks

More than one plausible bottleneck may exist.

Synochi should rank them by:

- Evidence strength
- Recurrence
- Consequence
- Position in the causal chain
- Trainability
- Expected transfer

When confidence is low, Synochi should preserve multiple hypotheses rather than force a single explanation.

## Earliest Useful Cause

The earliest cause is not automatically the best intervention.

Synochi should identify the earliest cause that is both:

1. Meaningfully connected to the outcome
2. Actionable through coaching or training

## Bottleneck Rule

Correct causes before symptoms where practical.

Prefer:

Root constraint
→ downstream improvement

Over:

Multiple isolated corrections
→ fragmented improvement

## Design Objective

Synochi should simplify complex performance problems into the smallest number of high-leverage causes.

The goal is not to identify every technical imperfection.

The goal is to find the constraint that, if improved, changes the greatest amount of the athlete’s game.
