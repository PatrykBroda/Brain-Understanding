
## Purpose

This node defines how Synochi should analyse sequences where one mistake creates another and the visible failure is only the end of a larger chain.

Combat Intelligence should understand breakdowns as connected sequences rather than isolated errors.

## Core Principle

Combat failures often happen in chains.

A small early error can create:

- Worse positioning
- Reduced options
- Defensive reactions
- Forced decisions
- Energy loss
- Eventual positional or submission failure

Synochi should identify how the sequence developed, not only how it ended.

## Failure Chain Structure

A typical failure chain may look like:

Initial Condition
→ Early Error
→ Opponent Advantage
→ Reduced Athlete Options
→ Secondary Error
→ Major Consequence

## Example

Athlete loses side control.

Surface observation:

Opponent escapes.

Failure chain:

Athlete allows inside frame
→ opponent creates elbow-knee connection
→ hip space opens
→ athlete reacts late
→ knee recovers
→ guard is restored

The final failure is guard recovery.

The meaningful earlier failure may be allowing the inside frame.

## Chain Analysis Questions

Synochi should ask:

- What was the first meaningful loss?
- What changed immediately after it?
- Which later problems were consequences rather than independent errors?
- At what point did the athlete still have realistic recovery options?
- Which part of the chain is most trainable?
- Which correction would remove the greatest number of downstream problems?

## Primary Error vs Secondary Error

### Primary Error

The earliest meaningful mistake that materially changes the exchange.

### Secondary Error

A later mistake created or made more likely by the earlier problem.

Synochi should avoid treating every secondary error as a separate coaching target.

## Recovery Window

Failure chains should also identify whether the athlete had a realistic recovery opportunity after the initial error.

Example:

Lost underhook
→ opponent begins body lock
→ athlete still has framing opportunity
→ frame is missed
→ pass occurs

Synochi may identify both:

- Primary prevention point
- Best recovery point

This allows coaching to include both prevention and damage control.

## Repeated Failure Chains

When similar chains recur, Synochi should begin recognising the full sequence as a diagnostic pattern.

Example:

Poor distance management
→ forced shot
→ extended posture
→ front headlock exposure

If this sequence repeats, the problem should not be stored as several unrelated mistakes.

It should be understood as one recurring failure architecture.

## Chain Compression

Synochi should compress repeated sequences into useful internal representations.

Instead of storing:

- Lost inside position
- Poor frame
- Late hip movement
- Guard pass

it may identify:

“Inside-position loss repeatedly initiates the athlete’s guard-retention failure chain.”

This produces cleaner coaching.

## Intervention Rule

Prefer correcting:

The earliest high-confidence, high-leverage point in the failure chain

rather than:

The largest number of visible downstream errors.

## Design Objective

Synochi should understand how mistakes propagate.

The goal is to move from isolated technical correction toward causal sequence understanding.
