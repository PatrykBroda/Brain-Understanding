
## Purpose

This node defines how Synochi should judge whether a reaction branch inside a combat system is reliable enough to be trusted.

A branch should not be treated as part of the athlete’s core system simply because it exists technically.

It should earn reliability through evidence.

## Core Principle

A useful branch must be:

- Recognisable
- Repeatable
- Executable under resistance
- Connected to a predictable opponent reaction
- Valuable enough to justify inclusion

## Branch Structure

Trigger
→ Opponent Reaction
→ Athlete Recognition
→ Selected Response
→ Outcome

Synochi should evaluate each stage.

## Reliability Factors

### Reaction Frequency

How often does the opponent reaction actually occur?

A branch built around a rare reaction should carry less weight.

### Recognition Accuracy

Can the athlete reliably recognise the cue that activates the branch?

### Execution Reliability

Can the athlete perform the response under realistic resistance?

### Outcome Quality

Does the branch usually produce a useful result?

### Continuity

Does the branch keep the athlete inside a strong system, or does it create a disconnected technical detour?

## Reliability Levels

### Experimental

The branch is technically plausible but has little real evidence.

### Emerging

The branch has appeared successfully more than once but is not yet dependable.

### Reliable

The athlete recognises and executes the branch consistently under resistance.

### Core

The branch is highly reliable and forms an important part of the athlete’s game architecture.

## Weak Branch Detection

Synochi should identify branches that repeatedly fail because of:

- Late recognition
- Poor timing
- Technical weakness
- Incorrect reaction reading
- Excessive complexity
- Weak connection to the athlete’s strengths

## Branch Pruning

A combat system should not become larger indefinitely.

Synochi should be willing to reduce or remove branches that:

- Rarely appear
- Repeatedly fail
- Create unnecessary decision load
- Duplicate stronger options
- Pull the athlete away from their preferred game

## Branch Reinforcement

A strong branch can be reinforced through:

- Repetition under resistance
- Reaction-specific drilling
- Positional rounds
- Cue recognition training
- Constraint-led practice
- Competition validation

## Decision Load

More branches are not always better.

Each additional branch increases the athlete’s decision burden.

Synochi should prefer the smallest number of reliable branches that cover the highest proportion of realistic opponent reactions.

## System Efficiency

A strong system may look like:

Primary Position
→ 3 common reactions
→ 3 highly reliable responses

rather than:

Primary Position
→ 10 possible reactions
→ 10 poorly developed options

## Design Objective

Synochi should help compress the athlete’s game into high-confidence decision systems.

The goal is not maximum technical choice.

The goal is maximum reliability with minimum unnecessary decision load.
