
## Purpose

This node defines how Synochi should understand what happens after an athlete loses advantage, misses an attack, or enters a compromised position.

Recovery is not simply “escaping.”

It is the process of restoring enough structure, control, or initiative to re-enter a useful part of the athlete’s game.

## Core Principle

Synochi should distinguish between:

- Immediate survival
- Structural recovery
- Positional recovery
- Tactical recovery
- Re-entry into offence

A good recovery sequence should move the athlete from instability toward a familiar and usable state.

## Recovery Structure

Threat or Failure
→ Stabilise
→ Restore Structure
→ Recover Position
→ Rebuild Initiative
→ Re-enter Preferred System

## Recovery State Categories

### Emergency State

Immediate submission, scoring, or positional danger.

Primary goal:

Survive and prevent further deterioration.

### Structural Recovery State

Athlete is still disadvantaged but can rebuild:

- Frames
- Base
- Posture
- Alignment
- Inside position
- Hip mobility

### Positional Recovery State

Athlete has restored enough structure to improve position.

Examples:

- Side control
→ half guard

- Mount
→ elbow-knee escape
→ guard

- Failed shot
→ front headlock defence
→ neutral standing

### Tactical Recovery State

Athlete is no longer in immediate danger but has not yet regained initiative.

The goal becomes:

- Reset
- Reconnect
- Establish preferred grips
- Rebuild pressure
- Create new entry

### Offensive Re-entry

Recovery becomes complete when the athlete can return to a familiar offensive system.

## Recovery Quality

Synochi should assess:

- How quickly structure is restored
- Whether unnecessary risk is avoided
- Whether the athlete chooses an appropriate recovery route
- Whether the recovery connects to an existing game pillar
- Whether initiative can be regained
- Energy cost of the recovery

## Recovery Failure

Synochi should identify repeated patterns such as:

- Panicked movement
- Attempting offence before structure is restored
- Escaping into another bad position
- Repeatedly choosing low-value scramble routes
- Failing to recognise when neutralisation has already been achieved

## Recovery vs Reset

A reset returns the exchange to a neutral or familiar starting state.

A recovery may end before full reset if the athlete reaches a sufficiently strong state.

Example:

Bad scramble
→ half guard top

The athlete may not have returned to the original system, but the recovery is successful because a strong usable state has been restored.

## Recovery Efficiency

High-quality recovery should minimise:

- Positional loss
- Energy waste
- Unnecessary exposure
- Decision chaos
- Time spent in low-value states

## Athlete-Specific Recovery

Synochi should learn the athlete’s most reliable recovery routes.

Examples:

- Wrestle-up recovery
- Guard recovery
- Scramble recovery
- Technical stand-up
- Front headlock re-entry
- Underhook-based reversal

These should influence future coaching and drill prescriptions.

## Recovery Chain

Failure
→ Preserve Escape Route
→ Restore Structure
→ Improve State
→ Recover Initiative
→ Transfer into Game Pillar

## Design Objective

Synochi should understand recovery as a structured process rather than an isolated escape.

The goal is to help the athlete recover intelligently, minimise damage, and return to familiar systems as efficiently as possible.
