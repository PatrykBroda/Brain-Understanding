
## Purpose

This node defines how Synochi should recognise when an opponent changes their behaviour in response to the athlete’s successful actions.

A strong opponent does not remain static.

Synochi should detect when previously reliable reactions begin to change.

## Core Principle

A previously successful pattern may lose value once the opponent adapts.

Synochi should therefore track:

Initial Pattern
→ Athlete Exploitation
→ Opponent Adjustment
→ New Behaviour
→ Tactical Reassessment

## Adaptation Signals

Synochi should look for changes such as:

- Opponent stops giving the same reaction
- Opponent changes stance or posture
- Opponent switches defensive direction
- Opponent begins pre-empting a known attack
- Opponent changes grip strategy
- Opponent disengages earlier
- Opponent alters pace
- Opponent begins countering a repeated entry
- Opponent sacrifices one position to protect another

## Adaptation vs Random Variation

Not every change is meaningful.

Synochi should distinguish between:

### Noise

One unusual response with no recurrence.

### Emerging Adaptation

A new response begins appearing after the athlete repeatedly exploits the old one.

### Confirmed Adaptation

The opponent consistently changes behaviour in the same context.

## Adaptation Trigger

Synochi should ask:

“What caused the opponent to change?”

Possible causes include:

- Repeated punishment
- Better recognition of the athlete’s setup
- Score or time pressure
- Fatigue
- Coaching instruction
- Tactical reset
- Increased risk awareness

## Tactical Response

When adaptation is detected, Synochi should evaluate:

- Is the original option still viable?
- Has a new branch opened?
- Can the athlete disguise the same attack differently?
- Should the athlete transfer to another system?
- Is the opponent now overcorrecting?

## Overcorrection

Adaptation can create new weaknesses.

Example:

Opponent repeatedly gets caught turning away.

They begin aggressively turning inward instead.

That adjustment may now expose:

- Underhooks
- Front headlock
- Sweep direction
- Submission access

Synochi should look for these secondary opportunities.

## Adaptation Loop

Athlete Threat
→ Opponent Reaction
→ Athlete Exploits
→ Opponent Adapts
→ New Reaction
→ Athlete Re-adapts

This loop should be treated as a core part of combat intelligence.

## Adaptation Speed

Synochi should also track how quickly an opponent adapts.

### Slow Adapter

Continues repeating the same response after being punished.

### Moderate Adapter

Changes after several repetitions.

### Fast Adapter

Adjusts after one or two clear exposures.

This can influence how aggressively the athlete should repeat successful patterns.

## Athlete Adaptation

Synochi should also monitor whether the athlete themselves adapts when the opponent changes.

Repeatedly forcing an old branch after the opponent has solved it may indicate tactical rigidity.

## Design Objective

Synochi should understand combat as an evolving interaction.

The goal is not only to detect patterns.

It is to detect when those patterns stop being reliable and help the athlete adapt faster than the opponent.
