
## Purpose

This node defines how Synochi should understand which athlete is currently forcing the other to react.

Initiative is not the same as movement, aggression, or attacking first.

It is the ability to shape the exchange and constrain the opponent’s choices.

## Core Principle

The athlete with initiative is usually the athlete creating the questions the opponent must answer.

Synochi should distinguish between:

- Acting
- Reacting
- Forcing reactions
- Recovering initiative
- Losing initiative

## Initiative Structure

Action
→ Opponent Forced Response
→ Continued Pressure
→ Reduced Opponent Options
→ Athlete Maintains Initiative

## Initiative Indicators

Synochi should look for:

- Opponent repeatedly reacting rather than initiating
- Athlete controlling pace or direction
- Athlete forcing predictable defensive responses
- Athlete connecting attacks without allowing reset
- Opponent abandoning preferred game
- Athlete deciding where the exchange develops
- Opponent spending time recovering structure

## False Initiative

Activity does not automatically equal initiative.

An athlete may appear aggressive while actually reacting to the opponent.

Examples:

- Constantly scrambling from bad positions
- Throwing attacks without controlling reactions
- Moving quickly while opponent dictates position
- Repeatedly defending and countering without establishing their own sequence

Synochi should evaluate who is shaping the exchange.

## Initiative Gain

Initiative may be gained through:

- Strong positional control
- Effective first contact
- Successful off-balancing
- Creating credible threats
- Forcing predictable reactions
- Breaking opponent structure
- Establishing preferred grips or connections
- Winning a transition

## Initiative Loss

Initiative may be lost when:

- Athlete becomes purely reactive
- An attack creates poor position
- Opponent resets the exchange
- Athlete loses connection
- Athlete hesitates at a key decision point
- Defensive pressure forces abandonment of preferred game

## Initiative Recovery

Synochi should identify actions that allow the athlete to regain control of the exchange.

Examples:

Defence
→ frame
→ create space
→ wrestle up
→ initiate attack

or:

Failed attack
→ maintain connection
→ secondary attack
→ force new reaction

## Initiative Chains

Synochi should recognise repeated sequences where initiative is maintained across multiple actions.

Example:

Pressure pass
→ opponent frames
→ redirect
→ opponent turns
→ back exposure
→ control

The important feature is not only technical success.

It is that the opponent never regains meaningful control of the exchange.

## Athlete-Specific Initiative

Different athletes may control initiative differently.

Examples:

- Forward pressure
- Counter-attacking
- Grip fighting
- Pace manipulation
- Positional control
- Threat chaining
- Scramble creation

Synochi should not assume initiative always looks aggressive.

## Tactical Context

Initiative value should account for:

- Score
- Time remaining
- Ruleset
- Position
- Athlete fatigue
- Opponent style
- Competition strategy

Sometimes preserving position is more valuable than forcing continued initiative.

## Design Objective

Synochi should understand who is shaping the fight.

The system should help identify:

- Where the athlete reliably takes initiative
- Where they surrender it
- How they recover it
- Which actions allow them to maintain control of the exchange
