
## **Core Idea**

Combat exchanges should not be understood as isolated techniques.

An attack creates a defensive response.

That defensive response changes position, posture, balance, exposure, and available options.

Those changes create the next offensive opportunity.

The basic cycle is:

**Attack → Defensive Reaction → Positional Change → New Exposure → Re-Attack**

Offence and defence are therefore not separate phases.

They continuously create one another.

## **Why It Matters**

A technique can fail while still improving the attacker’s position.

For example:

- a submission attempt may force an opponent to expose their back,
- a guard pass attempt may force a frame that opens another direction,
- a takedown attempt may create posture or balance reactions that expose a secondary attack.

The value of an attack is therefore not only:

Did it finish?

but also:

What reaction did it force?

## **Defensive Reactions as Information**

Every defensive response reveals something.

Examples include:

- direction of escape,
- preferred frame,
- posture change,
- weight shift,
- limb exposure,
- balance recovery,
- grip commitment,
- turning tendency.

These reactions should be treated as information that shapes the next decision.

## **Chaining**

Effective offence often depends on chaining attacks around predictable defensive reactions.

The structure becomes:

**Threat A → Reaction A → Attack B**

rather than repeatedly forcing Threat A after the opponent has already solved it.

This creates adaptive offence.

## **Defence Creates Offence**

The cycle also works in reverse.

A defensive movement may create an offensive transition.

For example:

- escaping a pin may expose an underhook,
- recovering guard may create a leg-entry opportunity,
- defending a takedown may create front-headlock access,
- defending a submission may reverse positional advantage.

Good defence should therefore not always aim merely to return to neutral.

Where possible, it should transition directly into offence.

## **Positional Continuity**

The important unit is not the individual technique.

It is the **sequence of changing constraints**.

Combat Intelligence should therefore reason about:

- what the current threat forces,
- what reactions are likely,
- what those reactions expose,
- and which next action best exploits the new position.

## **Coaching Implication**

When diagnosing a failed attack, FRAME should not only ask:

Why did the technique fail?

It should also ask:

What reaction did the attack create, and was the athlete prepared to exploit it?

A technically correct attack may still be strategically incomplete if there is no follow-up for the expected defence.

## **Video Analysis Implication**

Video analysis should look beyond isolated success or failure.

A sequence may show:

Athlete attacks → opponent gives predictable reaction → athlete resets instead of exploiting exposure.

The useful observation may therefore be:

The primary issue is not attack selection, but failure to recognise and connect the defensive reaction to the next action.

## **Principle**

**Every attack changes the problem. Every defence creates new information.**

Combat should be understood as a continuous cycle of:

**threat → reaction → adaptation → new threat**

rather than a collection of disconnected techniques.
