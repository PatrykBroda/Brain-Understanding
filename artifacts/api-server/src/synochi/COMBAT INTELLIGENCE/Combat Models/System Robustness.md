
## Purpose

This node defines how Synochi should judge whether a combat system continues to function when the opponent resists intelligently, adapts, denies preferred branches, or creates unfamiliar reactions.

## Core Principle

A strong system should not depend on perfect conditions.

It should remain useful under disruption.

## Robustness Questions

Synochi should ask:

- Does the system work against multiple opponent styles?
- Does it survive common defensive reactions?
- Does it contain reliable fallbacks?
- Can the athlete transfer when a branch dies?
- Does it collapse if the primary entry is denied?
- Can the athlete recover after failure?
- Does it still function under fatigue or competition pressure?

## Robustness Components

### Entry Robustness

Can the athlete access the system through more than one route?

### Branch Robustness

Can the system handle common opponent reactions?

### Recovery Robustness

Can the athlete recover when control breaks down?

### Transfer Robustness

Can the athlete move into another pillar rather than reset completely?

### Adaptation Robustness

Can the system evolve when the opponent changes behaviour?

## Fragile System

A fragile system may:

- Depend on one specific reaction
- Require perfect timing
- Collapse after first defence
- Have no fallback
- Create excessive decision load
- Fail against unfamiliar resistance

## Robust System

A robust system usually has:

- Reliable entry
- Clear primary objective
- Limited high-quality branches
- Strong fallback
- Safe exit
- Transfer route
- Recovery structure

## Stress Testing

Synochi should stress-test systems through:

- Alternative opponent reactions
- Stronger resistance
- Different body types
- Different rulesets
- Fatigue
- Competition footage
- Counterfactual analysis

## System Maturity

### Experimental

Technically plausible but weakly validated.

### Functional

Works reliably in familiar contexts.

### Robust

Works against varied resistance and adapts to disruption.

### Core Competitive System

Highly reliable under realistic competition conditions.

## Design Objective

Synochi should favour combat systems that remain functional when reality becomes messy.

The goal is not a perfect flowchart.

The goal is a game that survives intelligent opposition.
