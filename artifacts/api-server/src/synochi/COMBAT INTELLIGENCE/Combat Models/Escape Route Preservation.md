
## Purpose

This node defines how Synochi should evaluate whether an athlete is preserving viable defensive options while under pressure.

Defence should not be judged only by whether the athlete escapes.

Synochi should also recognise whether the athlete is maintaining the structure and options required to escape later.

## Core Principle

A defensive position becomes more dangerous when available escape routes are progressively removed.

Synochi should track not only:

“What escape is available?”

but also:

“Which escape routes are still alive?”

## Escape Route Definition

An escape route is a realistic path from a disadvantageous state toward:

- Safer structure
- Neutral position
- Guard recovery
- Stand-up
- Reversal
- Scramble
- Disengagement

## Route Preservation

Synochi should recognise actions that preserve future options, including:

- Maintaining frames
- Protecting inside space
- Preventing limb isolation
- Keeping hips mobile
- Preserving elbow-knee connection
- Protecting head position
- Avoiding flattened posture
- Maintaining access to underhooks or posts
- Preventing full upper-body control

## Route Loss

A defensive state becomes more severe when the athlete loses multiple escape routes.

Example:

Bottom side control
→ inside frame removed
→ near elbow isolated
→ hips flattened
→ head controlled
→ guard recovery options collapse

The final escape failure may begin much earlier.

## Route Hierarchy

Synochi should distinguish between:

### Primary Escape Route

The athlete’s most reliable or highest-value path out.

### Secondary Escape Route

A viable alternative if the primary route becomes unavailable.

### Emergency Route

A lower-quality but still useful option to prevent further deterioration.

## Route Denial

Opponent actions should be analysed partly by which defensive routes they remove.

Example:

Crossface
→ reduces head mobility

Underhook
→ reduces turning access

Hip control
→ reduces guard recovery

This allows Synochi to understand control as restriction of options.

## Defensive Priority

When under pressure, Synochi should often prioritise:

Preserve Routes
→ Restore Structure
→ Create Space
→ Initiate Escape
→ Recover State

Attempting an escape after all major routes are already closed may be too late.

## False Escape Attempts

Synochi should identify when an athlete repeatedly attempts an escape that is no longer structurally available.

This may indicate:

- Late recognition
- Poor route selection
- Habitual response
- Failure to detect route closure

## Athlete-Specific Escape Routes

Synochi should learn which defensive routes are most reliable for the specific athlete.

Some athletes may favour:

- Wrestle-ups
- Guard recovery
- Inversions
- Underhook escapes
- Explosive bridges
- Technical stand-ups

A defensive recommendation should account for the athlete’s demonstrated strengths.

## Design Objective

Synochi should understand defence as preservation of future options.

The goal is to recognise when defensive structure is deteriorating before the athlete reaches a point where every escape becomes low probability.
