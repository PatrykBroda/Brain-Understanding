
## Purpose

This node defines how Synochi should understand combat as movement between states rather than as isolated techniques.

A position is not static.

Every exchange contains transitions that improve, worsen, or preserve the athlete’s situation.

## Core Principle

Synochi should evaluate not only:

“What technique happened?”

but also:

“What state did the athlete move from, and what state did they move into?”

## State Structure

Current State
→ Action
→ Opponent Reaction
→ Transition
→ New State

## State Categories

A combat state may be:

### Advantageous

The athlete has meaningful positional, tactical, or finishing advantage.

### Neutral

Neither athlete has a clear advantage.

### Disadvantageous

The opponent has meaningful control, scoring access, or finishing potential.

### Transitional

The exchange is unstable and both athletes still have meaningful access to improvement.

## State Improvement

Synochi should recognise when an action improves the athlete’s state.

Examples:

- Neutral standing
→ successful entry
→ connected takedown position

- Open guard
→ off-balance
→ top position

- Side control
→ isolated arm
→ submission exposure

## State Degradation

Synochi should recognise when the athlete’s position becomes progressively worse.

Example:

Guard
→ inside position lost
→ opponent controls hips
→ pass initiated
→ side control

The final state may be side control, but Synochi should understand the entire degradation process.

## Transitional Windows

Transitions often contain the highest-value opportunities.

Synochi should pay particular attention to:

- Scrambles
- Guard-pass transitions
- Takedown finishes
- Submission escapes
- Stand-up transitions
- Back exposure
- Mount recovery
- Opponent posture changes

These are moments where state can change rapidly.

## Stable vs Unstable States

### Stable State

The athlete has enough control that the position is relatively resistant to immediate change.

### Unstable State

Small actions can significantly change the outcome.

Synochi should distinguish technical mistakes made in stable positions from decisions made during unstable transitions.

## State Preservation

Sometimes the correct action is not progression.

The athlete may need to:

- Consolidate
- Stabilise
- Recover structure
- Prevent reversal
- Reduce immediate risk

Synochi should not reward constant progression when preservation is tactically superior.

## State Value

State value should consider:

- Positional control
- Scoring potential
- Submission potential
- Exposure to danger
- Ability to initiate
- Ability to disengage
- Energy cost
- Ruleset
- Time remaining
- Athlete’s preferred game

## Athlete-Specific State Value

The same position may have different value for different athletes.

Example:

A front headlock may be extremely valuable for an athlete with a strong front-headlock system but less valuable for an athlete who rarely attacks from there.

Synochi should therefore combine general positional value with athlete-specific competence.

## Transition Pattern

Repeated transitions should be tracked.

Example:

Athlete repeatedly moves:

Half guard top
→ knee cut attempt
→ opponent underhook
→ dogfight
→ loss of top position

This should become a meaningful transition pattern rather than four isolated events.

## Design Objective

Synochi should understand how the athlete moves through combat states.

The system should progressively learn:

- Which states the athlete creates well
- Which states they struggle to maintain
- Which transitions they exploit
- Which transitions repeatedly cause breakdowns
- Which states best connect to their preferred game
