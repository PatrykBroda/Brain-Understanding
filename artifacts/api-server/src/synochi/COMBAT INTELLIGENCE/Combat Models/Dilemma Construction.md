
## Purpose

This node defines how Synochi should understand situations where the opponent is forced to choose between two or more responses, each of which exposes a meaningful consequence.

A strong combat system does not only create attacks.

It creates dilemmas.

## Core Principle

A dilemma exists when defending one threat reliably exposes another.

Synochi should identify sequences where:

- The opponent must respond
- The response solves one problem
- The same response creates another problem
- The athlete is prepared to exploit either branch

## Dilemma Structure

Threat A
→ Opponent Response
→ Threat B becomes available

OR

Opponent avoids Threat A
→ Threat A remains available

This creates a constrained decision environment.

## Example

Athlete threatens a front headlock attack.

Opponent raises posture to defend.

That reaction may expose:

- Go-behind
- Re-shot
- Back access

If the opponent stays low, the original front headlock threat remains dangerous.

The value lies in forcing a choice where both branches favour the athlete.

## Dilemma vs Combination

A combination is:

Action A
→ Action B

A dilemma is:

Threat A
→ opponent must choose
→ choice exposes Threat B or preserves Threat A

Synochi should distinguish between pre-planned sequences and reaction-dependent dilemmas.

## Dilemma Quality

A strong dilemma should have:

- Credible first threat
- Predictable defensive reactions
- Reliable secondary option
- Minimal reset between branches
- Strong connection to athlete strengths
- Limited opponent escape routes

## False Dilemma

Synochi should not classify a sequence as a dilemma if:

- The first threat is not credible
- The opponent has several safe alternatives
- The second option depends on a low-probability reaction
- The athlete cannot reliably execute the follow-up

## Dilemma Density

Synochi should identify positions where the athlete has multiple connected threats available.

Higher dilemma density can make a position more valuable because the opponent has fewer clean defensive choices.

Examples:

- Submission plus back exposure
- Sweep plus wrestle-up
- Pass plus submission threat
- Takedown plus front headlock
- Escape denial plus submission isolation

## Dilemma Chains

One dilemma may lead into another.

Threat
→ Reaction
→ Secondary Threat
→ New Reaction
→ Tertiary Threat

Synochi should recognise when an athlete can maintain pressure through multiple linked decision points.

## Athlete-Specific Dilemmas

Synochi should learn which dilemmas the athlete already creates naturally.

It should prioritise building around:

- Existing strengths
- Repeated opponent reactions
- Reliable transitions
- High-confidence positions

The goal is not to force generic systems onto every athlete.

## Coaching Use

When Synochi identifies a weak sequence, it should ask:

- Is the athlete presenting only one threat?
- Can the opponent defend without consequence?
- What second threat naturally punishes the common defence?
- Can the two actions be trained as one decision system?

## Design Objective

Synochi should help transform isolated attacks into connected threat systems.

The goal is to create situations where the opponent’s defensive choices increasingly feed the athlete’s next action.
