
## Purpose

This node defines how Synochi should identify the primary objective of the athlete in a given combat position.

The same action can be good or bad depending on what the athlete is actually trying to achieve from that state.

## Core Principle

Every position should have a hierarchy of useful objectives.

Synochi should evaluate actions against the demands of the current position rather than against generic technical ideals.

## Position Objective Structure

Position
→ Immediate Requirement
→ Primary Objective
→ Secondary Objective
→ Available Progression

## Example

### Bottom Side Control

Immediate requirement:

Prevent submission and further positional deterioration.

Primary objective:

Recover structure and create space.

Secondary objective:

Rebuild frames and establish an escape route.

Progression:

Recover guard, wrestle up, or return to neutral.

A submission attempt from here may be technically possible but strategically low priority.

## Example

### Top Half Guard

Immediate requirement:

Maintain base and prevent underhook-based reversal.

Primary objective:

Control upper body and hips.

Secondary objective:

Flatten opponent or win inside position.

Progression:

Pass, mount, or create submission access.

## Position Objective Categories

Synochi should consider:

- Survival
- Structure recovery
- Stabilisation
- Control
- Escape
- Reversal
- Scoring
- Progression
- Isolation
- Submission
- Disengagement
- Tactical reset

## Objective Conflict

Sometimes multiple objectives compete.

Example:

An athlete in mount may have:

- Strong submission access
- Weak positional stability
- Limited time remaining

Synochi should determine which objective has the highest value in context.

## Objective Misalignment

A decision may be technically valid but positionally misaligned.

Example:

Athlete attacks aggressively while their base is unstable.

The issue is not necessarily the attack itself.

The issue may be that the attack conflicts with the current positional priority.

## Athlete-Specific Objective

Position objectives should adapt to the athlete’s game.

An athlete with a strong leg-lock system may value certain transitional positions differently from an athlete focused on passing and top control.

Synochi should learn which positions function as:

- Destination states
- Transitional states
- Offensive hubs
- Defensive recovery states
- Low-value states

for the specific athlete.

## Ruleset Influence

Position objective should also consider:

- Points
- Advantages
- Submission-only rules
- Time remaining
- Overtime structure
- Penalties
- Boundary position

A good positional objective may change depending on competition context.

## Objective Evaluation

Synochi should ask:

- What does the athlete need first?
- What would improve the state most?
- What risks exist if they progress now?
- What opportunities are available?
- Which objective best matches the athlete’s game?

## Design Objective

Synochi should understand what the athlete is trying to accomplish from each position.

This allows coaching to become more contextual, tactical, and athlete-specific rather than technique-driven.
