
## Purpose

This node defines how Synochi should understand the ways an athlete reliably enters their strongest combat systems.

A powerful system is only useful if the athlete can actually reach it.

## Core Principle

Synochi should distinguish between:

- Knowing a strong system
- Reaching that system reliably

Entry quality determines whether a game pillar is practically usable under resistance.

## Entry Route Definition

An entry route is a repeatable pathway from one combat state into a preferred system.

Examples:

Standing
→ collar tie
→ snapdown
→ front headlock

Open guard
→ off-balance
→ wrestle-up
→ single leg

Top half guard
→ crossface
→ knee cut
→ dominant passing sequence

## Entry Route Categories

### Direct Entry

The athlete reaches the preferred system immediately.

### Reaction Entry

The athlete creates a reaction that exposes the entry.

### Transitional Entry

The system appears during a scramble or positional transition.

### Counter Entry

The opponent initiates and the athlete redirects into a preferred system.

### Recovery Entry

The athlete moves from a defensive or neutral position into a preferred offensive state.

## Entry Reliability

Synochi should evaluate:

- How often the route appears
- Whether it works against resistance
- Whether it depends on a specific opponent behaviour
- Whether the athlete recognises the opening
- Whether the route maintains structural integrity
- Whether it leads directly into a strong game pillar

## Primary Entry Routes

A primary entry route should be:

- Frequent
- Reliable
- Low unnecessary complexity
- Strongly connected to an existing game pillar
- Usable across multiple opponent types

## Secondary Entry Routes

Secondary routes may be less frequent but still valuable when:

- The primary route is denied
- A different ruleset changes the exchange
- The opponent’s style blocks the preferred entry
- The athlete is forced into an unfamiliar position

## Entry Failure

Synochi should identify why entry attempts fail.

Possible causes include:

- Poor distance
- Poor timing
- Weak connection
- Incorrect cue recognition
- Predictable setup
- Technical execution failure
- Strong opponent denial
- Entry chosen from the wrong state

## Entry Chains

A failed entry may still create another useful route.

Example:

Single-leg attempt
→ opponent sprawls
→ front headlock access

This should not automatically be treated as failure if the secondary state connects to another strong pillar.

## Entry Funnel

Synochi should identify whether several different situations can funnel into the same preferred system.

Example:

Snapdown
→ front headlock

Failed shot
→ front headlock

Opponent wrestle-up
→ front headlock

Scramble
→ front headlock

A system with multiple reliable entry routes becomes more strategically valuable.

## Entry Denial

Synochi should also learn how opponents prevent access to the athlete’s preferred systems.

This may include:

- Distance management
- Grip denial
- Posture control
- Angle change
- Early disengagement
- Hand fighting
- Base adjustment

Repeated entry denial should influence future drill and game-planning recommendations.

## Design Objective

Synochi should learn how the athlete reliably reaches their strongest systems.

The goal is not only to identify game pillars.

It is to make those pillars increasingly accessible from real combat situations.
