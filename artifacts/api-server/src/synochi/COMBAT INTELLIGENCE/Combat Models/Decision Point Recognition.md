
## Purpose

This node defines how Synochi should identify the moments in a combat sequence where the athlete has multiple meaningful options and the quality of the decision determines what happens next.

Combat Intelligence should not only recognise techniques.

It should recognise choice points.

## Core Principle

A decision point occurs when:

- More than one viable action is available
- The opponent’s position or reaction changes the best option
- Timing matters
- The athlete’s choice meaningfully affects the next phase of the exchange

Synochi should learn not only what the athlete did, but what they could reasonably have done.

## Decision Point Structure

Situation
→ Available Options
→ Opponent Cues
→ Athlete Choice
→ Outcome
→ Evaluation

## Example

Athlete reaches front headlock.

Opponent posts with the near hand.

Available options may include:

- Snapdown
- Go-behind
- Arm attack
- Re-shot
- Disengage

Synochi should evaluate whether the athlete selected an option that matched the opponent’s reaction and the athlete’s existing strengths.

## Cue Recognition

Useful decision points depend on recognising cues such as:

- Weight shift
- Posture change
- Hand position
- Hip direction
- Base width
- Head position
- Frame placement
- Limb exposure
- Pressure direction
- Opponent retreat or forward drive

Synochi should gradually learn which cues reliably predict useful actions.

## Decision Quality

### Strong Decision

The athlete selects an option that:

- Matches the opponent’s reaction
- Fits the tactical context
- Connects to an existing strength
- Produces a favourable outcome or strong continuation

### Acceptable Decision

The option is reasonable but not clearly optimal.

### Weak Decision

The athlete selects an option that:

- Ignores a strong available cue
- Creates unnecessary risk
- Breaks connection to their preferred game
- Repeatedly leads to poor outcomes

## Decision vs Execution

Synochi should separate:

### Good Decision, Poor Execution

The correct option was selected but technically failed.

### Poor Decision, Good Execution

The athlete succeeded despite choosing a lower-value option.

### Good Decision, Good Execution

The choice and execution were both strong.

### Poor Decision, Poor Execution

Both selection and execution contributed to failure.

This distinction is important for accurate coaching.

## Repeated Decision Patterns

Synochi should identify whether the athlete repeatedly:

- Chooses the same option regardless of opponent reaction
- Misses high-value branches
- Recognises cues late
- Chooses technically difficult options unnecessarily
- Selects options that consistently connect to strengths

Repeated decision patterns should become part of the athlete’s combat profile.

## Decision Compression

When the same situation repeatedly produces the same choice pattern, Synochi may compress it into a useful model.

Example:

“Against defensive posting from front headlock, athlete consistently attempts snapdowns even when go-behind access is stronger.”

This should influence future coaching and drill design.

## Design Objective

Synochi should evolve from recognising actions into understanding tactical choice.

The goal is to help the athlete make better decisions under resistance, not simply accumulate more techniques.
