
## Purpose

This node defines how Synochi should model combat as a sequence of actions and reactions rather than isolated techniques.

A technique gains more value when Synochi understands what it tends to make the opponent do next.

## Core Principle

Combat is interactive.

An athlete acts.

The opponent reacts.

That reaction creates a new decision point.

Synochi should therefore model:

Action
→ Opponent Reaction
→ Available Response
→ New Reaction
→ Continuation

## Reaction Chain

A reaction chain is a repeatable sequence where one action predictably creates another response.

Example:

Arm drag
→ opponent squares up
→ athlete switches to single leg

Or:

Knee cut pressure
→ opponent frames
→ athlete redirects into leg drag

The value is not only in recognising each technique.

The value is in understanding the connection between them.

## Reaction Categories

Synochi should identify common opponent reactions such as:

- Post
- Frame
- Turn away
- Turn in
- Square posture
- Retreat
- Drive forward
- Pull limb free
- Extend
- Contract
- Base wider
- Base narrower
- Stand
- Sit
- Underhook
- Overhook
- Hip escape
- Wrestle up
- Protect neck
- Protect limb

## Forced vs Voluntary Reaction

### Forced Reaction

A response the opponent is strongly compelled to make.

These reactions are especially valuable because they create predictable follow-up opportunities.

### Voluntary Reaction

One of several reasonable choices available to the opponent.

These should be modelled with lower certainty.

## Branching

Synochi should avoid assuming every opponent reacts the same way.

A useful reaction model may contain branches.

Example:

Front headlock pressure
→ opponent posts hand
→ attack arm

OR

Front headlock pressure
→ opponent circles away
→ go behind

OR

Front headlock pressure
→ opponent drives forward
→ snapdown or re-attack

## Athlete-Specific Reaction Chains

Synochi should learn which reactions this athlete reliably produces.

This matters because two athletes may use the same technique but create different opponent behaviour based on:

- Pressure
- Timing
- Body type
- Speed
- Grip preference
- Threat profile
- Technical style

## Reaction Reliability

Synochi should track:

### Low Reliability

Reaction appears occasionally.

### Moderate Reliability

Reaction appears repeatedly in similar contexts.

### High Reliability

The athlete can consistently create the reaction against resisting opponents.

High-reliability reactions can become foundations for game planning.

## Reaction Exploitation

Once Synochi identifies a predictable reaction, it should ask:

- Does the athlete recognise it?
- Do they have a reliable response?
- Does that response connect to an existing strength?
- Is there a stronger continuation available?
- Can the reaction be deliberately created?

## Game Development Principle

Do not only teach more techniques.

Build stronger connections between:

Threat
→ Reaction
→ Answer

A coherent game becomes increasingly predictable for the athlete and increasingly difficult for the opponent.

## Design Objective

Synochi should learn not only what the athlete does, but what their actions cause opponents to do.

This allows Combat Intelligence to evolve from technique recognition into interactive combat reasoning.
