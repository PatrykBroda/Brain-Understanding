
## Purpose

This node defines how Synochi should understand what the athlete should fall back to when a preferred option, branch, or system fails.

A strong combat game should not collapse when Plan A is removed.

It should degrade intelligently.

## Core Principle

Synochi should identify:

- Primary option
- Secondary option
- Tertiary option
- Safe reset

The athlete should know what comes next when the preferred route is denied.

## Fallback Structure

Primary System
→ Denied
→ Secondary System
→ Denied
→ Tertiary System
→ Safe Reset

## Example

Preferred route:

Single leg
→ opponent sprawls

Fallback:

Front headlock

If front headlock is lost:

Go-behind or re-shot

If neither is available:

Reset to standing

The key is that each failure still leaves a known next state.

## Fallback Types

### Technical Fallback

A secondary technique inside the same position.

### Branch Fallback

A different branch inside the same system.

### Pillar Fallback

Transfer into another game pillar.

### Positional Fallback

Return to a stable position.

### Tactical Reset

Disengage and rebuild the exchange.

## Fallback Quality

A strong fallback should:

- Be familiar
- Preserve structure
- Avoid major risk
- Connect to existing strengths
- Require minimal decision complexity
- Be realistic under resistance

## Failure Without Fallback

Synochi should identify situations where the athlete:

- Freezes after the first option fails
- Repeats the same failed attack
- Forces low-value continuation
- Gives up position unnecessarily
- Enters chaotic scrambles with no clear plan

These may indicate missing fallback structure.

## Fallback Depth

Not every system needs endless alternatives.

Synochi should prefer:

Primary
→ Secondary
→ Safe Reset

over:

Large numbers of low-confidence options.

## Fallback Reliability

Fallbacks should be ranked by:

- Recognition speed
- Execution reliability
- Positional safety
- Connection to strengths
- Competition evidence

## Athlete-Specific Fallbacks

Different athletes should have different fallback priorities.

An athlete with strong wrestling may prefer:

Failed guard attack
→ wrestle-up

Another athlete may prefer:

Failed guard attack
→ re-guard and reset

Synochi should learn which fallbacks preserve the athlete’s strongest game.

## Strategic Value

Fallback hierarchy increases resilience.

It allows the athlete to remain composed when the preferred sequence breaks.

The athlete should increasingly experience:

“That option is gone, so I go here.”

rather than:

“That failed, now I improvise.”

## Design Objective

Synochi should help build combat systems that remain functional even when preferred branches are removed.

The goal is not perfect execution.

The goal is robust adaptation.
