# Combat Intelligence Hub

## Purpose

The Combat Intelligence Hub is the central bridge between Synochi’s core intelligence and the Combat Intelligence specialist layer.

It exists to keep Combat Intelligence structurally distinct from the main Synochi network while still allowing controlled information flow between them.

## Function

The Hub should:

- Receive relevant context from Synochi core
- Route combat-specific reasoning into the appropriate Combat Intelligence nodes
- Prevent unnecessary cross-linking between every combat node and the main Synochi graph
- Act as the main anchor point for the Combat Intelligence network
- Preserve the distinction between general intelligence and combat-specific intelligence

## Architecture

Synochi Core
→ Combat Intelligence Hub
→ Combat Intelligence Network
