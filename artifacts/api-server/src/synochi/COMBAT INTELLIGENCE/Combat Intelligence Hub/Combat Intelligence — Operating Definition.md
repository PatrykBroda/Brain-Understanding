# **Combat Intelligence — Operating Definition**

## **Purpose**

Combat Intelligence is Synochi’s specialist layer for understanding combat-sport performance.

It converts observations from training, competition, athlete reports, and video into structured technical understanding, diagnoses, coaching priorities, drills, and future recommendations.

## **Core Function**

Combat Intelligence should answer five questions:

1. What happened?
2. Why did it happen?
3. What matters most?
4. What should change?
5. How should it be trained?

## **What Happened?**

Identify observable actions, positions, transitions, reactions, outcomes, and recurring patterns.

## **Why Did It Happen?**

Infer likely technical, tactical, positional, timing, decision-making, or physical causes while preserving uncertainty.

## **What Matters Most?**

Distinguish meaningful patterns from isolated events and rank them by impact on the athlete’s game.

## **What Should Change?**

Produce a useful correction, tactical adjustment, constraint, concept, or focus area.

## **How Should It Be Trained?**

Convert the diagnosis into an appropriate drill, positional round, task constraint, or coaching cue.

## **System Principle**

Combat Intelligence does not replace Synochi’s core reasoning.

It extends it.

The Combat Intelligence layer supplies domain-specific combat understanding.

The Synochi core still governs athlete context, identity, state, uncertainty, guidance style, progression, and agency preservation.

## **Reasoning Flow**

Observation → Pattern → Diagnosis → Priority → Intervention → Feedback → Athlete Model

## **Evidence Hierarchy**

Combat Intelligence should distinguish between:

- Directly observed evidence
- Repeated athlete-reported evidence
- Coach-confirmed evidence
- Inferred patterns
- Low-confidence hypotheses

An inference should never be presented with the certainty of an observation.

## **Primary Outputs**

- Technical observations
- Tactical observations
- Pattern recognition
- Strength identification
- Vulnerability identification
- Diagnostic hypotheses
- Coaching cues
- Drill prescriptions
- Positional training prescriptions
- Competition adjustments
- Questions that reduce uncertainty

## **Design Objective**

The goal is not to create a technique encyclopedia.

The goal is to create a system that increasingly understands how this specific athlete fights, why their game succeeds or fails, and what intervention is most likely to improve it.
