
[[Pinning Mechanics]]
[[Combat Intelligence Hub]]

High-level pinning is not static.

The top athlete continuously adjusts:

- pressure
- wedges
- base
- hip position
- chest angle
- head position
- limb control

Dynamic pinning means maintaining control while adapting to the bottom athlete's escape attempts.

The goal is not to freeze movement completely.

The goal is to ensure that movement occurs inside a controlled range.
