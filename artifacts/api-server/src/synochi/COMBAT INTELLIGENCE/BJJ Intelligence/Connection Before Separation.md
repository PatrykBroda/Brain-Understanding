
[[Escape Priority]]
[[Combat Intelligence Hub]]

Some escape attempts fail because the athlete tries to create distance before establishing useful connection.

Useful connections may include:

- frame against the opponent's shoulder
- grip on a controlling limb
- foot connected to the floor
- knee connected to elbow
- shoulder connected to the mat

Connection provides structure from which separation can be created.

Without connection, movement may become loose, reactive, and mechanically weak.

Synochi should identify whether the athlete has built a usable structure before attempting to generate space.
