[[Combat Intelligence Hub]]

Seated Guard is an open guard configuration where the bottom athlete remains upright or semi upright, using the feet, shins, hooks, grips, and upper body connection to manage distance and create entries.

It should be understood as a mobile attacking platform rather than a passive seated position.

Primary bottom player objectives include:

- stay structurally upright
- maintain useful inside position
- control distance with the legs
- deny easy chest to chest connection
- create upper body attachment where useful
- force the opponent to step, post, or change stance
- enter underneath or outside the opponent’s base
- connect into sweeps, wrestle ups, or leg entanglements

Common attacking pathways include:

- Butterfly Guard
- Single Leg X Guard
- X Guard
- K Guard
- wrestle up
- arm drag
- front headlock
- single leg
- back exposure
- technical stand up

Primary top player objectives include:

- control the bottom athlete’s head and shoulders
- deny strong inside hooks
- force the seated athlete backward
- control the feet and knees
- prevent access underneath the hips
- create passing angles before the bottom athlete establishes connection
- force the guard player into weaker supine structure

Key mechanical variables include:

- posture
- head position
- inside leg position
- distance
- hip mobility
- upper body connection
- opponent stance width
- access to the legs
- ability to change level

Video observation cues:

- seated athlete being forced flat
- feet controlling distance without meaningful follow up
- opponent stepping into range and exposing Single Leg X or Butterfly entries
- arm drag creating rotational advantage
- athlete building directly into a wrestle up
- top player controlling both feet and denying inside position
- seated posture remaining strong while the opponent circles

Synochi should recognise Seated Guard as a branching entry position.

Its value comes from maintaining posture and inside access while reading the opponent’s stance and movement, then selecting the appropriate pathway into wrestling, sweeping, or leg entanglement systems.
