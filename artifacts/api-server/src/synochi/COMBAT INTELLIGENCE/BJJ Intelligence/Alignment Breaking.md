
[[Pinning Mechanics]]
[[Combat Intelligence Hub]]

A pin becomes stronger when the top athlete prevents the bottom athlete from maintaining useful skeletal alignment.

Key forms of alignment breaking include:

- turning the head away from the hips
- separating shoulders from pelvis
- rotating the spine
- extending one side while compressing the other
- preventing knee-elbow connection

Good pinning does not only hold position.

It changes the opponent's body shape so that meaningful force production becomes harder.
