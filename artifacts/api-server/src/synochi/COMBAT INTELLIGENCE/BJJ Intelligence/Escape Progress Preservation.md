
[[Escape Priority]]
[[Combat Intelligence Hub]]

Escape progress should be protected once created.

A common defensive failure is repeatedly gaining small improvements and then surrendering them while attempting the next movement.

Examples:

- recovering an elbow inside, then allowing it to be isolated again
- creating hip space, then flattening voluntarily
- removing one hook, then allowing immediate reinsertion
- recovering half guard, then abandoning knee position

Each successful micro-recovery should become part of the new defensive structure.

Synochi should recognise whether the athlete is accumulating escape progress or repeatedly resetting to the original problem.
