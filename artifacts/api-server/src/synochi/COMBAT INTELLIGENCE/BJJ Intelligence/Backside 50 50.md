
[[50 50 Guard]]
[[K Guard]]
[[Combat Intelligence Hub]]

Backside 50 50 is a leg entanglement reached when the attacker controls the opponent’s leg from behind the line of the hips, usually after creating an angle that prevents the opponent from easily squaring back toward them.

It should be understood as a control and rotational dominance position rather than simply a heel hook entry.

Primary attacking objectives include:

- control the opponent’s knee line
- stay behind the opponent’s hip line
- prevent the opponent from turning back to square
- control the secondary leg where possible
- manage distance between the hips
- expose the heel without sacrificing positional control
- use the opponent’s defensive rotation to maintain or improve the entanglement

Common attacking pathways include:

- heel exposure where ruleset permits
- transition to 50 50 Guard
- transition to Saddle
- secondary leg attacks
- sweep to top position
- back exposure
- disengagement into passing position after control is established

Primary defensive objectives include:

- recover the knee line
- turn the hips back toward the attacker
- clear secondary leg control
- separate the attacker’s legs and hip connection
- deny heel exposure
- rebuild base before attempting full extraction

Key mechanical variables include:

- position relative to the opponent’s hip line
- knee line depth
- hip angle
- secondary leg control
- rotational freedom
- heel exposure
- ability to prevent the opponent from squaring

Video observation cues:

- attacker clearly positioned behind the opponent’s hip line
- opponent unable to rotate back toward square
- knee line deeply controlled before heel exposure develops
- secondary leg being used to limit defensive movement
- opponent recovering square hip alignment and weakening the position
- attacker maintaining control while following defensive rotation

Synochi should recognise Backside 50 50 as a position where angle creates control.

Its value comes from remaining behind the opponent’s hip line, limiting their ability to square up, and using that positional advantage to create leg attacks, sweeps, or further transitions.
