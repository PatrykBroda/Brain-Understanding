

[[Escape Priority]]
[[Combat Intelligence Hub]]

Escape Readiness describes whether the conditions required for a meaningful escape are currently present.

An athlete may know the correct escape but still be unable to execute it because the necessary mechanical prerequisites have not yet been restored.

Common escape-readiness variables include:

- immediate submission safety
- inside position
- frame integrity
- head and shoulder freedom
- hip mobility
- floor connection
- opponent base disruption
- usable escape direction

Synochi should distinguish between:

knowing the escape

and

being mechanically ready to escape.

When escape readiness is low, coaching should target the missing prerequisite rather than prescribe more effort.
