
[[Escape Priority]]
[[Combat Intelligence Hub]]

Successful escapes often occur through sequential constraint removal.

The athlete should identify which controlling mechanism is preventing the next useful movement.

Example sequence:

head control removed
→ shoulder rotation recovered
→ elbow returns inside
→ hip can rotate
→ knee enters
→ guard is recovered

The athlete does not escape the entire position at once.

They remove enough constraints for the next layer of movement to become available.

Synochi should model escapes as progressive constraint reduction rather than isolated techniques.
