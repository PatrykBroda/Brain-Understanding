
[[Combat Intelligence Hub]]

Type:
Drill Template

Ruleset:
Both

Purpose:

Constraint Based Positional Sparring is a live training format where the athletes begin in a specific position and are given narrow objectives or restrictions that force repeated exposure to a particular problem.

The goal is not simply to win the round.

The goal is to increase the number of meaningful decision repetitions around a selected position, mechanic, or tactical problem.

Template Structure:

Start Position:
Define the exact position or configuration.

Attacker Objective:
Define what counts as meaningful attacking success.

Defender Objective:
Define what counts as meaningful defensive success.

Constraints:
Limit available options where necessary to increase repetition density.

Reset Condition:
Define exactly when the position resets.

Round Duration:
Usually short enough to maintain high repetition quality.

Example:

Start Position:
Bottom athlete in Half Guard with knee shield.

Top Objective:
Flatten the bottom athlete and clear the knee line.

Bottom Objective:
Maintain structure and achieve an underhook, wrestle up, or guard transition.

Constraints:
Top athlete cannot disengage completely.
Bottom athlete cannot immediately switch to Closed Guard.

Reset:
Reset when the top player establishes stable side control or the bottom player achieves a meaningful reversal or transition.

Why It Works:

The drill compresses training around a specific decision environment.

Instead of waiting for the position to appear naturally during sparring, the athlete repeatedly encounters:

- the same positional cues
- common opponent reactions
- timing windows
- successful and unsuccessful decisions
- transitions that emerge from the position

Progression Variables:

The drill can be made easier or harder by changing:

- starting advantage
- permitted techniques
- resistance level
- number of available reactions
- reset conditions
- round duration
- scoring incentives

Diagnostic Use:

Synochi should use this template when an athlete:

- repeatedly fails in the same position
- understands a technique but cannot apply it live
- needs better timing or recognition
- struggles to connect multiple options
- needs higher repetition density around a specific problem

Prescription Logic:

Identify the athlete’s recurring positional problem.

Select the smallest representative starting position.

Define one clear objective for each athlete.

Restrict irrelevant options.

Create frequent resets.

Increase complexity as success becomes consistent.

Synochi should treat Constraint Based Positional Sparring as a general drill framework that can be instantiated around any position, transition, escape, pass, or submission system.
