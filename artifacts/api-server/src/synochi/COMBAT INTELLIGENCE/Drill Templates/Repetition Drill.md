# Repetition Drill

## Definition
A Repetition Drill repeatedly rehearses a movement, micro-movement, technical sequence, or positional action to improve efficiency, consistency, timing, and automaticity.

## Purpose
Use when the athlete needs cleaner execution of a known action rather than more decision complexity.

Best suited for:
- technical refinement
- movement efficiency
- micro-adjustments
- grip or hand-fighting sequences
- entries
- transitions
- finishing mechanics
- position-specific movement patterns

## Starting Position
Begin from the exact position immediately before the target action occurs.

The starting position should be close enough to the target movement that unnecessary setup does not dilute repetitions.

## Attacker Objective
Execute the target movement with:
- correct mechanics
- consistent structure
- minimal unnecessary movement
- appropriate timing
- increasing smoothness

## Defender Objective
Provide the level of structure or resistance required for accurate repetitions.

Resistance may range from:
- passive positioning
- realistic posture
- predictable reaction
- light resistance

The defender should not turn the drill into open sparring unless progression specifically requires it.

## Allowed Actions
Only actions necessary to complete and reset the target movement.

Additional techniques should be restricted if they reduce repetition quality.

## Constraints
Possible constraints include:
- one grip only
- one direction of movement
- fixed starting position
- no alternative finish
- slow execution
- precision before speed
- continuous repetitions without disengagement

## Reset Condition
Reset when:
- the target movement is completed
- the athlete loses the required structure
- execution becomes significantly distorted
- the prescribed endpoint is reached

Return immediately to the starting position to maximise useful repetitions.

## Duration / Reps
Can be prescribed by:
- number of repetitions
- timed blocks
- alternating partner sets
- quality threshold

Volume should remain below the point where fatigue significantly corrupts the movement unless fatigue exposure is intentionally part of the drill.

## Success Metric
Success may be measured through:
- technical consistency
- reduced unnecessary movement
- smoother sequencing
- positional accuracy
- completion rate
- reduced execution time without loss of quality

## Common Errors
- performing repetitions too quickly before mechanics are stable
- allowing setup time to dominate the drill
- adding unnecessary techniques
- repeating poor mechanics
- confusing volume with useful practice
- allowing fatigue to degrade movement without noticing

## Progression
Progress by introducing:
- greater speed
- realistic partner posture
- predictable resistance
- variable starting conditions
- a required reaction
- transition into a decision drill
- progressive resistance

## Regression
Simplify by:
- reducing the movement
- isolating a micro-movement
- slowing execution
- removing resistance
- fixing the starting position
- reducing the number of variables

## Athlete Model Signal
The drill can reveal:
- mechanical inconsistency
- coordination limitations
- unnecessary tension
- poor movement sequencing
- difficulty retaining corrections
- whether execution deteriorates under fatigue
- whether the athlete understands the movement but cannot reproduce it reliably

## Core Rule
Repeat the smallest useful unit until execution becomes reliable enough to add complexity.
