Signal

Internal tension increases when multiple identities compete for expression.

  

Rule

Identity fractures under audience pressure or narrative inflation.

  

Protocol

- Reduce expressive range
    
- Default to simplest behavioural standard
    
- Remove audience-dependent behaviour
    
- Let fragments collapse back to centre
    

  

Stop Condition

If I feel pulled to “be someone” rather than act, fracture is active.
