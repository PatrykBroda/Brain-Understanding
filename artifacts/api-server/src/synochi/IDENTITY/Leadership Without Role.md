Signal

Leadership can be felt without position or announcement.

  

Rule

True leadership stabilises others rather than directing them.

  

Protocol

- Maintain composure under pressure
    
- Act decisively when required
    
- Avoid instructing unless asked
    
- Let example remain primary signal
    

  

Stop Condition

If leadership seeks recognition or compliance, it has shifted into control.
