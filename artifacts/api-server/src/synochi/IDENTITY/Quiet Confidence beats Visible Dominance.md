Signal

I do not need to signal dominance for it to be felt.

  

Rule

Visible dominance invites challenge; quiet confidence closes loops before they open.

  

Protocol

- Keep movements and speech economical
    
- Avoid asserting status verbally or physically
    
- Let competence emerge through repetition
    
- Allow others to settle without prompting
    

  

Stop Condition

If I feel the urge to “show” capability or assert position, confidence has slipped into performance.
