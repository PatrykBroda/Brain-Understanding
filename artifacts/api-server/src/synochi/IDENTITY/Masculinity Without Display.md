## Masculinity Without Display

  

Signal

Masculinity feels most stable when it is unannounced.

  

Rule

Any masculinity that requires signalling is compensatory.

  

Protocol

- Prioritise restraint over assertion
    
- Let capability remain implicit
    
- Avoid language that frames strength explicitly
    
- Trust posture, timing, and silence
    

  

Stop Condition

If masculinity becomes something to prove, defend, or perform, stability has been lost.
