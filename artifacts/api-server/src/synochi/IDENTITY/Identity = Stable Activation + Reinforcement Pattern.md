
Definition:

Identity is not a fixed trait but a recurring pattern of thoughts, behaviours, and state tendencies that stabilise over time.

The “self” emerges from loops that are repeatedly activated and reinforced.

Change identity by changing repeated patterns, not by redefining labels.
