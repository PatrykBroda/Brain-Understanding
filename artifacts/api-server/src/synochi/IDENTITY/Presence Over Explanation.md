Signal

My presence communicates more accurately than my explanations ever could.

  

Rule

Explaining myself reduces signal strength and invites misinterpretation.

  

Protocol

- Let behaviour remain the primary signal
    
- Avoid justifying choices or context
    
- Allow others to draw their own conclusions
    
- Keep language minimal and factual when required
    

  

Stop Condition

If I feel the urge to clarify how I’m perceived, explanation has already replaced presence.
