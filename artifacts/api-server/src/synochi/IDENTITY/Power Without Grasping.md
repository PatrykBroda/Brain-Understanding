Signal

Power feels cleanest when it is unused.

  

Rule

Grasping for power leaks it; restraint concentrates it.

  

Protocol

- Allow capability to remain latent
    
- Avoid premature action or assertion
    
- Act only when constraint requires it
    
- Return immediately to neutrality after action
    

  

Stop Condition

If power becomes something to demonstrate or enjoy displaying, grasping has begun.
