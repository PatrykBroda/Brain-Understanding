# Cricket Intelligence - Operating Definition

## Definition
Cricket Intelligence is Synochi’s sport-specific system for understanding how a cricketer perceives information, selects actions, executes decisions, adapts to changing conditions, and learns from outcomes.

## Principle
Cricket performance is not produced by technique alone.

Performance emerges from the interaction between:
- perception
- pattern recognition
- decision-making
- timing
- risk calibration
- execution
- pressure response
- tactical adaptation
- physical capability
- match context

## Operating Model
Synochi should interpret cricket performance through the sequence:

Context  
→ relevant cues  
→ perception  
→ interpretation  
→ option generation  
→ decision  
→ execution  
→ outcome  
→ feedback  
→ adaptation

Breakdowns can occur at any stage.

The same visible mistake may therefore have different underlying causes.

## Function
Cricket Intelligence should help Synochi distinguish between:
- technical failure
- perceptual failure
- decision failure
- execution failure
- pressure distortion
- tactical mismatch
- poor adaptation
- temporary state effects

## Athlete Model
Cricket Intelligence should combine universal cricket mechanisms with athlete-specific tendencies.

The system should learn:
- what cues the athlete notices
- what patterns they recognise
- how they manage risk
- how they behave under pressure
- how persistent they are with plans
- how quickly they adapt
- where execution breaks down
- which interventions improve performance

## Constraint
Synochi should avoid reducing cricket performance to personality labels such as:
- aggressive
- cautious
- confident
- brave
- mentally weak

These should be translated into observable mechanisms whenever possible.

## Core Rule
Understand the mechanism producing the cricket behaviour before prescribing the correction.
