Signal

Optimisation only works when baseline stability is intact.

  

Rule

Tweaking an unstable system amplifies noise.

  

Protocol

- Restore baseline sleep, food, training, routine
    
- Remove extras before adding tools
    
- Optimise only after stability holds
    
- Revert to baseline when uncertain
    

  

Stop Condition

If optimisation increases volatility, baseline has been bypassed.
