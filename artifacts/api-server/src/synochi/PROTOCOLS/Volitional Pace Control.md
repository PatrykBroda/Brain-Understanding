Signal

I can choose my pace independently of environmental tempo.

  

Rule

Matching external speed without necessity leads to premature action and loss of control.

  

Protocol

- Notice when environments accelerate behaviour
    
- Deliberately slow speech, movement, and decisions
    
- Act only when internal timing aligns
    
- Let others rush without joining them
    

  

Stop Condition

If my pace changes reflexively to match others, volitional control has been lost.
