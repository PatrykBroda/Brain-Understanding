Signal

The way I leave an environment matters more than the way I enter it.

  

Rule

A clean exit preserves authority, prevents residue, and closes loops before they form.

  

Protocol

- Finish sessions without over-talking
    
- Avoid post-training analysis with others
    
- Leave while energy is still neutral or high
    
- Do not linger for validation or decompression
    

  

Stop Condition

If I stay to explain, connect, or “round things off,” the exit window has already passed.
