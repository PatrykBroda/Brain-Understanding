# Threshold Control

## Definition
Threshold Control is Synochi’s ability to manage **when** you cross internal lines:
- escalation
- confrontation
- commitment
- intensity
- spending
- messaging
- training volume

It keeps power precise by controlling *crossing points*.

---

## Core Law
**Crossing thresholds early creates chaos.**
