# Position-Holding Language Protocol

**Definition:** Under pressure, language must stabilise the system, not accelerate it. The purpose of speech is to hold position in chaos: reduce choice, slow tempo, and anchor in body and immediate reality. Fewer words = more control.

**Mechanism:**
- Narrow to one instruction; remove commentary
- Use body anchors (breath, posture, contact points) to restore axis
