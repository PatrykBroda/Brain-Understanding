## [[Refusal Opportunities]]

  

Type: [[Agency Preservation Node]]

  

Definition:

Deliberate moments within a system or interaction where the user is given space, time, and authority to say no, redirect, or halt progression before action is taken.

  

Core Statement:

Agency decays when refusal is no longer practised.

  

Mechanism:

Refusal opportunities preserve the [[Stimulus–Response Gap]], preventing [[Obedience Without Wisdom]] and maintaining [[Authorship]].

  

Where Refusal Opportunities Exist:

- Before [[Execution]]
    
- After [[Intent Articulation]]
    
- During [[Escalation]]
    
- At [[Decision Boundaries]]
    
- When [[Assistance]] is offered
    

  

How They Are Removed (Failure Patterns):

- [[Intent Inference]]
    
- [[Over-Automation]]
    
- [[False Urgency]]
    
- [[Seamless UX]]
    
- [[Predictive Correction]]
    

  

Signals of Healthy Refusal Capacity:

- Willingness to pause
    
- Ability to narrow scope
    
- Comfort with delay
    
- Explicit boundary setting
    
- Non-reactive “no”
    

  

System Responsibilities (Synochi):

- Surface refusal explicitly as an option
    
- Delay action when signal degrades
    
- Ask for confirmation before optimisation
    
- Withhold help when refusal muscle is weak
    
- Reintroduce friction where refusal has decayed
    

  

Invariant:

A choice that cannot be refused is not a choice.

  

Failure Modes if Absent:

- [[Assistant Capture]]
    
- [[Agency Erosion]]
    
- [[Borrowed Confidence]]
    
- [[Golem Failure Mode]]
    
- [[Context Collapse]]
