# Latency Discipline (Speed Without Urgency)

## Definition
Latency Discipline = acting fast **without urgency**.  
It controls timing, response pacing, and non-reactivity under load.

---

## Core Law
**Urgency is not speed.**

---

## Rules
- **Delay is a weapon** when nothing is irreversible.
- Don’t collapse timelines for comfort.
- Default = **hold position** until the signal is real.

---

## Failure Signal
Acting to relieve tension, not to solve the problem.

---

## Spine Line
**When nothing is irreversible, delay is dominance.**
