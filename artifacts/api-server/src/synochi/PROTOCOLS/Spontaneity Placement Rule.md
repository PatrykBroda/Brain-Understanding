# Spontaneity Placement Rule

**Definition:** Spontaneity is an emergent property of regulated systems — never the spine. When the nervous system is coherent, creativity and expression appear naturally. When incoherent, chasing spontaneity becomes noise, impulsivity, and identity performance.

**Mechanism:**
- Don’t “try to be spontaneous” — reduce constraints/noise until it emerges
- Build structure first; spontaneity rides on top
