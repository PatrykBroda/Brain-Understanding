Signal

Rule

Protocol

- Remove one input, task, or commitment
    
- Slow pace slightly
    
- Return to fundamentals
    
- Reassess after reduction
    

  

Stop Condition

If clarity doesn’t improve after reduction, the wrong variable was removed.
