Signal

I can feel the moment before reaction and choose not to move.

  

Rule

Non-reaction is an active choice, not passivity.

  

Protocol

- Detect the impulse to respond
    
- Pause without suppressing sensation
    
- Let the impulse pass unexpressed
    
- Resume baseline behaviour
    

  

Stop Condition

If I justify non-reaction verbally or internally, the choice has turned defensive.
