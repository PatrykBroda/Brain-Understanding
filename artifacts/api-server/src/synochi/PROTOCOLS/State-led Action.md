# State-Led Action

## Definition
State-Led Action means behaviour should be chosen based on the current nervous system state — not based on ideal plans, guilt, or identity.

The state sets the menu.

---

## Core Law
**Don’t force output from the wrong state.**

## Rules
- If state is low: simplify + recover.
- If state is clear: execute.
- If state is volatile: regulate before decisions.

---

## Failure Mode
Forcing action → resentment + instability + drift.

---

## Spine Line
**The state chooses the move.**
