Signal

Discipline feels lighter when it is not used to define identity.

  

Rule

Identity-based discipline becomes brittle; behaviour-based discipline endures.

  

Protocol

- Perform disciplined actions without self-labelling
    
- Avoid narratives of “being disciplined”
    
- Let routines exist without commentary
    
- Drop discipline quietly when context changes
    

  

Stop Condition

If discipline becomes something to defend or display, identity has attached.
