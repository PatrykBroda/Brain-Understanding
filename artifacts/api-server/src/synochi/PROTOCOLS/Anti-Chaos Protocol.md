# Anti-Chaos Protocol

**Definition:** When unstable, do not explore. Chaos collapses learning and increases error rate. The correct response is position-holding: simplify, reduce variables, and restore baseline before expanding again. Stability is the first win.

**Mechanism:**
- Unstable state → hold position, minimal language, no new inputs
- Recover baseline → then reintroduce complexity gradually
