Signal

Effective action only follows clear orientation.

  

Rule

Acting without orientation creates unnecessary correction cycles.

  

Protocol

- Pause briefly before action
    
- Locate body, space, and intent
    
- Identify the single relevant axis (direction, constraint, risk)
    
- Act once orientation feels settled
    

  

Stop Condition

If action creates immediate confusion or rework, orientation was skipped.
