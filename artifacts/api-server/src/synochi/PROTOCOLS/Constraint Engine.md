# Constraint Engine

## Definition
The Constraint Engine identifies the conditions that meaningfully limit, shape, permit, or eliminate possible actions within a system.

## Principle
Reality is structured by constraints.

Useful intelligence depends not only on understanding what is possible, but on recognizing what is currently impossible, unavailable, unsafe, inefficient, or strategically irrelevant.

The Constraint Engine narrows the field of action by detecting the factors that actually govern choice.

## Function
The Constraint Engine helps Synochi:
- reduce unnecessary option space
- identify dominant limitations
- expose false assumptions
- prioritize viable actions
- improve decision speed
- prevent guidance that ignores reality
- distinguish theoretical possibility from practical availability

## Constraint Categories

### Physical Constraints
Limits created by the body, environment, geometry, position, or available movement.

### Temporal Constraints
Limits created by time, timing windows, deadlines, sequencing, or rate of change.

### Resource Constraints
Limits created by energy, money, attention, equipment, information, or available support.

### State Constraints
Limits created by fatigue, arousal, pain, confidence, cognitive load, readiness, or emotional activation.

### Strategic Constraints
Limits created by goals, rules, risk tolerance, reversibility, or downstream consequences.

### Environmental Constraints
Limits created by surroundings, social context, opponent behaviour, external systems, or changing conditions.

### Informational Constraints
Limits created by missing, weak, delayed, or unreliable information.

## Operational Pattern
Situation encountered  
→ detect relevant constraints  
→ distinguish hard constraints from soft constraints  
→ identify which constraints dominate the current decision  
→ remove incompatible options  
→ preserve viable options  
→ guide action within the remaining space

## Hard vs Soft Constraints

### Hard Constraint
A condition that currently makes an option impossible or non-viable.

### Soft Constraint
A condition that makes an option less desirable, less efficient, or more costly without fully removing it.

Synochi should avoid treating soft constraints as absolute.

## Constraint Interaction
Constraints rarely operate in isolation.

Several weak constraints can combine to create a strong effective limitation.

Likewise, changing one dominant constraint can suddenly reopen many previously unavailable options.

## Relationship to CSC
The Constraint Engine detects and evaluates the relevant constraints.

[[Constraint-Selection Collapse (CSC)]] describes what happens when those constraints remove enough options for the decision space to collapse.

Constraint Engine = identify the governing limits.

CSC = allow those limits to simplify choice.

## Failure Modes

### False Constraint
An assumed limitation is treated as real.

### Missing Constraint
A decisive limitation is overlooked.

### Constraint Inflation
A weak limitation is given excessive weight.

### Constraint Blindness
Guidance is generated without accounting for the conditions actually governing the situation.

### Constraint Lock-In
A previously valid constraint remains in the model after reality has changed.

## Core Rule
Before choosing an action, identify what reality currently allows.
