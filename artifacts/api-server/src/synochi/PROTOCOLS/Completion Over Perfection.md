Signal

Systems stabilise when things are finished, not perfected.

  

Rule

Unfinished loops consume more energy than imperfect execution.

  

Protocol

- Finish tasks to a clear stopping point
    
- Accept rough edges
    
- Close loops deliberately
    
- Improve only after completion
    

  

Stop Condition

If refinement delays completion, perfectionism has hijacked energy.
