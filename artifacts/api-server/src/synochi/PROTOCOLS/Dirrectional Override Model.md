# Directional Override Model

**Definition:** The ability to impose direction even when the system is activated. Not suppression — override. When stimuli compete for control, the nervous system selects one forward vector and refuses distraction. This is leadership at the neural level.

**Mechanism:**
- Detect hijack → restore axis → commit to one action
- Behaviour leads state: movement installs direction, not thoughts
