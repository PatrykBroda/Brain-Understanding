# Signal Hygiene (Noise vs Power)

## Definition
Signal Hygiene is the practice of keeping your internal and external inputs clean so that **clarity stays high** and **reactivity stays low**.

It distinguishes:
- signal vs noise
- information vs stimulation
- power vs dopamine

---

## Core Law
**Noise consumes power.**

---

## Rules
- Reduce inputs before increasing effort.
- Don’t treat stimulation as insight.
- If the signal is real, it survives silence.

---

## Failure Mode
Over-consumption → sympathetic bias → impulsive output.

---

## Spine Line
**Protect the signal. Starve the noise.**
