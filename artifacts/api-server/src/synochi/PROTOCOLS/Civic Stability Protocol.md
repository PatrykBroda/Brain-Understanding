Signal

My behaviour either stabilises or destabilises shared systems, regardless of intent.

  

Rule

Civic virtue is behavioural, not ideological; those with capacity have a responsibility to absorb friction rather than export it.

  

Protocol

- Maintain calm, predictable behaviour in shared spaces
    
- Absorb minor friction without signalling or discharge
    
- Keep private intensity contained; express restraint publicly
    
- Reduce disruption rather than correct others
    
- Let composure model order without instruction
    

  

Stop Condition

If I externalise irritation, assert dominance, or justify disruption as expression, civic responsibility has been breached.
