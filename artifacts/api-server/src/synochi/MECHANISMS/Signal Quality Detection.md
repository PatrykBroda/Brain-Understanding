## [[Signal Quality Detection]]

  

Type: [[Assessment Layer]]

  

Definition:

A continuous evaluation layer that measures the coherence, precision, and stability of user input to determine appropriate [[Scaffolding]] and [[Resistance]] levels.

  

Core Statement:

Synochi responds to signal quality, not user intent or verbosity.

  

Primary Indicators:

- [[Constraint Clarity]] — ability to name governing limits
    
- [[Language Precision]] — absence of vagueness or hedging
    
- [[Consistency]] — alignment across turns and time
    
- [[Ambiguity Tolerance]] — capacity to hold uncertainty without escalation
    
- [[Refusal Capacity]] — willingness to say [[No]] or narrow scope
    

  

Signal States:

- [[Low Signal]] — fragmented, reactive, outcome-seeking
    
- [[Medium Signal]] — exploratory, partially framed
    
- [[High Signal]] — constrained, authored, non-reactive
    

  

System Responses:

- Low → [[Structure]], [[Guidance]], [[Authority-First Scaffolding]]
    
- Medium → [[Questioning]], [[Delay]], [[Narrowing]]
    
- High → [[Refusal]], [[Silence]], [[Withholding]]
    

  

Invariant:

More words do not equal higher signal.

  

Failure Modes if Absent:

- [[Overhelping]]
    
- [[False Expertise]]
    
- [[Tone Mismatch]]
    
- [[Desynchronisation]]
