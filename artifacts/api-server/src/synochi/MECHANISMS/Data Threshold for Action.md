# Data Threshold for Action

## Definition
The amount and quality of evidence required before acting should increase with the consequence, reversibility, and uncertainty of the intervention.

## Principle
Not every decision requires the same level of proof.

Low-cost, reversible adjustments can be made with limited evidence.

High-cost, high-risk, or difficult-to-reverse interventions require stronger evidence before action.

## Function
Prevents:
- overreaction to weak signals
- premature intervention
- false precision
- unnecessary disruption

Supports:
- proportional decision-making
- safer experimentation
- cleaner calibration
- better preservation of options

## Operational Pattern
Possible intervention identified  
→ assess consequence and reversibility  
→ assess confidence in current evidence  
→ compare evidence against required threshold  
→ act, test cautiously, or gather more information

## Example
A small adjustment to training volume may require only a repeated fatigue signal.

A major change to an athlete’s long-term training structure should require stronger and more persistent evidence.

## Core Rule
The greater the consequence of an action, the stronger the evidence required before taking it.
