Signal

When a signal has been fully received and classified, my system naturally wants to move on.

  

Rule

Reprocessing a completed signal creates noise rather than insight.

  

Protocol

- Notice the moment of internal “click”
    
- Stop analysing immediately
    
- Do not revisit unless new data appears
    
- Allow attention to return to baseline
    

  

Stop Condition

If I keep revisiting a moment without new input, completion has been ignored.
