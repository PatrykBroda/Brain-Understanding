# Discomfort Tolerance

## Definition
Discomfort Tolerance is the ability to remain regulated and precise while experiencing internal pressure (uncertainty, restraint, waiting, rejection, friction).

It prevents discomfort from becoming behaviour.

---

## Core Law
**Discomfort is not a problem. It’s a signal.**

## Rules
- Don’t fix discomfort with action.
- Let the body feel it without the mind narrating it.
- Use discomfort as reps for containment.

---

## Failure Mode
Comfort-chasing → sloppy decisions → drift.

---

## Spine Line
**Hold discomfort. Keep standards.**
