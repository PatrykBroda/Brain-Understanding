# Transition Bands

**Definition:** Temporary state ranges that appear during environmental, circadian, identity, or training shifts. In transition bands, variability is expected — performance and mood won’t be stable yet because the system is still mapping the new terrain.

**Mechanism:**
- Normalises “in-between” phases to prevent overcorrection
- The correct strategy is stability-first behaviour until the band collapses into a new baseline
