# Baseline Arousal

**Definition:** The default physiological activation level the nervous system returns to when nothing urgent is happening. It sets the tone of perception, muscle tension, decision speed, and threat sensitivity. If baseline is high, everything feels closer and louder; if baseline is low, clarity and patience increase.

**Mechanism:**
- Baseline arousal governs the “idle speed” of mind and body
- Lower baseline → wider tolerance window + cleaner signal
