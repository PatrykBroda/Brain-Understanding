Signal

The speed of thought changes before content becomes distorted.

  

Rule

Rising cognitive velocity signals arousal or misalignment earlier than emotion.

  

Protocol

- Notice acceleration of internal dialogue
    
- Slow behaviour before slowing thought
    
- Reduce inputs (conversation, media, analysis)
    
- Return to simple physical anchors
    

  

Stop Condition

If thoughts begin to layer, branch, or self-reference rapidly, regulation is required before insight.
