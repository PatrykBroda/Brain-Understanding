Attention Allocation

Layer: [[Synochi – Mechanisms]]

The nervous system continuously distributes limited attentional resources based on perceived relevance, threat, and reward.

Function  
Determines what enters conscious awareness and what gets ignored, shaping perception, emotion, and behaviour in real time.

Mechanism  
Attention is biased toward:
• Threat signals (survival priority)  
• Reward cues (dopaminergic pull)  
• Unresolved loops (prediction error)  
• Identity-relevant stimuli  

Because attention is limited, increasing focus in one area necessarily reduces awareness elsewhere.

Consequences  
• Attention directs energy and behaviour  
• Chronic threat focus narrows perception  
• Scattered attention reduces execution quality  
• Stable attention improves regulation and decision-making  

Regulation Link  
Improved nervous system regulation expands attentional flexibility, allowing voluntary redirection instead of reflexive capture.

Failure Modes  
• Rumination loops  
• Hypervigilance  
• Validation seeking  
• Task switching without completion
