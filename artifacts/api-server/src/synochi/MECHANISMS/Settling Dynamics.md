# Settling Dynamics (Blur ↔ Settling)

**Definition:** Mental blur is often a *settling phase*, not a problem. When the nervous system is recalibrating, it reduces cognitive sharpness to stabilise internal variables. Forcing clarity too early creates noise, impatience, and state drift.

**Mechanism:**
- Blur = system reallocating resources to regulation / integration
- The correct response is *containment*: simplify inputs, close loops, wait for coherence to return
