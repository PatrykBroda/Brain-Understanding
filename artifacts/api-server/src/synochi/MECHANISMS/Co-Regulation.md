# Co-Regulation / System Collisions

**Definition:** Nervous systems reshape each other on contact. A regulated system stabilises the field; a dysregulated system exports chaos. Most interpersonal conflict is actually a collision of states — not a disagreement of facts.

**Mechanism:**
- State is contagious: tone, pace, eye contact, posture transmit regulation
- Leadership = holding coherence so the field aligns around it
