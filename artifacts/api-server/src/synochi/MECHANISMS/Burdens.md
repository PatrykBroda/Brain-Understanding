# Burdens

**Definition:** Carried pressure held inside the nervous system — expectation, responsibility, unresolved tension, or silent load. Burdens don’t just occupy thoughts; they alter baseline arousal, muscle tone, and threat sensitivity. The system behaves differently when it is “carrying.”

**Mechanism:**
- Burdens increase idle cost: the system stays partially braced
- Regulation improves when burdens are named, sorted, and structurally contained
