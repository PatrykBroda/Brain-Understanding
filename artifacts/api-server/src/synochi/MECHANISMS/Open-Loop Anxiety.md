# Open-Loop Anxiety (Unclosed Conversations)

**Definition:** A state where interaction ends without clear closure, leaving the nervous system holding residual uncertainty. Nothing is wrong — but the system remains partially activated because the loop is unfinished.

**Mechanism:**
- Lack of closure maintains background scanning and meaning-searching
- Closure is restored through explicit end-points or internal collapse of the loop
