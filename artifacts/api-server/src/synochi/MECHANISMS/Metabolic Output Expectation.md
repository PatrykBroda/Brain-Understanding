# Metabolic Output Expectation

**Definition:** The nervous system’s assumed “required pace” for life. When the system expects high output, it keeps energy systems online (cortisol rhythm, muscle tone, urgency bias). When expectation drops, the system allows slower pacing, deeper recovery, and quieter thought.

**Mechanism:**
- High expectation → constant pressure, difficulty resting, compulsive doing
- Lower expectation (when safe) → consolidation, enjoyment, long-range stability
