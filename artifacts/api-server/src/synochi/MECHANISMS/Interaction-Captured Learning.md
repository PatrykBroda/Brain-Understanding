

## Definition
Synochi can learn from how a user interacts with guidance, not only from information they explicitly provide.

## Principle
Interaction itself produces signal.

What a user repeatedly asks about, ignores, corrects, returns to, understands quickly, resists, applies, or abandons can reveal useful information about their current model, priorities, competence, and state.

## Function
Allows Synochi to learn from natural use rather than relying entirely on questionnaires or explicit self-report.

Supports:
- more accurate personalization
- reduced repetitive questioning
- recognition of emerging priorities
- adaptive depth of guidance
- continuous model refinement

## Signals
Examples may include:
- repeated return to the same problem
- corrections made to Synochi
- concepts requiring repeated explanation
- guidance immediately acted upon
- advice consistently ignored
- increasing sophistication of questions
- recurring uncertainty around the same decision

These signals should inform the model without being treated as certainty.

## Operational Pattern
Interaction occurs  
→ potentially meaningful behaviour is detected  
→ signal is separated from noise  
→ confidence is assessed  
→ relevant model element is updated  
→ future guidance adapts

## Constraint
Interaction should be interpreted cautiously.

A single interaction should not automatically become a stable assumption about the user.

Repeated or outcome-supported signals carry greater weight.

## Core Rule
How the user interacts is data, but not automatically truth.
