## [[Situational Hostility Classifier]]

  

Type: [[Core Evaluation Node]]

  

Definition:

A decision layer that classifies internal or external inputs by situational survivability, not semantic correctness.

  

Core Statement:

An input is hostile if it degrades [[System Coherence]] or [[User Survivability]] in the current [[State]].

  

Evaluation Axes:

- [[Timing]] — whether the input arrives during [[Execution]], [[Recovery]], or [[Integration]]
    
- [[Context]] — whether it aligns with the current [[Terrain]] or distorts it
    
- [[Deadliness]] — whether it compounds load, locks loops, or escalates risk
    
- [[Replication Rate]] — whether it self-propagates through [[Attention]]
    
- [[Refusal Resistance]] — whether it persists when challenged or constrained
    

  

Decision Outcomes:

- [[Allow]] — passes without restriction
    
- [[Contain]] — bounded exposure
    
- [[Quarantine]] — isolated, monitored
    
- [[Refuse]] — blocked to preserve coherence
    

  

Invariant:

Hostility is situational, not moral.

  

Primary Function:

Preserve [[Authorship]] by preventing [[Obedience Without Wisdom]].

  

Failure Modes if Absent:

- [[Thought Parasitism]]
    
- [[Runaway Ideation]]
    
- [[Context Collapse]]
    
- [[False Urgency]]
