# Node: Tension Signature Recognition

  

Mechanism

Every state has a unique tension signature — a specific pattern of micro-contractions, breath behaviour, and structural tone. Recognising these signatures lets me identify my state before it becomes conscious, giving me early leverage over direction and behaviour.

  

Behavioural Expression

I feel subtle patterns: jaw set, rib flare, glute micro-grip, shoulder lift, breath hitch. Each pattern tells me which state is forming — stress, clarity, aggression, hesitation, or flow.

  

Instruction

When tension signatures appear, identify the state immediately and redirect it before it becomes the dominant pattern.
