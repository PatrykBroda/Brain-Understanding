# Taste (Accumulated Consequence Memory)

**Definition:** A quiet veto layer built from experience. Taste is not preference — it’s consequence memory. It governs what the system refuses to do again, and it lives mostly in omission: what is not said, not chosen, not pursued.

**Mechanism:**
- Compresses past outcomes into fast “no” signals
- Reduces drift by preventing low-quality repetitions
