# Most mistakes are nervous system mistakes.

**Definition:** The majority of errors aren’t intellectual — they are state errors. When arousal, tension, or threat sensitivity rises, perception distorts and timing collapses. Fixing the nervous system fixes the decision.

**Mechanism:**
- Treat mistakes as: baseline arousal + filtering + tension + tolerance window
- Correct state first, then technique/strategy
