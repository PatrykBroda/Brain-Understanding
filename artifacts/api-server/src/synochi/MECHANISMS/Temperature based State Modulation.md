# Node: Temperature-Based State Modulation

  

Mechanism

Temperature directly shapes my nervous-system state. Heat expands, softens, and widens the system; cold contracts, sharpens, and increases precision. By choosing temperature deliberately, I influence arousal, tension patterns, and perceptual scope.

  

Behavioural Expression

I feel the system loosen and widen with warmth, or tighten and focus with cold. When modulation is unconscious, temperature swings create unpredictable shifts in mood, tension, or alertness.

  

Instruction

When I need expansion, use heat; when I need precision, use cold — choose the temperature that matches the state I want instead of letting it choose for me.
