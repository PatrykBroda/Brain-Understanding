# Regulation–Reflex Feedback Loop

**Definition:** Regulation determines reflex quality, and reflex outcomes reshape regulation. When the system is regulated, reflexes become precise and economic. When dysregulated, reflexes become exaggerated, mistimed, or panicked — and the failures feed back into higher threat sensitivity.

**Mechanism:**
- Calm baseline → better timing + cleaner motor programs
- Poor reflex outcomes → threat threshold drops → arousal rises → worse reflexes
