Signal

Repeated exposure can quietly shift interactions from professional to familiar without explicit consent.

  

Rule

Familiarity increases access; unchecked drift erodes boundaries and clarity.

  

Protocol

- Monitor tone shifts over time
    
- Reset to neutral politeness when familiarity creeps in
    
- Reduce personal disclosure as exposure increases
    
- Use spacing to restore baseline
    

  

Stop Condition

If interactions start to assume shared context, jokes, or entitlement, drift has occurred.
