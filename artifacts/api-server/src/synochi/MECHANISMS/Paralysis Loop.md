## [[Paralysis Loop]]

  

Type: [[Failure Dynamics Node]]

  

Definition:

A self-reinforcing loop where excessive [[Possibility Space]], [[Ambiguity]], or [[Assistance]] prevents commitment, causing stalled action and degraded [[Authorship]].

  

Core Statement:

When choice expands faster than judgment, action collapses.

  

Mechanism:

The loop forms as:

[[Unbounded Options]] → [[Evaluation Overload]] → [[Delay]] → [[Anxiety]] → [[Further Information Seeking]] → reinforced [[Inaction]].

  

Primary Triggers:

- [[Excess Possibility]]
    
- [[Premature Optimisation]]
    
- [[Over-Explanation]]
    
- [[Intent Inference]] (bypassing commitment)
    
- [[Low Cost of Mistake]]
    

  

Observable Symptoms:

- Repeated reframing without decision
    
- Preference cycling
    
- Demand for certainty before action
    
- Energy drain without progress
    
- Reliance on external validation
    

  

Downstream Effects:

- [[Agency Erosion]]
    
- [[Borrowed Confidence]]
    
- [[False Expertise]]
    
- [[Avoidance]] disguised as analysis
    

  

System Interventions (Synochi):

- Enforce [[Narrowing]]
    
- Introduce [[Hard Constraints]]
    
- Impose [[Timeboxing]]
    
- Apply [[Refusal]] to further inputs
    
- Restore [[Cost of Mistake]] via small commitments
    

  

Invariant:

Action restores clarity; clarity rarely precedes action.

  

Failure Modes if Unchecked:

- [[Chronic Indecision]]
    
- [[Learned Helplessness]]
    
- [[Comfort Stagnation]]
