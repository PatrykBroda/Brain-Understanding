# Node: Sensory Bandwidth Control

  

Mechanism

Sensory bandwidth is the amount of incoming information my system can process without destabilising. When bandwidth is controlled, I receive only what I can integrate; when it widens too fast or narrows too hard, the system slips into overwhelm or hyper-focus.

  

Behavioural Expression

I feel steady, manageable input when bandwidth is right. When it widens too far, everything feels loud or intrusive. When it narrows, I lose peripheral cues and slip into tunnelled states.

  

Instruction

When sensory load feels off, adjust bandwidth—soften to widen, stabilise to narrow, and keep the system inside a range it can process cleanly.
