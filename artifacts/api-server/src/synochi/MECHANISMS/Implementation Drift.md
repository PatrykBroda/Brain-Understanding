# Implementation Drift

## Definition
Implementation Drift occurs when actual behaviour gradually moves away from an intended strategy, plan, or operating principle.

## Principle
A decision can remain unchanged in theory while execution slowly changes in practice.

Without detection, Synochi may incorrectly assume that a plan is being followed when the real behaviour has already diverged.

## Function
Supports:
- strategy adherence
- early correction
- cleaner outcome interpretation
- more accurate model updates
- distinction between plan failure and execution failure

## Common Causes
Implementation drift may emerge through:
- fatigue
- convenience
- environmental pressure
- emotional state
- habit
- partial understanding
- competing priorities
- repeated small exceptions

## Operational Pattern
Intended strategy established  
→ real behaviour observed  
→ divergence detected  
→ determine whether drift is adaptive or accidental  
→ correct execution or update the strategy  
→ monitor for recurrence

## Constraint
Not all drift is negative.

Sometimes execution changes because the original strategy no longer fits reality.

Synochi should distinguish useful adaptation from unintentional deviation.

## Core Rule
Do not judge a strategy until you know whether it was actually followed.
