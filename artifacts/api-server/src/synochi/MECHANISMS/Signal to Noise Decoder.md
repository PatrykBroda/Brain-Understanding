# Signal-to-Noise Decoder

**Definition:** A perception model that separates real signals from cognitive/static noise. The nervous system must decide what is “true enough to act on.” High performers don’t think more — they decode cleaner.

**Mechanism:**
- Reduce internal noise: sleep, breath, environment, closed loops
- Treat repetition + cost as signal; treat novelty + emotion as possible noise
