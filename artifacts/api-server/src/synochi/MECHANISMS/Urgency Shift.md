# (Urgency Shift)

**Definition:** Perceived urgency is not fixed — it changes with relative motion. When a threat, task, or thought feels like it is “approaching,” its frequency rises: attention narrows, arousal increases, and urgency spikes. When it is “receding,” urgency drops even if the objective reality hasn’t changed.

**Mechanism:**
- Approaching signal → nervous system accelerates (fight readiness)
- Receding signal → nervous system downshifts (release permitted)
