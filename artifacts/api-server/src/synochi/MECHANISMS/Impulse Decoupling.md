# Impulse Decoupling

## Definition
Impulse Decoupling is the ability to experience a strong internal signal (desire, anger, hunger, excitement, fear) without treating it as an instruction.

It separates:
**feeling** from **action**

---

## Core Law
**Signal ≠ command.**

## Rules
- Feel it fully. Don’t enact it.
- Let impulses peak and pass without response.
- Act only from baseline or doctrine.

---

## Failure Mode
Fast behaviour used as emotional relief.

---

## Spine Line
**You don’t obey signals. You use them.**
