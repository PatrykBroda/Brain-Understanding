FRAME should have one central brain: the Athlete Model.

Everything feeds it.

The FRAME Knowledge Loop
            Chat

              ▼
      Athlete Model ◄──────── Video Analysis
              ▲                  │

Video Analysis Shouldn't Produce a Report

It should produce evidence.

Example:

Video analysis detects:

Rear hand drops after combinations.

Confidence:
High

Evidence:
Observed consistently across 11 exchanges.

FRAME doesn't just show this.

It writes it into the Athlete Model.

Athlete Model Structure

Instead of storing paragraphs, store structured observations.

{
  "category": "Striking Defence",
  "observation": "Rear hand drops after combinations",
  "confidence": 0.92,
  "source": "Video Analysis",
  "evidence_count": 11,
  "first_seen": "2026-07-10",
  "last_confirmed": "2026-07-10"
}

Every observation becomes a memory.

VIDEO ANALYSIS → ATHLETE MODEL INTEGRATION

Video Analysis is not a standalone feature.

Every completed analysis must update the Athlete Model.

Architecture:

Video Upload
↓

AI Analysis
↓

Extract structured observations

↓

Map each observation to an Athlete Model category

↓

Compare against existing observations

↓

If observation already exists:
- increase confidence
- update last confirmed timestamp
- increment evidence count

If observation is new:
- create a new observation
- assign an initial confidence based on AI certainty
- mark it as "Emerging" if confidence is below the confirmation threshold

↓

Recalculate:
- Model Confidence
- Fight Readiness inputs
- Athlete Identity
- FRAME Notes
- Athlete DNA confidence bands

↓

Display:

Athlete Model Updated

New observations:
✓ ...
✓ ...

Confidence increased:
+X%

Do not store long-form AI paragraphs as the source of truth.

Store structured observations with:

- category
- observation
- confidence
- source
- evidence count
- first seen
- last confirmed
- supporting evidence

The Athlete Model should be the single source of truth.

Chat, Session Reflections, Competition Reviews, Weekly Missions and Video Analysis must all read from and write to this same model.
The long-term vision

This is what I think makes FRAME genuinely different.

The AI shouldn't remember conversations.

It should remember evidence.

After six months, FRAME shouldn't be able to say:

"You told me you struggle with exits."

It should be able to say:

"Across 14 sparring videos, 6 post-session reflections, and 3 competition reviews, one pattern has remained consistent: your defensive structure breaks down during exits after multi-strike combinations. That pattern has strengthened over time, not weakened."

That's the moment users stop feeling like they're talking to a chatbot and start feeling like they have a coach that's been studying them over an entire career.
