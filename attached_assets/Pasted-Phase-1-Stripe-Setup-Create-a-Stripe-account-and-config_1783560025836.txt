Phase 1 — Stripe Setup

Create a Stripe account and configure:

Product: FRAME+
Price: £6.99/month
Monthly recurring subscription
Free trial (optional, e.g. 7 days)
Customer Portal enabled (so users can manage/cancel subscriptions)
Test mode first, then switch to Live when everything works.
Phase 2 — Database

Add subscription fields to your users table.

stripe_customer_id
stripe_subscription_id
subscription_status
plan
current_period_end

Example:

plan = free
plan = frame_plus

subscription_status = active
subscription_status = cancelled
subscription_status = past_due

Never rely solely on the frontend to determine access.

Phase 3 — Backend

Create endpoints such as:

POST /api/billing/create-checkout-session

POST /api/billing/webhook

GET /api/billing/status

POST /api/billing/create-portal-session

The webhook is the source of truth. When Stripe sends events like:

checkout.session.completed
customer.subscription.created
customer.subscription.updated
customer.subscription.deleted

update the user's subscription status in your database.
